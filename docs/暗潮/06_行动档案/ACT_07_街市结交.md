## 金钱戏

| 项 | 内容 |
|---|---|
| 类型 | 门路钱 |
| 对谁 | 林瑞生——街面名声 |
| 戏剧 | 两吊钱买茶、替人写封信、搭把手搬货，换的是“街面上有人认得你”。人脉≥10 后 ACT_10 接触竞品才像回事，而不是蹭热度。 |
| 拿不到 | `stat_network` 涨得慢；赵鸿运、聚丰行接触缺乏前置 |

### 阈值台词（表现层）

| 条件 | 反馈 |
|---|---|
| `stat_money < 20` | 「只能请一碗茶，话却说得足：‘兄弟，日后有事找林瑞生。’」 |
| `stat_money >= 50` | 「小小人情做足了，街市上有人点头：‘钱记那个跑腿的，会办事。’」 |

### B 线收益层级（跳槽线口径）

- `act_07` 对应**层 1：门路钱 / 街市信用**。你花的不是“买卖”那点银子，而是买到“有人愿意顺你一条路”
- 它本质喂给后续的 `act_10`（人脉≥10）和 `R005`（人脉/报价门槛），让跳槽线的“估值”有底座

```yaml
effects:
  - { op: add, key: stat_money, value: -2 }
  - { op: add_range, key: stat_network, min: 2, max: 5 }
```
