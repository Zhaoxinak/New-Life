## 金钱戏索引

Demo 日常行动按 **生存钱 / 情面钱 / 门路钱 / 黑账钱** 标注；详见 [`主角属性`](../04_数值定义/主角属性.md) 与 [`阈值与惩罚`](../04_数值定义/阈值与惩罚.md)。

| id | 名 | 金钱类型 | 消耗/收入 | 戏剧要点 |
|---|---|---|---|---|
| `act_01` | 商行干活 | 生存钱 | +2~3 | 最干净收入，养信任 |
| `act_02` | 整理货单 | 黑账（信息） | — | 货单数字是鸦片弧入口 |
| `act_03` | 茶楼打听 | 门路钱 | -2 | 花钱买消息 |
| `act_04` | 请师兄喝酒 | 情面钱 | -3 | 酒钱换后院风声 |
| `act_05` | 拉拢伙计 | 情面/黑账 | -1~3 | 散碎银子买支持 |
| `act_06` | 陪伴如烟 | 情面（可选） | 0 或 -3 | 空手 vs 带心意 |
| `act_07` | 街市结交 | 门路钱 | -2 | 街面名声前置 |
| `act_08` | 休息整理 | 生存（反向） | — | 不出门，省嫌疑不挣钱 |
| `act_09` | 暗中观察 | 黑账（风险） | — | 丢差事比花钱更疼 |
| `act_10` | 接触竞品 | 黑账（前置） | — | 赵鸿运先看周转能力 |
| `act_11` | 钱庄办事 | 生存+门路 | 菜单 | ≥10 进门，≥50 高阶 |
| `act_12` | 整理情报 | 门路（变现） | — | 情报变价码的前夜 |

**阈值台词**：各 ACT 口风见 [`DIALOG_ACT_POOL`](../11_对话档案/DIALOG_ACT_POOL.md)（`dialog_act_*_outro_*`）。
