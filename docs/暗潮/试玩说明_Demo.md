## 3. 建议试玩路径

### 路径 A · 隐忍（默认好走）

1. 前堂多「商行干活」，堆 `信任`。  
2. 后院整理货单 / 拉拢伙计，抬情报与支持。  
3. 货栈陪伴如烟；银两≥30 时可能触发送礼（人情债）。  
4. 跟主线到 E018A：看闪回清算与「林跑街」称呼。

**检查点：** 升职演出 → 轻清算 → 主清算 → `ending_a`

### 路径 B · 跳槽

1. 街市「结交」「茶楼打听」堆人脉。  
2. 人脉≥10 后「接触竞品」；银两≥50 时赵鸿运口气更好。  
3. 尽量走缺陷路线旗（事件选项），冲 E018B。

**检查点：** `stat_credit_market` 上涨 → 聚丰任命台词

### 路径 C · 洋行

1. 走洋人相关选项，抬 `impression_bradley` / 洋行信用。  
2. R009 或剧情开 `flag_bradley_invite` 后可拜访宝顺。  
3. `flag_ending_c_ready` 后，洋行「接代理佣金」或 E018C。

**检查点：** 名片邀约 → 佣金/代理分成 → `ending_c`

## 4. 系统速查（Demo 已接）

| 系统 | 怎么摸到 |
|---|---|
| 票号金融 | `loc_04` 钱庄办事：短借 / 还款 / 展期 / 汇兑 / 行情 |
| 断炊/拮据 | 日末银两＜10 / 10–19 |
| 组织账 | HUD「钱记热度 / 周转」；E013/E015 选择会改暗账热度 |
| 朝账差事/序位 | 浮窗「差事·序位」：默认可收起；拖标题移动、右下角改大小；「序」开榜 |
| **作弊台** | **F3** 打开：快捷跳转 / 时间 / 数值 / 职级朝账 / 事件 / 旗标（Esc 关） |

| 账簿朝账页 | 按 J →「朝账」页：上次摘要 / 定调 / 本周差事 |
| 交情五档 | HUD 德茂→你；禁止再写「好感度」 |
| 随机事件 | 仅玩家行动后可能触发，每日最多 1 条 |
| 失败 | 嫌疑/信任等越线后可能进 F\* |
