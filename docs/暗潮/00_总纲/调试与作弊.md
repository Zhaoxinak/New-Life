# 调试与作弊（设计）

> 设计期预留，实现时可做隐藏控制台 / 开发菜单。不进入正式通关路径。

---

## 1. 建议能力

| 命令 | 作用 |
|---|---|
| `set_day` / `set_slot` | 跳时间 |
| `add_stat` / `set_stat` | 改主角属性 |
| `add_edge_score` | 改交情分 |
| `set_meter` | 改 meter |
| `set_flag` / `clear_flag` | 旗标 |
| `unlock_clue` / `grant_item` | 线索信物 |
| `trigger_event` | 强塞事件队列 |
| `dump_save` | 导出当前运行库 |

全部应走 **同一套 effect / require 管线**，便于测白名单。

---

## 2. 纪律

- 仅 `dev_build` 或启动参数开启  
- 使用作弊不成就成就（若有）  
- 日志记录作弊指令，方便复现 bug
