# 本地化约定（设计）

> `loc_key` 键名模式权威。对话节点形状、effect 写法见 [`对话规范.md`](对话规范.md)。

---

## 1. 原则

- **逻辑表不进长文案**：人名显示、对话、事件标题用 `loc_key`  
- 默认语言：`zh-Hans`  
- 键名稳定，改文案不改键  

---

## 2. 键名建议

| 类型 | 模式 | 例 |
|---|---|---|
| 人物名 | `char.<id>.name` | `char.lin_ruisheng.name` |
| 事件标题 | `event.<id>.title` | `event.E014.title` |
| 对话 | `dialog.<event>.<node>` | `dialog.e014.a.intro` |
| UI | `ui.<screen>.<elem>` | `ui.hud.stat.money` |
| 线索 | `clue.<id>.name` / `.desc` | |

---

## 3. 回退

缺键 → 显示键名本身（调试）或 `zh-Hans` 回退。
