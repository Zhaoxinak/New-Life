# 表现层边界（设计）

> 游戏真相只在运行库。表现层订阅变化，不另造一套「剧情状态」。

---

## 1. 属于表现层（可随便改，不影响存档权威）

- 镜头、立绘、表情、走位  
- UI 动画、红点、震动  
- BGM / SE  
- 对话打字机速度、闪屏  

## 2. 属于模拟层（必须进库 / effect）

- 任何数值、交情、meter、flag、线索、物品  
- 时段推进、事件是否触发  
- 结局判定  

## 3. 桥接

```
run_* 变更 → 发出 domain event（如 EdgeScoreChanged）
         → UI / 演出监听 → 播动画 / 刷新 HUD
```

禁止：演出脚本里 `player.money += 10` 却不走 effect 管线。
