# 表现层边界（设计）

> 游戏真相只在运行库。表现层订阅变化，不另造一套「剧情状态」。

---

## 1. 属于表现层（可随便改，不影响存档权威）

- 镜头、立绘、表情、走位  
- UI 动画、红点、震动  
- BGM / SE  
- 对话打字机速度、闪屏  

---

## 2. 属于模拟层（必须进库 / effect）

- 任何数值、交情、meter、flag、线索、物品、**职级、恩怨**  
- 时段推进、事件是否触发  
- 结局判定  

---

## 3. 桥接

```
run_* 变更 → 发出 domain event（如 EdgeScoreChanged / RankChanged / GrudgeResolved）
         → UI / 演出监听 → 播动画 / 刷新 HUD
```

禁止：演出脚本里 `player.money += 10` 却不走 effect 管线。

---

## 4. 升职演出合同（四件套可见化）

触发：`set_rank` 成功或升阶仪式事件（如 E020 / E018）。

| 拍 | 表现 | 绑定真相 |
|---|---|---|
| 1 仪式 | 前堂全员 / 掌柜宣布；镜头从靴尖摇到主角 | flag / 对白 |
| 2 称呼 | UI 或字幕第一次打出新称号（林外场 / 林跑街） | `player_rank` |
| 3 权限 | 地图热区亮起、新 ACT 解锁闪白 | 解锁表 |
| 4 银钱 | 月例档位上跳动画（文案写清「月例」不是裸数字） | 收入档 / stat |
| 附 恩怨窗 | 若本阶可清算：恩怨页闪烁一条 open | `run_grudge` |

SE 建议：算盘一记 → 静场 → 窃窃私语。  
禁止系统腔旁白（「信任+10」）；用称呼与看客反应代替。

---

## 5. 清算演出合同（罚/恕）

触发：`resolve_grudge`。

| 拍 | 表现 |
|---|---|
| 0 闪回 | 黑场一句埋债羞辱（`flashback_key`） |
| 1 称呼 | 看客怎么叫你 |
| 2 站位 | 主角站位升高；仇人被挤到侧光 |
| 3 看客 | 私语、改眼神、有人后退 |
| 4 失态 | **罚**：崩脸、甩袖、被父喝止；**恕**：想发作不敢，又恨又惧 |
| 5 UI | 恩怨条划掉；status → punished / forgiven |

罚/恕分支必须有**不同镜头落点**（罚落在仇人脸上；恕落在主角收势的手上）。

---

## 6. Hub 序位芯片（`run_ladder`）

触发：`run_ladder` 变更 → `LadderRankChanged` domain event。

| 元素 | 绑定 | 表现 |
|---|---|---|
| 池名 | `pool_id` → `ui.ladder.pool.*` | 「学徒序」「外场序」「跑街序」 |
| 名次 | `player_rank` / `player_total` | `2/5` |
| 趋势 | `last_delta` | `↑1` `↓1` `—` |
| 朝账倒计时 | `run_meeting.days_until_next` | 可与芯片并列或 tooltip |
| 展开面板 | `entries[]` | 迷你排行榜条；**不显示核心层人物** |

核心召见时（`flag_core_summoned`）：芯片**临时替换**为「后堂召见」/ 不显示排名，避免玩家误以为靠排队进核心。

禁止：演出里手改名次却不走 `add_ladder_score` / `init_ladder_pool`。

---

## 7. 朝账议场（`MeetingStage`）

触发：朝账事件 `M*` / `M000` 开播（`DialogueRunner.dialog_started` 且 event/dialog 属 meeting）。

| 元素 | 绑定 | 表现 |
|---|---|---|
| 升/降幕 | meeting 事件起止 | 全屏议场覆盖 Hub；结束降下 |
| 机位 | `attendance_tier` | `listen` 帘影 / `report+` 全席；厅堂底图 `art/meeting/hall_front.png` |
| 席位胸像 | `art/meeting/busts/<char_id>.png` | 圆裁优先；缺则 portraits → sprites |
| 席位 | `def_meeting_stage` + flags / queue | 胸像落座；缺席划掉 |
| 段标 | `meeting_segment_changed` 或 dialog 启发 | ①–⑥ 顶部横幅 |
| 畅言焦点 | `council_*` + `council_turn_changed` | 金框当前发言者；沉默灰+…… |
| 定调 | `meeting_policy_resolved` | 上首独亮 + 文言短标 |
| 差事 | `meeting_tasks_changed` | 任务卡飞入 HUD |
| 关键字 | dialog tag `keyword_highlight` / `rank_address` | 正文 BBCode 高亮；称呼拍自动高亮「林外场 / 林跑街 / 林朋友…」（长词优先） |
| 仪式收束 | `ceremony_finished` | 议场回光；升职则旁听→列席挪位 |
| 截断 | `dialog_*demao_cut*` | 全席一震、上首放大 |
| 音效 | `MeetingAudio` | open / seat / gavel / cut + BGM loop（无资源则静默） |
| 心绪角标 | 席位 `MoodMark` | 言 / 默 / 偏 / 断 |
| 账簿朝账 | `last_summary_key` + history.meeting | Ledger「朝账」页回顾 |

禁止：舞台脚本里改 trust / suspicion / rank；细则见 [`../17_朝账系统/朝账议场演出合同.md`](../17_朝账系统/朝账议场演出合同.md)。
