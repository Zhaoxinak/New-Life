# 表现层边界（设计）

> 游戏真相只在运行库。表现层订阅变化，不另造一套「剧情状态」。

---

## 1. 属于表现层（可随便改，不影响存档权威）

- 镜头、立绘、表情、走位  
- UI 动画、红点、震动  
- BGM / SE  
- 对话打字机速度、闪屏  

---

## 2. 属于模拟层（必须进库 / effect）

- 任何数值、交情、meter、flag、线索、物品、**职级、恩怨**  
- 时段推进、事件是否触发  
- 结局判定  

---

## 3. 桥接

```
run_* 变更 → 发出 domain event（如 EdgeScoreChanged / RankChanged / GrudgeResolved）
         → UI / 演出监听 → 播动画 / 刷新 HUD
```

禁止：演出脚本里 `player.money += 10` 却不走 effect 管线。

---

## 4. 升职演出合同（四件套可见化）

触发：`set_rank` 成功或升阶仪式事件（如 E020 / E018）。

| 拍 | 表现 | 绑定真相 |
|---|---|---|
| 1 仪式 | 前堂全员 / 掌柜宣布；镜头从靴尖摇到主角 | flag / 对白 |
| 2 称呼 | UI 或字幕第一次打出新称号（林外场 / 林跑街） | `player_rank` |
| 3 权限 | 地图热区亮起、新 ACT 解锁闪白 | 解锁表 |
| 4 银钱 | 月例档位上跳动画（文案写清「月例」不是裸数字） | 收入档 / stat |
| 附 恩怨窗 | 若本阶可清算：恩怨页闪烁一条 open | `run_grudge` |

SE 建议：算盘一记 → 静场 → 窃窃私语。  
禁止系统腔旁白（「信任+10」）；用称呼与看客反应代替。

---

## 5. 清算演出合同（罚/恕）

触发：`resolve_grudge`。

| 拍 | 表现 |
|---|---|
| 0 闪回 | 黑场一句埋债羞辱（`flashback_key`） |
| 1 称呼 | 看客怎么叫你 |
| 2 站位 | 主角站位升高；仇人被挤到侧光 |
| 3 看客 | 私语、改眼神、有人后退 |
| 4 失态 | **罚**：崩脸、甩袖、被父喝止；**恕**：想发作不敢，又恨又惧 |
| 5 UI | 恩怨条划掉；status → punished / forgiven |

罚/恕分支必须有**不同镜头落点**（罚落在仇人脸上；恕落在主角收势的手上）。

---

## 6. Hub 序位芯片（`run_ladder`）

触发：`run_ladder` 变更 → `LadderRankChanged` domain event。

| 元素 | 绑定 | 表现 |
|---|---|---|
| 池名 | `pool_id` → `ui.ladder.pool.*` | 「学徒序」「外场序」「跑街序」 |
| 名次 | `player_rank` / `player_total` | `2/5` |
| 趋势 | `last_delta` | `↑1` `↓1` `—` |
| 朝账倒计时 | `run_meeting.days_until_next` | 可与芯片并列或 tooltip |
| 展开面板 | `entries[]` | 迷你排行榜条；**不显示核心层人物** |

核心召见时（`flag_core_summoned`）：芯片**临时替换**为「后堂召见」/ 不显示排名，避免玩家误以为靠排队进核心。

禁止：演出里手改名次却不走 `add_ladder_score` / `init_ladder_pool`。
