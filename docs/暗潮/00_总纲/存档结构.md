# 存档结构（运行库契约）

> 存档 = 运行库快照。只存**实例状态**，不存定义正文、不存可派生量的权威副本。  
> 相关：[`数据库架构.md`](数据库架构.md) · [`effect词汇表.md`](effect词汇表.md)

---

## 1. 存什么 / 不存什么

| 存 | 不存 |
|---|---|
| 当前日、时段、槽位元数据 | 人物背景文案、性情长文 |
| `stat_*` 当前值 | 属性「含义说明」 |
| 每条边的 score / 修正 / 债 / 把柄 | 由 score 推导的 tier（可缓存） |
| meter、flag、已解锁线索与品质 | 事件完整对白 |
| 持有信物/把柄 | 建筑描述、热区说明 |
| 已读对话节点（可选） | Mod 定义原文 |
| 事件队列（未播完） | |

## 2. 槽位元数据 `run_meta`

| 字段 | 类型 | 说明 |
|---|---|---|
| `slot_id` | int | 0..N |
| `schema_version` | string | 如 `0.1`；读档校验 |
| `content_version` | string | 暗潮文档/数据包版本 |
| `day` | int | ≥1；**不锁 30**（三章开放日程） |
| `slot` | enum | morning/noon/afternoon/evening/late_night |
| `player_rank` | enum | `apprentice` \| `waichang` \| `paojie` \| `houtang`；初值 `apprentice` |
| `rng_seed` | int | 可复现随机 |
| `playtime_sec` | int | 可选 |
| `last_act_id` | act_id? | 可选，供 tick 判断 |

## 4. 关系边 `run_edge`

| 字段 | 说明 |
|---|---|
| `from` / `to` | `char_id` |
| `score` | −100..+100 |
| `trust` / `suspicion` / `fear` | 档位整数（见词汇表） |
| `debt` | 人情债/账外欠情；短字符串或短数组 |
| `leverage` | 把柄/担保/卡脖子；短字符串或短数组 |
| `bonds` | 开局可从定义拷贝；运行时很少改 |

未出现的边：读时视为默认（泛泛 / 0 / 低 / 低 / 无 / 无）。  
**不必存满笛卡尔积。**

## 6c. 履历 `run_history`

按时间追加的可读履历（账簿「往来」）。存实例摘要，不存对白全文。

```yaml
run_history:
  - day: 3
    slot: afternoon
    kind: event          # event | edge | rank | grudge | clue | debt | route
    ref: E004
    summary_key: event.E004.name   # 或 history.* / def loc_key
    payload: {}          # 可选短字段
```

| 规则 | 说明 |
|---|---|
| 写入点 | 事件结束、交情/线索/恩怨/债变更、升降职、路线旗标点亮 |
| 旧档 | 无 `history` 时读档为空；可用 `seen_event_*` 回填标题级条目 |
| 表现 | 账簿往来 Tab；禁止系统腔「+10」作摘要 |

## 6b. 恩怨 `run_grudge`

run_grudge:

## 7. 债务实例 `run_debt`

```yaml
run_debt:
  debt_bank_short_001:
    service_id: svc_bank_loan_short
    creditor: org_bank
    principal: 15
    remaining: 12
    interest_per_day: 1
    due_day: 18
    collateral: none
    status: active
```

### 建议字段

| 字段 | 说明 |
|---|---|
| `service_id` | 对应定义服务 |
| `creditor` | `org_*` / `char_*` |
| `principal` | 初始借额 |
| `remaining` | 剩余应还 |
| `interest_per_day` | 日息 |
| `due_day` | 到期日 |
| `collateral` | 担保物/担保人 |
| `status` | `active` / `overdue` / `cleared` |

债务层用于正规借贷与明确借账；**人情债仍优先写在 `run_edge.debt`**。

## 10. 读档规则

1. `schema_version` 不识别 → 拒绝或走迁移表  
2. 缺字段 → 用定义初值填充  
3. 未知 flag/meter → 保留但警告（Mod 向前） / Demo 可丢弃  
4. tier 一律由 score 重算后再进 UI  
5. 未知 `run_debt.service_id` → 保留原值并警告，避免吞债
