# 旗标与命名（总表）

> 所有 `flag_*` / `route_*` / `meter_*` / 常用 `stat_*` 登记于此。  
> **未登记不得在事件里新造**（设计期可先提案再写入本表）。

---

## 1. 前缀规则

| 前缀 | 用途 |
|---|---|
| `char_` | 人物 |
| `loc_` | 地点 |
| `org_` | 组织 |
| `stat_` | 主角（及全局）数值 |
| `act_` | 自由行动 |
| `clue_` | 线索 |
| `item_` | 信物/把柄 |
| `dialog_` | 对话节点 |
| `meter_` 或裸 meter id | 玩法计量（存档用短 id） |
| `flag_` | 布尔/过程旗 |
| `route_` | 路线相关旗 |
| `grudge_` | 恩怨账条目 |
| `E` `R` `F` | 事件 |

## 2. Meter（已用）

| id | 范围 | 初值 | 说明 |
|---|---|---|---|
| `father_son` | 0–100 | 55 | 钱德茂↔钱子安和睦 |
| `pursuit` | 0–100 | 0 | 柳↔子安追求/亲密 |
| `eval` | 0–100 | 30 | 白瑞德→钱德茂评估 |
| `impression_bradley` | 0–100 | 0 | 白→林（可与交情分双写） |
| `impression_qing` | 0–100 | 0 | 庆→林 |
| `liu_source_risk` | 0–100 | 0 | 枕边风暴露风险（E016B 等累加；高则易触发 F004） |

文档旧称 `impression_bradley_lin` / `impression_qing_lin` 与上表 **同义**；实现统一用短 id。

疑心边字段 `edge.suspicion`：**整数档 0=低 1=中 2=高 3=极高**。禁止写 `high`/`extreme` 字符串。
