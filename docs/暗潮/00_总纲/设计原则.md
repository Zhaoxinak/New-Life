# 设计原则 · P 社式数据层

> 目标：基础档案稳定；**时间流动**与**事件选择**都能改同一套数值；代码可直接映射。  
> **契约详文**：[`数据库架构.md`](数据库架构.md) · [`effect词汇表.md`](effect词汇表.md) · [`存档结构.md`](存档结构.md)

---

## 1. 三层模型

```
┌─────────────────────────────────────────┐
│  DEFINITION（文档档案）                    │
│  人物 / 建筑 / 组织 / 数值定义 / 关系模板     │
│  → 永不被运行时改写                         │
└──────────────────┬──────────────────────┘
                   │ new game 复制初值
                   ▼
┌─────────────────────────────────────────┐
│  STATE（存档）                             │
│  当前日/时段 · 各 stat · 关系分 · flags · 线索 │
└──────────────────┬──────────────────────┘
                   │ apply
                   ▼
┌─────────────────────────────────────────┐
│  EFFECTS（行动 / 事件 / tick）             │
│  只描述「对 STATE 做什么」                   │
└─────────────────────────────────────────┘
```

---

## 2. 数值谁改、何时改

| 来源 | 时机 | 典型效果 |
|---|---|---|
| **日 tick** | 每日结算（见 `04_数值定义/日tick.md`） | 打工收入、生活费、冷落衰减 |
| **时段 tick** | 进入某时段 / 选深夜行动 | 深夜必然嫌疑↑ |
| **自由行动** | 玩家选 ACT | 银钱、情报、交情分等区间变化 |
| **固定/条件事件** | 日程命中且条件满足 | 大额改写、解锁线索、路线旗标 |
| **关系触发** | 每时段末扫描阈值 | 告密、内斗、监视等派生事件 |

原则：**同一字段可被多种来源改**；冲突时按「事件 > 行动 > tick」叠乘或顺序结算（实现时统一 pipeline）。

## 3. Effect 书写约定（文档伪代码）

每个行动/事件选项末尾用统一块：

```yaml
effects:
  - { op: add, target: player, key: stat_trust_firm, value: 5 }
  - { op: add, edge: {from: char_liu_ruyan, to: char_lin_ruisheng}, key: score, value: 10 }
  - { op: add_range, target: player, key: stat_intel, min: 2, max: 5 }
  - { op: add, meter: father_son, value: -15 }
  - { op: set_flag, key: route_endure, value: true }
  - { op: unlock_clue, id: clue_suspicious_manifest }
```

可见提示（UI 文案）与 effect 分开写，避免策划改数值时漏改文案。

## 4. 条件写法

```yaml
trigger:
  day: 10
  slot: late_night
  location: loc_02
  require:
    - { key: stat_intel, op: ">=", value: 10 }
    - { clue: clue_suspicious_manifest, owned: true }

```

## 5. 可见 vs 隐藏

| 类型 | 玩家可见 | 例 |
|---|---|---|
| 主角五维 | 是（嫌疑可只显示档） | 金钱、情报、人脉、信任、嫌疑 |
| 交情档（任意人→你 / 你查出的边） | 是（档）；精确分可后解锁 | 仇隙…厚交 |
| 疑心精确值 | **否**（只感知行为） | 钱德茂疑心 |
| 社会纽带 | 已知则可见 | 父子、定亲、竞业 |
| 线索 | 情报簿可见 | 鸦片弧层层解锁 |
| 路线旗标 | 部分可见 | Day7 选择后有提示 |

## 6. 钱的原则

在《暗潮》里，钱不是纯购买力，而是三件事叠在一起：

1. **尊严**：有没有脸谈婚事、请客、穿得体面、像个快满师的人  
2. **门路**：能不能买消息、打点人、进票号、让人把你当回事  
3. **风险**：脏钱、回扣、账外银、封口费会更快推你跨线

因此，写金钱相关剧情时要遵守：

- 不把钱只写成“+5 / -3”的数值跳动
- 每一笔钱都尽量落到 **谁拿、谁失、谁被逼** 上
- 同一笔钱对不同身份的人，意义必须不同
- 小钱更伤体面，大钱更伤底线

示例：

- 林瑞生想升跑街，不只为脸面，也为月例和油水能把婚事往前推
- 柳如烟怕礼，不是贪，而是知道退礼可能连活路都得罪没了
- 钱子安盯住“三万两”，不是差这点花销，是父权和家产羞辱
- 白瑞德愿给分成，是因为他算得出你能替他省更多成本

## 8. 核心循环（勿改语义）

```
选时段行动 → 应用行动 effect → 扫关系阈值
  → 若有固定/条件事件则弹出 → 应用事件 effect
  → 推进目标/线索 → 下一时段（日末跑日 tick）
```
