# 人物档案 · 统一模板

> **每人一篇必须按此结构与字段行顺序。** 勿删行、勿换列名、勿跳节。  
> 新加角色：复制本文件 → 改文件名与 `id` → 填空。  
> 关系权威：[`../05_关系档案/`](../05_关系档案/README.md)（玩家与 NPC **同一套**）。

---

## 空值约定

| 写法 | 何时用 |
|---|---|
| `—` | 不适用 |
| `0` | 适用但开局为零 |
| `未知` | 待补 |
| `无` | 明确没有 |

数值列不留空白；文本没有内容时写 `—` 或 `无`。

---

## 标题格式

```
# 显示名 · `char_id`
```

首行引用：一句话定位（可含 Demo / 路线提示）。

## 2. 钱与生计

| 项 | 内容 |
|---|---|
| 财力层级 | 拮据 / 小康 / 殷实 / 豪阔 / 看不透 |
| 明面钱路 | 月例 / 工钱 / 分红 / 票号 / 洋行 / 外快 / `无` |
| 暗面钱路 | 抽头 / 回扣 / 走账 / 孝敬 / 受供养 / `无` |
| 花钱习惯 | 抠 / 体面 / 挥霍 / 舍得打点 / 只花刀口上 / `—` |
| 金钱软肋 | 婚事 / 孝养 / 赌债 / 面子 / 升职 / 赎身 / 抽成 / 上供 / `无` |
| 越线价码 | 一句概括：他通常会为了什么钱、在什么压力下越线；不明写 `未知` |

说明：
- **不要**把这一节写成 NPC 面板数值；重点是钱从哪来、往哪去、会逼他做什么。
- 若角色明面不缺钱，也要写清他在乎的是现金流、面子、分成，还是更大的钱路。
