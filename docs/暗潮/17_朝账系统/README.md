## 设计原则

1. **开局就要有**：Day 1 旁听，让玩家看见「跑街」终点。  
2. **低职级进不去堂**：学徒门外听；外场起列席汇报；跑街起可摊派。  
3. **不替代主线**：E004/E006/E020 等仍保留 ID 与恩怨/职级结算，改在朝账场次内演出。  
4. **日期不锁死**：朝账日 = `day % 7 == 1`（Day 1、8、15…）；剧情朝账用 `M*` 编号覆盖。  
5. **议场不是对话框**：朝账必须升起 `MeetingStage`（席位 + 分段仪式）；细则见 [`朝账议场演出合同.md`](朝账议场演出合同.md)。
