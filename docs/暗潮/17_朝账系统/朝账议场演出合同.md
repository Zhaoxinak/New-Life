# 朝账议场演出合同

> **表现层合同**：把「前堂朝账」从连续对话框升级为太阁式议场演出。  
> 模拟权威仍在 [`朝账系统规则.md`](朝账系统规则.md) / [`诸人建言.md`](诸人建言.md)；本文件只约束舞台、席位、分镜与 DomainBus。  
> 边界总则：[`../00_总纲/表现层边界.md`](../00_总纲/表现层边界.md)。

---

## 0. 诊断

| 太阁立志传2 年会体感 | 暗潮升级前 |
|---|---|
| 进入专用议场空间 | 日常 Hub + DialogueBox |
| 一眼看见谁坐哪、谁缺席 | 站位只写在旁白里 |
| 发言时全员在场、焦点转移 | 单人头像轮播 |
| 沉默也是戏 | 一句旁白翻过 |
| 开场→点名→赏罚→建言→主公决断 | 六段被压成同一种对话框 |

**结论**：不改玩法骨架，重做表现合同——玩家感到「进入了朝账」，而不是「又开始一段对话」。

---

## 1. 目标体验

每周晨会 =

**锁死前堂 → 升起议场幕 → 席位落座 → 按段换光与焦点 → 逐人畅言 → 东家落槌 → 差事飞入 HUD → 散场回自由行动**。

旁听学徒与列席外场看见的是**同一座议场的两种机位**（门外帘影 / 堂内全席），不是两套文案拼贴。

---

## 2. 架构：`MeetingStage`

对标 `CeremonyOverlay`：朝账 `M*` / 自动 `M000` 期间覆盖 Hub；**禁止**在舞台脚本里改 `run_*` 数值。

```
TickPipeline → DialogueRunner（仍播 def_dialog）
                    │
                    ├─ tags / dialog_id 启发段号
                    └─ node_presented → MeetingStage
MeetingSystem effects → DomainBus
  meeting_segment_changed
  council_turn_changed
  meeting_policy_resolved
  meeting_tasks_changed
  meeting_changed（结束时 Stage 降下）
```

| 层 | 职责 |
|---|---|
| 模拟 | `run_meeting`、`council_*`、`policy_draft`、`weekly_tasks` |
| 表现 | `MeetingStage`：SeatMap、段标、焦点、帘影、关键字高亮、任务飞入 |

地点 ID 仍为 `loc_01`（不新开地图点）。朝账开始时 Hub 冻结；`complete_meeting_cycle` / `dialog_finished` 后舞台降下。

## 3. 机位（同一 SeatMap）

| `attendance_tier` | 机位 | 看见什么 |
|---|---|---|
| `listen` | 门外帘影 | 剪影排位、模糊人声感；关键字高亮；点名自己时帘动 |
| `report` / `decide` | 堂内全席 | 清晰胸像、席位灯、发言高亮、沉默灰化 |

升职当周（如 M003）可在 ③ 段把玩家从「门外旁听位」动画挪到「柜前列席位」（站位即爽点，见 [`../13_职级档案/称呼与站位变化.md`](../13_职级档案/称呼与站位变化.md)）。

## 4. 席位图 SeatMap

数据：`packs/anchao/def_meeting_stage.json`（表现 def，非存档权威）。

```
        [东家座 seat_master]          ← 上首；④ 暗听 / ⑤ 落槌
   [跑街 seat_paojie] [周 seat_zhou] [子安 seat_zian]
   [王 seat_wang] [玩家 seat_player] [空/仇 seat_rival_0]
        ……门帘……
     [门外旁听 seat_listen]
```

| 槽位 id | 默认占席 | 规则 |
|---|---|---|
| `seat_master` | `char_qian_demao` | 恒在；不入 `council_queue` |
| `seat_paojie` | 空或现任跑街 | 有人则优先建言 |
| `seat_zhou` | `char_zhou_guanshi` | 可发言，不入序位池 |
| `seat_wang` | `char_wang_pangzi` | 前堂实情 |
| `seat_zian` | `char_qian_zian` | 仅 `flag_zian_arrived`；否则空席虚位 |
| `seat_player` | `char_lin_ruisheng` | `listen`→门外槽视觉；`report+`→堂内 |
| `seat_rival_0` | 可选竞争者 | 本局入 queue 才现身 |
| `seat_listen` | 玩家旁听投影 | 仅 listen 机位强调 |

**开场**：按 `seat_order` 依次亮席 → 东家最后 → 静场 → ① 段。缺席：空席 + 名牌划掉。

## 5. 六段分镜

每段切换：顶部段标、灯光重心变；**禁止**六段共用同一种「无舞台反馈」。

| 段 id | 名 | 舞台行为 |
|---|---|---|
| `rollcall` | ① 开门点名 | 席位灯逐个点亮；缺席划掉 |
| `report` | ② 分铺汇报 | 汇报者焦点；旁侧迷你序位条（绑 `run_ladder`） |
| `ceremony` | ③ 仪典升降 | 让位 `CeremonyOverlay`；回场后席位可重排 |
| `council` | ④ 诸人建言 | 畅言模式：queue 焦点环；沉默灰+「……」；截断全席一震 |
| `policy` | ⑤ 东家定调 | 熄他席，上首独亮；定调句居中；`policy_draft` 最高项文言短标 |
| `tasks` | ⑥ 摊派差事 | 任务卡从东家位飞入 HUD「本周差事」 |

段号来源（优先级）：

1. effect `set_meeting_segment` → DomainBus `meeting_segment_changed`
2. dialog 节点 `stage.segment` 或 tags：`seg_rollcall` … `seg_tasks`
3. `dialog_id` 启发：`rollcall` / `ladder|report` / `council` / `policy` / `task` / 升职相关 → ceremony

## 6. 畅言 UX（④）

```
[席位条：全员胸像；当前金框；已说过微暗；沉默灰+……]
[主舞台焦点：当前发言者放大]
[东家上首小窗常在；截断时放大]
[底部选项：仅轮到玩家 — 建言 / 不言 /（decide）附议]
```

- NPC 发言：焦点转移不可跳过（打字可加速）。
- 旁听：席位剪影；正文高亮「人名 + 开/默」与关键字（tag `keyword_highlight`）。
- 子安：略偏席、焦点多停半拍（表现层 timing）。

规则权威：[`诸人建言.md`](诸人建言.md)。

## 7. 数据契约

### 7.1 表现读的存档字段

| 字段 | 用途 |
|---|---|
| `attendance_tier` | 机位 |
| `council_queue` / `council_index` / `council_log` | 焦点与灰化 |
| `policy_draft` / `last_policy` | ⑤ 文言标 |
| `weekly_tasks` | ⑥ 飞入卡 |
| `run_ladder` | ② 旁侧条 |

### 7.2 DomainBus（表现订阅）

| event | payload | 触发 |
|---|---|---|
| `meeting_segment_changed` | `{ segment }` | `set_meeting_segment` |
| `council_turn_changed` | `{ char, index, queue }` | `init_council_queue` / `record_council_speech` |
| `meeting_policy_resolved` | `{ policy, player_stance }` | ⑤ 定调落槌 |
| `meeting_tasks_changed` | `{ count }` | ⑥ 飞入 |
| `meeting_changed` | 既有 | 升降幕 / 刷新席 |
| `ceremony_finished` | `{ mode, old_rank?, new_rank? }` | ③ 仪式结束 → 议场回光 / 升职挪席 |

### 7.3 Effect 增量

| op | 语义 |
|---|---|
| `set_meeting_segment` | `value`: `rollcall\|report\|ceremony\|council\|policy\|tasks`；只发 DomainBus，不改数值 |

### 7.4 对话文案规范

朝账节点**禁止用旁白代替站位**（「你站在门边」→ 机位表达）。旁白只写空气与反应。  
关键字：节点 `stage.keywords: [string]` 或 tag `keyword_highlight` 时用默认词表（跑街、满师、特别货、货单、聚丰…）。

## 8. 内容节奏

| 类型 | 演出预算 |
|---|---|
| M001 首听 | 满仪式：帘影 + 关键字 + 看见「跑街」终点 |
| M002 / M003 | 剧情钉：少爷入席、升职挪位 |
| M000 例行 | 短：落座压缩；②③ 有变才拉长；④ 2–4 人；⑤⑥ 快刀 |

例行可用「本周异常」驱动满席/简席（有升降 / 仇人入席 / 黑线词 → 满席）。

## 9. 声画

- 开场 SE：算盘连击 → 木门闩（`art/audio/meeting/open.wav`）；BGM 慢板 loop。
- 点名：席位亮起配 `seat.wav`。
- ⑤ 定调：`gavel.wav` + BGM 短暂压低。
- 截断：`cut.wav` + 全席一震。
- 席位角标：言 / 默 / 偏（子安）/ 断（东家）——无立绘差分时的表情合同。
- 文案：禁系统腔；截断「够了。」；排名用看客反应。
- 账簿：`LedgerOverlay`「朝账」页读 `last_summary_key` / `last_policy` / `weekly_tasks`；`complete_meeting_cycle` 写入 `history.kind=meeting`。

## 11. 明确不做什么

- 不新开 `loc_*`
- 不把建言改成自由输入或战棋议事
- 不在 Stage 内写 trust / suspicion
- 不一次重写全部 M001–M003 文案；先舞台 + 启发段号，再按需补 `stage` cues
