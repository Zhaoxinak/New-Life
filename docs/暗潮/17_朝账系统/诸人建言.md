# 诸人建言

> **太阁式环节**：奖惩（③）之后、东家定调（⑤）之前，有资格者**逐人发言或保持沉默**。  
> 规则总览：[`朝账系统规则.md`](朝账系统规则.md) · 实例台词池：[`../11_对话档案/DIALOG_MEETING_COUNCIL.md`](../11_对话档案/DIALOG_MEETING_COUNCIL.md)

---

## 1. 在六段式中的位置

```
① 开门点名
② 分铺汇报
③ 仪典升降
④ 诸人建言   ← 本文件
⑤ 东家定调   （吸收或驳回建言后拍板）
⑥ 摊派差事
```

钱德茂在 ④ 段**只听不说**；定调权仍在 ⑤ 段。  
玩家体感：先听一圈人心，再听东家一句话定乾坤——和太阁年会「家臣进言 → 主公决断」同构。

---

## 2. 建议权 `council_eligible`

不是谁都能开口。按**堂内席位 + 职级 + 剧情旗标**决定本局 `council_queue`：

| 角色 | 默认建议权 | 说明 |
|---|---|---|
| `char_qian_demao` | **否** | 听者；⑤ 段定调 |
| 现任跑街（NPC） | 是 | 若有；汇报后优先发言 |
| `char_zhou_guanshi` | 是 | 管事；**核心层**，朝账可发言但不入池排名 |
| `char_wang_pangzi` | 是 | 老伙计；前堂实情；**非池内对手** |
| `char_qian_zian` | 条件 | `flag_zian_arrived` 后；跑街池对手，常乱开口 |
| **池内竞争者** | 条件 | 孙六/赵外场等；④ 段可踩玩家，见 [`../13_职级档案/各职级竞争者.md`](../13_职级档案/各职级竞争者.md) |
| 玩家 | 条件 | 见 §4 |
| 账房（未具名 NPC） | 例行朝账 | 只报数，少谈方针 |

**旁听期**（`attendance_tier: listen`）：不进入 queue，但在门外听到**谁在说话 / 谁沉默**的碎片。

## 3. 发言顺序

发言顺序（例行）：

```
周管事 → 王胖子 → 钱子安(若在) → 仇人(序位紧逼时) → 玩家(若有建议权)
```

仇人由 `MeetingSystem.primary_rival()` / `pick_meeting_rival()` 决定（同池取分差最近者：学徒小陈/孙六，外场李/赵，跑街子安）。

规则：

1. ③ 段刚被奖惩者**不强制**置末，但发言口气会受影响（被贬者易沉默，被抬者易多言）。  
2. 同一角色**每朝账最多发言一次**（附议见 §5）。  
3. 东家可在 ④ 段中**截断**过长发言：「够了。」→ 该角色本回合结束。

## 4. 玩家参与

| tier | ④ 段行为 |
|---|---|
| `listen` | 不入场；旁听「有人建言 / 有人不语」关键字 |
| `report` | 若在本局 `council_queue` 中，轮到时二选一：**建言** / **不言** |
| `decide` | 同上，且可 **附议** 上一发言者（不另起新话题） |

### 4.1 轮到自己

```yaml
choices:
  - id: council_speak
    label: 建言
    next: dialog_meeting_council_player_pick  # 选话题/口径
  - id: council_silent
    label: 不言
    next: dialog_meeting_council_player_pass
```

### 4.2 建言口径（示例）

| 选项 | 倾向 tag | 典型后果 |
|---|---|---|
| 稳明面、紧货单 | `policy_bright_steady` | 信任+；嫌疑− |
| 盯聚丰压价 | `policy_market_watch` | 情报+；子安/东家反应视路线 |
| 少问后院 | `policy_look_away` | 信任短期+；错过黑线情报 |
| 直报货单异常 | `policy_manifest_risk` | 需 `stat_intel`；易引 suspicion |

选「不言」：**不扣信任**，但错过一次影响 ⑤ 定调的窗口；周管事可能记「不敢说话」。

## 5. NPC：发言 vs 沉默

每个 NPC 轮到时的决策（表驱动 + 条件权重）：

```
若 roll < speak_weight → 发言（抽一条 council_line）
否则 → 沉默（播一句「某某不语」或跳过）
```

| 角色 | 基础 speak_weight | 升高 | 降低 |
|---|---|---|---|
| 周管事 | 85 | 嫌疑高、后院出事 | 庆系差事敏感周 |
| 王胖子 | 70 | `support_low` 高 | 被③段批评后 |
| 钱子安 | 60 | 刚被抬/要表现 | 刚被东家怼 |
| 玩家 | 100（若入队） | — | — |

### 附议（`decide` 专属）

上一发言者**开过口**后，玩家轮到时可三选一：

| 选项 | 节点 | effect |
|---|---|---|
| 建言 | → topic 口径 | 自起 stance |
| **附议刚才那句** | `dialog_meeting_council_endorse` | `endorse_last_council`：加强上一 stance×2，trust+1 |
| 不言 | `dialog_meeting_council_player_pass` | pass |

条件：`meeting_tier: decide` + `council_last_spoke: true`（上一有效发言存在）。  
附议不另起 topic；若上一是仇人踩线口径，附议等于站队——有爽也有险。

### 简席压缩（例行）

`council_brief: true`（queue 无子安/仇人）时：

- 周/王只走默认口径，不抽变体  
- 旁听走 `dialog_m000_council_listen_brief` 一句过门 → 定调

## 6. 建言如何影响 ⑤ 定调

④ 段不直接改 `run_org` 或大范围 stat，只写 **`policy_draft`**：

```yaml
run_meeting:
  policy_draft:
    bright_steady: 2      # 稳明面积分
    market_watch: 1
    manifest_risk: 0
    son_first: 3          # M002 周子安线权重高
    foreign_caution: 0
```

⑤ 段东家定调时：

1. 取 `policy_draft` **最高项**作主口径；  
2. 若玩家本局建言与最高项一致 → 额外 `stat_trust_firm +2`（「跟对了东家心思」）；  
3. 若玩家直触黑线而东家驳回 → 定调仍保守，但 `stat_suspicion +5`（「你知道太多了」）。

**剧情朝账（M001–M003）**可写死 queue 与台词，不必完全走表；例行朝账走 [`DIALOG_MEETING_COUNCIL.md`](../11_对话档案/DIALOG_MEETING_COUNCIL.md) 池。

## 7. 存档字段

```yaml
run_meeting:
  council_queue: [char_zhou_guanshi, char_wang_pangzi, char_lin_ruisheng]
  council_index: 0
  council_log:
    - char: char_wang_pangzi
      spoke: true
      topic_key: council.wang.front_busy
      stance: bright_steady
    - char: char_lin_ruisheng
      spoke: false
  policy_draft:
    bright_steady: 1
```

朝账结束时清空 `council_*` 与 `policy_draft`（或归档进 `last_summary_key`）。

## 9. 演出合同

权威分镜：[`朝账议场演出合同.md`](朝账议场演出合同.md) §6 畅言 UX。摘要：

- UI：堂内**发言者高亮**，沉默者头像灰化或显示「……」；全员席位条常在  
- 旁听：仅高亮 **人名 + 动/静**（「周管事开口了」「王胖子没作声」）  
- 单条建言 **宜短**（1–3 句）；太长由东家截断  
- 子安建言宜**蠢或偏**，给玩家「这人也配说话」的恨意
