## 设计原则

1. **爽感必须有前债**：没被踩过，后面翻盘就不够爽。  
2. **清算必须改局**：不能只嘴上赢，必须让关系、位子、钱路或舆论发生变化。  
3. **惩罚和宽恕都要爽**：  
   - 惩罚爽在反打、夺脸、夺势  
   - 宽恕爽在你有能力下手，却偏偏收手  
4. **爽点分阶段**：不是只在章终爽，章二就要开始给“抬位后的第一次还手”。
