# 清算双极

> 《暗潮》的清算戏默认走两极：**惩罚** / **宽恕**。  
> 两边都必须爽，而且是**不同性质的爽**。  
> 若要先看主角在什么位子上才有资格做这种清算，见 [`../13_职级档案/职级玩法导航图.md`](../13_职级档案/职级玩法导航图.md)。

---

## 1. 惩罚

### 爽点来源

- 把当初压你的人当场掀翻
- 夺他的脸
- 夺他的话头
- 夺他的位子或手里的路

### 常见后果

- 看客改口
- 仇人失态
- 分利裂开
- 婚事主动权夺回
- 新位子被当众坐实

### 适用对象

- 钱子安
- 跟风看客
- 势利中层
- 拿你当耗材的旧东家

---

## 2. 宽恕

### 爽点来源

- 你能下手，但你收了手
- 不是你做不到，是你不屑全做绝
- 爽不在“原谅”，爽在“我现在有资格不必赶尽杀绝”

### 常见后果

- 对方欠你一手
- 旁人看出你分寸比对方高
- 舆论更容易站你
- 后续可留 leverage、债、把柄

### 宽恕不是

- 心软
- 圣母
- 无代价放过

---

## 3. 两极怎么选

| 情况 | 更适合惩罚 | 更适合宽恕 |
|---|---|---|
| 对方曾当众踩你 | 是 | 也可，但要强调你是“压着放” |
| 你需要立威 | 是 | 否 |
| 你需要收人心 | 视对象而定 | 是 |
| 对方以后还能当工具人 | 视格局而定 | 是 |
| 这场是大结算 | 更常见 | 可作为高级爽点 |

---

## 4. 三条线的清算味道

| 路线 | 惩罚味道 | 宽恕味道 |
|---|---|---|
| A 隐忍 | 前堂掀脸、账面反压 | 接权不撕破，留着旧东家欠你 |
| B 跳槽 | 截胡、带走客户、市场打脸 | 给台阶，但让所有人知道是你给的 |
| C 洋人 | 借势压场、权谋反打 | 亮势收刀，让人知道你背后站着别的世界 |
