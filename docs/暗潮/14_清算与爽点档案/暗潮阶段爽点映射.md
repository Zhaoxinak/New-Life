# 暗潮阶段爽点映射

> 本文件是《暗潮》本体的**阶段爽点挂点权威**。  
> 抽象规则见 [`爽点结构原则.md`](爽点结构原则.md)。  
> 并读职级推进：[`../13_职级档案/暗潮职级推进映射.md`](../13_职级档案/暗潮职级推进映射.md)。

> 《暗潮》要做的是：**先憋、再抬、再试、再爆。** 爽点不是结局前一次性发完。

---

## 1. 章一 · 被踩

### 目标

- 让玩家知道自己原本想要什么
- 再让他知道这些东西怎么被夺走

### 爽点类型

- 不是“爽”，而是**爽前的痛**
- 痛得越具体，后面越好还

### 核心任务 / 应给玩家什么

- 满师愿望
- 婚事期待
- 工钱与体面压力
- 第一次被轻慢、被搁置、被压婚事
- 埋下具体羞辱债

### 代表挂点

| 节点 | 爽/痛 | 说明 |
|---|---|---|
| E001–E002 | 温 | 满师希望、婚事压力 |
| E004–E006 | 痛·埋债 | 子安轻慢、搁置升职 → `grudge_*` |
| E008 | 痛·主债 | 盯如烟 → `grudge_zian_fiancee` |
| E009 | **立誓爽** | 决心落地；给出「下一阶小目标」提示 |
| `R010` | 痛·看客债 | 为章二轻清算铺料 |

---

## 2. 章二 · 摸刀

### 目标

- 让玩家第一次尝到“我开始有资格反一下手”

### 爽点类型

- 情报爽 · 升位爽 · 轻清算爽

### 核心任务 / 应给玩家什么

- 知道别人不知道的事
- 第一次正式位子变化
- 第一次让看客闭嘴 / 第一次清算资格

### 代表挂点

| 节点 | 爽点类型 | 说明 |
|---|---|---|
| E010–E013 | 情报爽 | 发现弧 |
| E019 | 情报爽 | 用情报当面压人一次 |
| E020* | **职级爽** | 升外场 / 报价 / 门路；仪式四件套 |
| E021* | **清算爽（轻）** | 看客或轻量子安；罚/恕 |
| 自由日 | 经营爽 | 人脉/支持/信用铺路 |

---

## 3. 章三 · 翻盘

### 目标

- 把之前的位子、人脉、情报、门路，真正转成压人的资格

### 爽点类型

- 阴谋爽 · 主清算爽 · 章终身份落点爽

### 核心任务 / 应给玩家什么

- 当众把仇人压下去
- 把婚事主动权夺回来
- 让新身份被当众钉死

### 代表挂点

| 节点 | 爽点类型 | 说明 |
|---|---|---|
| E014–E016 | 阴谋爽 | 鲁莽、挑拨 → 可见权力位移 |
| E015 | 认知爽 | 鸦片真相抬高赌注 |
| E022* | **清算爽（主）** | 子安婚事债；罚/恕必选 |
| E018* | **职级爽（大）** | 跑街 / 聚丰 / 代理任命 + 未兑现恩怨结算提示 |
| 后堂旁白 | 钩子 | `player_rank → houtang` 预告或软解锁 |

## 4. 三线重心

| 路线 | 章二最该爽什么 | 章三最该爽什么 |
|---|---|---|
| A 隐忍 | 升外场、轻清算 | 跑街任命、账权入口 |
| B 跳槽 | 被报价、街市改口 | 截胡打脸、外部位子坐实 |
| C 洋人 | 门路确认、借势轻压 | 代理身份成立、长期绑定 |

B/C 对位细节见 [`../10_路线与结局/BC路线爽点映射.md`](../10_路线与结局/BC路线爽点映射.md)。

---

## 5. 结构原则（写章时）

1. **章一不给太多爽**，主要存债  
2. **章二一定要给第一次还手**  
3. **章三一定要给大清算和新身份钉死**  
4. 爽点必须和：职级/位子 · 钱路 · 看客反应 · 仇人失态 —— 至少挂上两项
