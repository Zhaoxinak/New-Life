# 职级系统规则

> 本文件只定义“职级 / 位子 / 身份”作为系统如何工作，不绑定《暗潮》具体事件号。  
> 《暗潮》本体映射见 [`暗潮职级推进映射.md`](暗潮职级推进映射.md)。

---

## 1. 职级系统要解决什么

职级不是单纯加头衔，而是同时决定：

- 别人怎么称呼你
- 你能接触什么权力
- 你能碰到什么钱路
- 你有没有资格进行某类清算

---

## 2. 两类上位

### 内部职级

- 进入 `player_rank`
- 用于组织内部升迁
- 体现明面位次、权限与职责

### 外部位子 / 代理身份

- 不一定改 `player_rank`
- 可用独立旗标或身份记录
- 体现跳槽、挂靠、代理、被报价、被纳入门路

---

## 3. 职级系统最少要回答

1. 这是内部升迁还是外部位子  
2. 位子变化后，别人怎么改口  
3. 位子变化后，主角能接触什么新钱路  
4. 位子变化后，能不能立刻转成一次还手资格  

---

## 4. 职级系统负责什么

- 定义术语
- 定义内部职级与外部位子的边界
- 定义称呼、权限、钱路、清算资格之间的关系

职级系统不负责：

- 某个战役里第几章第一次升外场
- 某个角色在哪个场景里第一次改口
- 某条路线的任命仪式具体怎么写

这些属于战役实例层。

---

## 5. 推荐的推进节奏

职级相关内容一般至少包含四步：

1. 埋升职欲望  
2. 抬位子  
3. 坐稳位子  
4. 身份定局  

如果只给最后任命、不提前埋欲望，升职爽会变薄。  

---

## 6. 成功标准

- 玩家感受到的不是数字提升，而是位子、称呼、权限、钱路同时变化。  
- 未来新增战役可以复用同一套“内部职级 / 外部位子”边界，而不依赖钱记本身。
