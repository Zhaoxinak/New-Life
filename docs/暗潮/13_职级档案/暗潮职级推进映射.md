## 2. A 线：钱记内部爬升

| 节点 | 职级意义 | 玩家体感 |
|---|---|---|
| `M001` 首次旁听 | 看见跑街终点 + **学徒序 2/5** | 盼 |
| `M002`+`E006` 搁置 | 池内第二、子安第一；满师被划掉 | 痛 |

| `E022` 清算子安 | 位子开始转化成压人的资格 | 清算爽 |
| `E018A` 跑街任命 | 内部职级真正坐实 | 章终大爽 |

## 5. 三种“升上去”的区别

| 路线 | 你升的是什么 |
|---|---|
| A | 商行内部正式职级 |
| B | 市场给你的价和外部跑街位子 |
| C | 洋行把你纳入长期调用的代理身份 |

所以《暗潮》的“晋升”不是单一官阶树，而是三种不同的上位方式。

## 6. 做事件时怎么用

如果某个事件被认定为“职级相关事件”，至少回答：

1. 这是在**埋升职欲望**、**抬位子**、还是**坐稳位子**？  
2. 这次变化，别人怎么叫你？  
3. 这次变化，让你能碰到什么新钱路？  
4. 这次变化，能不能立刻转成一次清算资格？
