## 设计原则

1. **职级不只写名字**：必须同时写称呼、权限、活钱口径、可清算窗口。  
2. **内部职级** 与 **外部位子** 分开：  
   - 钱记内部升迁进 `player_rank`
   - 跳槽 / 洋行身份用独立旗标记录
3. **路线爽点不等于职级本身**：路线文档写的是“怎么爽”，本目录写的是“你升成了什么”。  
4. **规则词固定**：涉及术语统一时，以 [`职级术语表.md`](职级术语表.md) 为准。  
5. **明面序位战** 与 **核心入局** 分轨：朝账只服务前者，见 [`核心层与入局捷径.md`](核心层与入局捷径.md)。
