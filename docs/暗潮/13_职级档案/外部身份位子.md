# 外部身份位子

> 本文件处理**不属于钱记内部编制**、但对主角地位有同等甚至更强影响的“位子”。  
> 它们不是 `player_rank` 的替代，而是路线分化后的**身份落点**。  
> 若要看这些外部位子对应什么钱路，见 [`各职级可接触的钱路.md`](各职级可接触的钱路.md)。
> 用词统一见 [`职级术语表.md`](职级术语表.md)。

---

## 1. 为什么单独列

A 线的爽是“在钱记里升上去”。  
B / C 线的爽不是升同一把梯子，而是**跳到另一张桌子上**。

所以要分开记录：

- **内部职级**：`player_rank`
- **外部位子**：独立旗标

---

## 2. B 线 · 聚丰跑街

| 项 | 内容 |
|---|---|
| 身份旗标 | `flag_rank_jufeng_paojie` |
| 获得时机 | `E018B` |
| 本质 | 竞品正式给位子 |
| 体感 | 不是“终于被东家看见”，而是“别人愿意花钱请你” |
| 钱口径 | 月薪五两、启动甜头、截胡第一单 |
| 爽点关键词 | 报价、跳槽、抬价、市场位子 |

### 与钱记内部职级的关系

- 可先在钱记内达到 `waichang`
- 但章终真正落点不是钱记 `paojie`
- 因此**不覆盖** `player_rank` 历史，只另外记旗

---

## 3. C 线 · 宝顺天津代理

| 项 | 内容 |
|---|---|
| 身份旗标 | `flag_rank_foreign_agent` |
| 获得时机 | `E018C` |
| 本质 | 洋行把你纳入长期合作关系 |
| 体感 | 不是升职，是“被抬进另一套权力网络” |
| 钱口径 | 第一次分成落袋 + 后续抽头 / 佣金资格 |
| 爽点关键词 | 门路、价码、代理、绑定 |

### 与钱记内部职级的关系

- 可先在钱记内达到 `waichang`
- 但章终不要求钱记 `paojie`
- 你拿到的是**天津代理人**，不是东家内部的正式跑街

---

## 4. 三条路线的身份落点对照

| 路线 | 最终身份落点 | 记录方式 |
|---|---|---|
| A 隐忍 | 钱记跑街 | `player_rank = paojie` |
| B 跳槽 | 聚丰跑街 | `flag_rank_jufeng_paojie` |
| C 洋人 | 宝顺天津代理 | `flag_rank_foreign_agent` |

这三者都属于“主角升上去了”，但**升的不是同一把梯子**。

若要继续看这些位子分别由哪些事件钉死，见 [`职级玩法导航图.md`](职级玩法导航图.md)。
