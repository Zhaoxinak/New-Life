## 2. 每阶四件套

| 阶 | 称呼变化 | 权限变化 | 活钱变化 | 清算窗口 |
|---|---|---|---|---|
| 学徒 | 瑞生 / 林师弟 | 前堂杂务 | 碎银、跑腿赏钱 | 埋债期 |
| 外场 | 林外场 | 独立跑差、部分货单经手 | 月例微涨、差事赏钱更稳 | E021* |
| 跑街 | 林跑街 | 街面代表商行、应酬账可报 | 月例更厚、体面更足 | E022 / E018A |
| 后堂 | 林先生 / 林管事（可选） | 后堂、密账、暗线边缘 | 不一定现银更多，但钱路更深 | 正式版大清算 |

## 3. 升阶门槛（现行）

### 学徒 → 外场

| 条件 | 口径 |
|---|---|
| `stat_trust_firm >= 45` | 东家至少肯把你推到人前 |
| `stat_intel >= 20` | 不是只会卖力气，得会看货、看人、看话头 |
| 非 `flag_demoted` / `flag_fired` | 没被踩出局 |
| 对应事件 | `E020` / `E020B` / `E020C` 三选一 |

### 外场 → 跑街

| 条件 | 口径 |
|---|---|
| `stat_trust_firm >= 50` | 商行信任到位 |
| A 线通常还要 `father_son` 压低、情报够深 | 不是熬够日子，而是能顶住事 |
| 对应事件 | `E018A` |

### 跑街 → 后堂

| 条件 | 口径 |
|---|---|
| 现阶段未正式开放 | 章终只开门缝 |
| 软落点 | `flag_houtang_door_ajar` |

## 4. 为什么要单独抽出来

因为《暗潮》的爽点不只在“复仇成功”，还在**位子一层层变厚**：

1. 别人怎么叫你变了  
2. 你能进的屋变了  
3. 你手里能过的钱变了  
4. 你清算别人的资格变了  

如果不把职级单独列出来，这四层很容易被路线文档吞掉。
