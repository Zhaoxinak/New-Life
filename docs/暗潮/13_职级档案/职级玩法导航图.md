# 职级玩法导航图

> 这份文件回答的不是“你是什么职级”，而是：  
> **你靠哪些事件升上去、靠哪些事件证明自己、靠哪些事件把位子坐稳。**  
> 本文件现在偏向《暗潮》本体实例图；若看抽象规则，先读 [`职级系统规则.md`](职级系统规则.md)，若看新的本体映射入口，见 [`暗潮职级推进映射.md`](暗潮职级推进映射.md)。  
> 如果要先看位次定义本身，见 [`职级阶梯.md`](职级阶梯.md)。
> 用词统一见 [`职级术语表.md`](职级术语表.md)。
> 若要把“怎么爬”与“怎么清算、怎么爽”并读，见 [`../14_清算与爽点档案/阶段爽点结构.md`](../14_清算与爽点档案/阶段爽点结构.md)。

## 1. 职级推进总图

| 阶段 | 核心问题 | 关键事件 | 作用 |
|---|---|---|---|
| 学徒期 | 你为什么想升 | `E002` / `E006` / `E008` | 把升职与婚事、体面、活路绑死 |
| 埋债期 | 你为什么必须往上爬 | `E004` / `R003` / `R010` | 羞辱记账；没有位子就没有还手资格 |
| 试位期 | 你配不配从“使唤的人”变成“办事的人” | `E019` / `E020*` | 信息优势 + 第一次位子变化 |
| 坐稳期 | 新位子有没有真分量 | `E021*` | 轻清算，验证新称呼不是空壳 |
| 抬价期 | 你在别人的体系里值多少钱 | `E020B` / `E020C` | B/C 线把“升职”改写成“被报价 / 被纳入门路” |
| 定局期 | 你最终坐哪张桌子 | `E022*` / `E018*` | 主清算 + 章终身份钉死 |

## 2. A 线：钱记内部爬升

| 节点 | 职级意义 | 玩家体感 |
|---|---|---|
| `E006` 升职搁置 | 让“跑街”从抽象愿望变成被夺走的位子 | 痛 |
| `E019` 密账一用 | 证明你不只是卖力气，也会用脑子 | 情报爽 |
| `E020` 升任外场 | 第一次正式抬位 | 升职爽 |
| `E021` 轻清算 | 验证“林外场”有没有真分量 | 小反转爽 |
| `E022` 清算子安 | 位子开始转化成压人的资格 | 清算爽 |
| `E018A` 跑街任命 | 内部职级真正坐实 | 章终大爽 |

---

## 5. 三种“升上去”的区别

| 路线 | 你升的是什么 |
|---|---|
| A | 商行内部正式职级 |
| B | 市场给你的价和外部跑街位子 |
| C | 洋行把你纳入长期调用的代理身份 |

所以《暗潮》的“晋升”不是单一官阶树，而是三种不同的上位方式。

---

## 6. 做事件时怎么用

如果某个事件被认定为“职级相关事件”，至少回答：

1. 这是在**埋升职欲望**、**抬位子**、还是**坐稳位子**？  
2. 这次变化，别人怎么叫你？  
3. 这次变化，让你能碰到什么新钱路？  
4. 这次变化，能不能立刻转成一次清算资格？
