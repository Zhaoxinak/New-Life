# 职级竞争与排名

> **明面升迁 = 同池排位 + 朝账兑现**；**核心层 ≠ 朝账排队**。  
> 竞争者名册：[`各职级竞争者.md`](各职级竞争者.md) · 核心入局：[`核心层与入局捷径.md`](核心层与入局捷径.md) · 朝账：[`../17_朝账系统/朝账系统规则.md`](../17_朝账系统/朝账系统规则.md)

---

## 1. 设计目标

| 目标 | 做法 |
|---|---|
| 开局就有追赶感 | 学徒池人多、活简单，HUD 实时见名次 |
| 越升越难 | 池子变小、单项分值权重变刁、对手会搞你 |
| 与朝账咬合 | 每周 `report_score` 汇入池内排位；③ 段按序升降 |
| 与剧本咬合 | 子安是跑街级对手；后堂靠密账/庆系/父子局，不靠排队 |
| Hub 一眼读懂 | 常驻芯片：`{池名} {名次}/{人数}` + 距朝账 |

---

## 2. 双层结构

```
┌─────────────────────────────────────────┐
│  核心层（后堂 / 暗账 / 庆系接引）          │  ← 朝账进不去；特殊入局
│  钱德茂 · 周管事 · 账房 · 已坐稳的自己人   │
├─────────────────────────────────────────┤
│  明面晋升轨（前堂朝账序位战）              │  ← 学徒→外场→跑街
│  每周汇报分 → 池内排名 → 朝账③升降        │
├─────────────────────────────────────────┤
│  外场 / 街面（B·C 外部位子另轨）           │  ← 聚丰报价、洋行门路
└─────────────────────────────────────────┘
```

**铁律：** `player_rank` 升到 `paojie` 仍不等于核心层；`houtang` / 暗账经手权只走 [`核心层与入局捷径.md`](核心层与入局捷径.md)。

## 3. 晋升池 `ladder_pool`

每阶只争**下一阶的空额**，不跨阶混排。

| 当前职级 | 池 ID | 人数 | 朝账周期腾位 | 工作难度 | 主要记分行动 |
|---|---|---|---|---|---|
| `apprentice` | `pool_apprentice` | **5** | 0–1 个外场 | 低 | `act_01`、整理货单、值更、准时差事 |
| `waichang` | `pool_waichang` | **3** | 0–1 个跑街预备 | 中 | 街面差事、情报、信任、应酬不出丑 |
| `paojie` | `pool_paojie` | **2** | 跑街正式位（剧情锁） | 高 | 业绩 + 政治 + 父子/洋人局 |
| `houtang` | — | — | 不池化 | 极高 | 非朝账赛道 |

### 3.1 难度曲线

| 维度 | 学徒池 | 外场池 | 跑街池 |
|---|---|---|---|
| 竞争者数 | 多（5） | 中（3） | 少（2） |
| 单项分值 | 低（+3～8/次） | 中（+5～15） | 高（+10～25，但易翻车扣分） |
| NPC 周增长 | 慢、波动小 | 中 | 快；子安有「少爷加成」 |
| 失误惩罚 | 小 | 中（嫌疑、信任） | 大（可触发 F002 / 搁置） |
| 玩家策略 | 刷简单活、堆勤恳 | 平衡信任与情报 | 路线抉择 + 清算窗 |

## 4. 存档 `run_ladder`

```yaml
run_ladder:
  pool_id: pool_apprentice      # 当前所在晋升池
  cycle_week: 1                 # 本池第几周（换池重置）
  promotion_slots: 1            # 本朝账周期可腾位数量（可被剧情改）
  entries:
    - char_id: char_lin_ruisheng
      score: 42
      is_player: true
      trend: 1                  # -1 跌 / 0 平 / 1 升（HUD 箭头）
    - char_id: char_apprentice_xiao_liu
      score: 38
      is_player: false
      trend: 0
    # …
  player_rank: 2                # 缓存名次；score 变时重算
  player_total: 5
  last_delta: 1                 # 较昨日名次变化（Hub ↑↓）
```

换 `player_rank`（`set_rank`）时：**换池、清空 entries、重生成竞争者名册**。

## 5. 分数来源

### 5.1 玩家

| 来源 | 汇入 |
|---|---|
| 本周 `meeting_report_score` | 朝账前夜一次性 +50% 权重入池 |
| 完成 `weekly_tasks` | 按 `weight` 入池 |
| 行动 tick | 见 [`汇报分与周差事.md`](../17_朝账系统/汇报分与周差事.md) 各池权重表 |
| 剧情事件 | E001 考校 +8、E006 搁置 −20 等 |

### 5.2 NPC（周模拟 `on_ladder_weekly`）

朝账前夜对每个 `entries`（非玩家）：

```
npc_score += base_growth[char] + noise + story_bias
```

| 角色 | 学徒池 bias | 说明 |
|---|---|---|
| 小刘 | 偷懒，波动大 | 有时超玩家，有时垫底 |
| 小陈 | 勤恳稳定 | 中期劲敌 |
| 阿福 | 平庸 | 陪跑 |
| 孙六 | 会拍马 | 朝账前易突然蹿升 |
| 李外场 | 外场池实干 | 稳 |
| 赵外场 | 外场池媚上 | 信任高时猛涨 |
| 钱子安 | 跑街池 | **少爷加成** + 剧情锁：M002 前常压玩家 |

## 6. 与朝账六段式

| 段 | 排名作用 |
|---|---|
| ② 分铺汇报 | 堂内报「{池名}本周序：林瑞生第二，小陈第一」 |
| ③ 仪典升降 | **仅池内前 `promotion_slots` 名**可升；末位可警告/降杂役(F002) |
| ④ 诸人建言 | 竞争者可口头踩你、附议别人方案 |
| ⑤ 定调 | 不直接改排名；但方针影响下周行动权重 |

**旁听期**：门外听见名次，看不见全表——HUD 仍给玩家完整排名（「你数得清，他们当你数不清」）。

## 7. Hub 实时排名（表现层合同）

见 [`../00_总纲/表现层边界.md`](../00_总纲/表现层边界.md) §6。

常驻芯片示例：

```
学徒序 2/5 ↑1    距朝账 3日
```

| 字段 | 绑定 |
|---|---|
| 池名 | `pool_id` → loc_key |
| 名次/总人数 | `player_rank` / `len(entries)` |
| 箭头 | `last_delta` |
| 距朝账 | `run_meeting.days_until_next` |

点击展开：**迷你排行榜**（前五名 score 条 + 竞争者头像/称呼）。  
名次变化时 DomainBus `ladder_rank_changed` → 短 tip + 可选 SE。
