# 职级术语表

> 本表用于统一《暗潮》里与晋升相关的固定用词。  
> 原则：**同一个意思尽量只保留一个主词**，其他词作叙事修辞，不作规则词。

---

## 1. 核心词优先级

| 词 | 用途 | 是否规则词 | 备注 |
|---|---|---|---|
| **职级** | 钱记内部的正式晋升层级 | 是 | 对应 `player_rank` |
| **位子** | 更口语、更有戏的说法 | 否（默认） | 可泛指内部职级或外部身份 |
| **身份** | 更宽泛的社会/组织定位 | 否（默认） | 常用于 B/C 线 |
| **外部位子** | 不属于钱记内部编制的落点 | 是（目录术语） | 用于 B/C 线说明 |
| **代理身份** | C 线的具体外部身份 | 是（具体项） | 对应 `flag_rank_foreign_agent` |

---

## 2. 现行统一规则

### 2.1 内部晋升

- 一律优先用 **职级**
- 写具体层时用：
  - 学徒
  - 外场
  - 跑街
  - 后堂看账

标准句式：

- `player_rank` 由学徒升到外场
- 主角的内部职级提升为跑街

不推荐作规则词：

- 官阶
- 岗级
- 编制层级

---

### 2.2 外部上位

- B / C 线不叫“内部职级”
- 优先写 **外部位子** 或 **身份落点**

标准句式：

- B 线的外部位子是聚丰跑街
- C 线的身份落点是宝顺天津代理

---

### 2.3 叙事表达

在对白、旁白、人物心态里，可以自由用这些词增强戏感：

- 位子
- 脸面
- 身份
- 站位
- 抬头说话
- 上桌

但写规则、门槛、索引时，尽量回到统一词：

- **职级**
- **外部位子**
- **身份落点**

---

## 3. 术语映射

| 旧/散用词 | 现行建议 |
|---|---|
| 升跑街 | 升到跑街职级 / 拿到跑街位子（叙事可保留） |
| 位子变了 | 叙事可保留；规则层请写职级变化或身份落点变化 |
| 外部身份 | 可保留；正式说明优先写外部位子 |
| 代理人 | C 线具体身份，可保留 |
| 新东家给位子 | B 线外部位子成立 |

---

## 4. 文档写法建议

### 规则文档

优先用：

- 职级
- 外部位子
- 身份落点
- `player_rank`
- `flag_rank_*`

### 路线文档

可混用：

- 位子
- 身份
- 抬价
- 上桌

但至少第一次出现时，要能回指到具体规则词。

### 对话文档

不要求统一死板。  
对白优先自然；术语统一主要约束说明文档与规则文档。
