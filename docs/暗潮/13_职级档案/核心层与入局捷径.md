# 核心层与入局捷径

> **前堂朝账只能爬到跑街门前；后堂 / 暗账 / 庆系核心，没有排队号码。**  
> 明面池规则：[`职级竞争与排名.md`](职级竞争与排名.md)

---

## 1. 什么是「核心层」

钱记内部两张桌子：

| 桌子 | 场所 | 谁坐 | 玩家默认 |
|---|---|---|---|
| **前堂朝账** | `loc_01` 明面 | 跑街以下争序位 | 学徒起旁听 → 外场汇报 |
| **后堂夜议 / 密账** | `loc_02` 后院账房 | 东家、周管事、账房、**自己人** | 朝账**进不去** |

核心层成员特征：

- 知道「不能写明白的钱」  
- 参加的不是周朝账，而是**夜账、密见、差使接引**  
- HUD 排名**不显示**他们——他们是裁判席，不是同池选手

---

## 2. 为什么朝账进不去核心层

剧情理由（钱记口径）：

1. **跑街仍是门面**：经手街面应酬账，不等于碰顺序权  
2. **后堂要投名状**：周管事只认「办成了什么差」，不认「朝账排第几」  
3. **少爷也进不去**：钱子安能在跑街池里抢名头，一样被挡在账房门外（E013 偷看才半知）

玩法理由：

- 避免「刷简单活」一路排到后堂  
- 把 E013/E014/E016/E018 后堂钩做成**第二赛道**，与序位战并行

## 3. 入局捷径（按章节）

| 阶段 | 事件 / 行动 | 得到什么 | 与排名的关系 |
|---|---|---|---|
| 章二 | **E013** 账房密账 | 第一次摸黑账链；`flag_ledger_touch` | 不加后堂席，但开**夜路** |
| 章二 | **E019** 密账一用 | 证明「会用脑子」 | 外场池加分；核心**敲门** |
| 章三 | **E014** 护送银票 → 周管事 | `impression_qing`、庆系手书 | 庆系记名；**准自己人** |
| 章三 | **E016** 挑拨父子 | `father_son` 崩塌 | 东家需替手；**旁路召见** |
| 章终 | **E018** 跑街任命 | `flag_houtang_door_ajar` | 名分跑街 + **后堂门缝** |
| 正式版 | `set_rank: houtang` | 核心席位 | 须多条捷径叠满 |

### 3.1 特殊仪式：后堂夜议（非 M*）

触发条件（示例，三选二）：

- `flag_ledger_touch`  
- `meter.impression_qing >= 20`  
- `father_son < 35`  
- `player_rank == paojie`

入口：**深夜** `loc_02`，周管事传话「东家在后堂等你」——**不是**朝账日早上。

与朝账区别：

| | 朝账 | 夜议 |
|---|---|---|
| 时段 | `morning` | `late_night` |
| 参与者 | 明面序位者 | 核心层 + 被点名玩家 |
| 议题 | 汇报、升降、差事 | 暗账、上供、谁背锅 |
| HUD | 显示池排名 | 不显示排名；显示「核心召见」 |

## 4. 三条路线的核心入局

| 路线 | 捷径主链 | 终点身份 |
|---|---|---|
| A 隐忍 | 密账 → 父子局 → 跑街 → 后堂门缝 | 钱记跑街 + 经手账 |
| B 跳槽 | 排名仍在前堂；核心用**聚丰报价**绕开钱记后堂 | 聚丰跑街 |
| C 洋人 | 周管事手书 → 宝顺会谈；核心在**洋行体系** | 天津代理 |

B/C 在 HUD 上可把芯片文案从「学徒序」换成「估价档 / 门路档」，但底层仍可用 `run_ladder` 或平行 `run_market_rank`。
