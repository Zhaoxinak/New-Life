# 各职级可接触的钱路

> 在《暗潮》里，位子变化最直接的后果不是“战力+1”，而是：  
> **你能碰到哪些钱、哪些账、哪些体面。**  
> 若要先看“你是什么位子”，见 [`职级阶梯.md`](职级阶梯.md) 与 [`外部身份位子.md`](外部身份位子.md)。

---

## 1. 内部职级与钱路

| 职级 | 能碰到的钱 | 不能碰的钱 | 现实体感 |
|---|---|---|---|
| 学徒 | 工钱、赏钱、零碎跑腿钱 | 应酬账、账房顺序权、暗线钱 | 活着就不错 |
| 外场 | 更稳的月例、差事赏钱、少量门面支出 | 大额账权、暗线分利 | 开始像“能办事的人” |
| 跑街 | 月例、应酬账、街面垫付、回商行报账 | 真正核心黑账分配权 | 钱开始和面子绑在一起 |
| 后堂 | 顺序权、压放权、暗线边缘 | 仍未必摸到最终分利源头 | 知道的比拿到的更值钱 |

---

## 2. 外部位子与钱路

| 身份 | 能碰到的钱 | 核心逻辑 |
|---|---|---|
| 聚丰跑街 | 月薪五两、启动甜头、截胡订单利润 | 别人出价买你攒下的人脉与货情 |
| 宝顺天津代理 | 第一次分成、后续抽头 / 佣金 | 门路比现钱更值钱，现钱是门路的结果 |

---

## 3. 同样是“升上去”，钱路有什么区别

### A 隐忍

- 从 **工钱** 升到 **账权**
- 钱越来越像“体系里给你的位置”
- 爽点：别人肯让你碰钱，肯让你先垫后报

### B 跳槽

- 从 **被报价资格** 升到 **市场位子**
- 钱越来越像“别人愿为你付多少钱”
- 爽点：你值钱了，别人肯出钱把你挖走

### C 洋人

- 从 **门路资格** 升到 **代理分成**
- 钱越来越像“长期绑定的结果”
- 爽点：你不是打工，是开始吃抽头

---

## 4. 写事件时的用法

如果一个事件写“主角升了”，至少要回答四件事：

1. 他这次能碰到什么新钱路？  
2. 这笔钱是**工资、赏钱、报账、价码、分成**中的哪一种？  
3. 这笔钱让谁觉得你地位变了？  
4. 这笔钱会把你更深地绑进哪套关系？
