# 《暗潮》内容平台入口

> **版本**：V3.1 拆分稿 + 扩展化重构中  
> **时代**：清光绪十六年（1890）天津  
> **用途**：把《暗潮》维护为可继续追加主线、支线、DLC、MOD 的内容平台，而不只是单次剧本稿

---

## 一句话原则

**核心契约管规则，系统模块管玩法，战役实例管《暗潮》本体，注册表管接入与覆盖。**

---

## 四层结构

| 层 | 职责 | 运行时会改吗 | 当前入口 |
|---|---|---|---|
| 核心契约层 | schema、effect、存档、命名、表现边界、扩展规则 | 否 | [`00_总纲/`](00_总纲/) |
| 系统模块层 | 数值、路线、职级、清算等可复用玩法规则 | 否 | [`04_数值定义/`](04_数值定义/) · [`10_路线与结局/`](10_路线与结局/) · [`13_职级档案/`](13_职级档案/) · [`14_清算与爽点档案/`](14_清算与爽点档案/) |
| 注册表层 | 事件、对话、内容包、系统挂钩的统一索引 | 否 | [`15_注册表/`](15_注册表/) |
| 战役实例层 | 《暗潮》本体的角色、组织、事件、对话、日程、线索 | 否 | `01`–`12` 各档案 + `07/08/09/11` |

运行时仍遵守原契约：**定义层不被改写，effect 只改 `run_*` 与运行中实例。**

**必读三件套：**  
[`00_总纲/数据库架构.md`](00_总纲/数据库架构.md) · [`00_总纲/effect词汇表.md`](00_总纲/effect词汇表.md) · [`00_总纲/存档结构.md`](00_总纲/存档结构.md)

## ID 速览

| 前缀 | 含义 | 例 |
|---|---|---|
| `char_*` | 人物 | `char_lin_ruisheng` |
| `loc_*` | 地点 | `loc_01` |
| `org_*` | 组织 | `org_qianji` |
| `stat_*` | 主角属性 | `stat_money` |
| `act_*` | 自由行动 | `act_01` |
| `E*` / `R*` / `F*` | 事件 | `E014` |
| `clue_*` | 线索 | `clue_suspicious_manifest` |
| `item_*` | 信物 / 把柄 | `item_qing_letter` |
| `dialog_*` | 对话节点 | `dialog_e014_a_intro` |
| `grudge_*` | 恩怨账 | `grudge_zian_fiancee` |
| `route_*` / `flag_*` | 旗标 | `route_endure` |
| meter 短 id | 玩法计量 | `father_son` |
| `player_rank` | 职级枚举 | `waichang` |

完整总表以 [`00_总纲/旗标与命名.md`](00_总纲/旗标与命名.md) 为准；事件后缀语义以后续总表为准。
