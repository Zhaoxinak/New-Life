## 字段说明

| 字段 | 说明 |
|---|---|
| `slot_id` | 事件在系统中的竞争槽位 |
| `event_type` | `mainline_variant` / `reckoning_variant` / `ending` / `random` 等 |
| `route_tags` | 事件偏向的路线，不等于绝对锁死 |
| `mutex_group` | 同组候选只播一个 |
| `dialog_entry` | 事件落地时的对白入口 |
| `depends_on` | 前置事件或前置槽位 |
