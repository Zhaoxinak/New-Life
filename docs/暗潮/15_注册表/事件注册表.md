## 字段说明

| 字段 | 说明 |
|---|---|
| `slot_id` | 事件在系统中的竞争槽位 |
| `event_type` | `mainline` / `mainline_variant` / `mainline_retry` / `reckoning_variant` / `ending` / `random` / `failure` / `meeting` |
| `route_tags` | 事件偏向的路线，不等于绝对锁死 |
| `mutex_group` | 同组候选只播一个；空表示无互斥组 |
| `dialog_entry` | 事件落地时的对白入口 |
| `depends_on` | 前置事件或前置槽位（软依赖摘要；硬 require 以事件页为准） |

## 当前约束

1. `E020*`、`E021*`、`E022*` 统一视为“同槽位多变体”。  
2. `E010` / `E010b` 同属 `chapter2.night_cargo`（推迟重入）。  
3. `E018` 是章终收束槽位，条件口径见 [`../10_路线与结局/阶段性结局.md`](../10_路线与结局/阶段性结局.md)。  
4. README 顺序与本表顺序可以不同，但本表字段必须稳定。  
5. `depends_on` 中的 `E022*` 表示任一分轨主清算完成后可进终章。  
6. `M*` 朝账事件与 `E*` 内嵌关系见 [`../17_朝账系统/暗潮朝账挂点.md`](../17_朝账系统/暗潮朝账挂点.md)。
