## 字段说明

| 字段 | 说明 |
|---|---|
| `entry_kind` | `event_entry` / `variant_entry` / `overlay_entry` / `action_pool` / `meeting_council` |
| `variant_of` | 若是对白变体，指向基础入口 |
| `pack_id` | 提供该对白入口的包 |

## 当前约束

1. 事件注册表只记“走哪个入口”；对白结构细节仍在实际对话文件。  
2. 若未来某 DLC 只替换演出，不改主逻辑，应新增 `variant_of` 条目，而不是直接覆盖整个事件。  
3. `DIALOG_ACT_POOL` 服务自由行动口风，不绑定单一 `event_id`。
