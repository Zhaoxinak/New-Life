# 内容包注册表

> 记录哪些包存在、依赖什么、覆盖什么。  
> 当前以设计期 Markdown 维护；实现时可导出为结构化表。

| pack_id | 名称 | type | depends | load_order | provides | overrides | 状态 |
|---|---|---|---|---:|---|---|---|
| `base` | 暗潮本体 | `campaign` | `[]` | 0 | `campaign_anchao`, `route_endure`, `route_defect`, `route_foreign` | `[]` | active |

## 字段说明

| 字段 | 说明 |
|---|---|
| `pack_id` | 包唯一标识 |
| `type` | `campaign` / `dlc` / `mod` / `system` |
| `depends` | 依赖包 |
| `load_order` | 覆盖优先级 |
| `provides` | 本包引入的战役、路线、系统能力 |
| `overrides` | 本包覆盖的对象或槽位 |

## 约束

1. 任何未来 DLC / MOD 先在此表登记，再补事件和对白条目。  
2. 若包只追加对白变体，也必须登记 `pack_id`。  
3. 若包覆盖原版事件，`overrides` 必须可回溯到具体对象。
