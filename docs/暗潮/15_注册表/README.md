## 使用原则

1. 没有注册的事件，视为未接入。  
2. 没有注册的对白入口，视为不会被系统调用。  
3. 覆盖原版对象时，优先查本目录，不只看单个事件文档。  
4. README 给人读；注册表同时服务于人和未来工具链。
