## 1. 章二升阶仪式组

| 事件 | 路线主爽 | 互斥对象 | 触发核心 | 结果标记 |
|---|---|---|---|---|
| `E020` | A 隐忍 | `E020B` / `E020C` | 信任 / 情报 / 学徒身位 | `flag_rank_waichang_ceremony` |
| `E020B` | B 跳槽 | `E020` / `E020C` | 赵报价 / 市场信用 / 学徒身位 | `flag_e020b_done` |
| `E020C` | C 洋人 | `E020` / `E020B` | 洋行邀约 / 洋行信用 / 学徒身位 | `flag_e020c_done` |

规则：

1. 同一轮章二只播 **一条** 升阶主爽。  
2. 三者都成立时，按**当前主路线**选一条；没有主路线时，可按信用最高的一条或用户指定路线。  
3. 未被选中的其余两条，可保留数值铺垫，不播完整仪式戏。

## 2. 章二轻清算组

| 事件 | 路线主爽 | 互斥对象 | 依赖 |

| `E021` | A 隐忍 | `E021B` / `E021C` | `flag_grudge_window_light` + A 升阶轨 |
| `E021B` | B 跳槽 | `E021` / `E021C` | `flag_grudge_window_light` + `flag_e020b_done` |

规则：

1. 同一轮章三只播 **一条** 子安主清算。  
2. 清算后统一打 `flag_reckoning_zian_started`、`flag_marriage_agency_reclaimed`。  
3. `grudge_zian_slight` 若仍 open，默认并入同场兑现。

## 4. 章终身份落点组

| 结局 | 身份落点 | 关键旗 |
|---|---|---|
| `E018A` | 钱记跑街 | `player_rank = paojie` |
| `E018B` | 聚丰跑街（外部位子） | `flag_rank_jufeng_paojie` |

- A 线是**组织内升职**，直接改 `player_rank`。  
- B/C 线是**外部位子 / 代理身份落点**，用独立旗保留，不覆盖钱记内部 rank 历史。  

---

## 5. 实现优先级建议

1. 先判章二主爽组（`E020*`）  
2. 再判章二轻清算组（`E021*`）  
3. 章三推进后判主清算组（`E022*`）  
4. 章终统一判 `E018` 成功/失败分支  

若同一时段多个主爽候选同时满足，**绝不并播**；必须先根据路线主导权选出一条。
