# 洋行邀约 · `R009`

| 项 | 内容 |
|---|---|
| 地点 | `loc_03` · `hz_street_teahouse` |
| 时段 | afternoon, evening |
| 触发 | impression_bradley≥20，路线 C 且未关闭 |
| 效果摘要 | 邀至宝顺；白→林 score+5；`stat_credit_foreign` 起跳；解锁 `loc_05` 到访 |
| 对话入口 | [`dialog_r009_start`](../../11_对话档案/DIALOG_R009.md) |

> 街市茶楼递名片；**谈价与分成在 `loc_05`**（见 [`LOC_05`](../../02_建筑档案/LOC_05_宝顺洋行.md)）。

```yaml
require:
  - { loc: loc_03 }
  - { slot_in: [afternoon, evening] }
  - { meter: impression_bradley, op: ">=", value: 20 }
  - { flag: route_foreign, value: true }
  - { flag: route_foreign_closed, value: false }
effects:
  - { op: add, key: stat_credit_foreign, value: 5 }
  - { op: add, edge: {from: char_bradley, to: char_lin_ruisheng}, key: score, value: 5 }
  - { op: set_flag, key: flag_bradley_invite, value: true }
note: flag_bradley_invite 为 loc_05 首次进入门槛；正式会谈另需 flag_ending_c_ready（E017A）
```

### 实现模板（金融）

```yaml
effects:
  - { op: add, key: stat_credit_foreign, value: 5 }
  - { op: add, edge: {from: char_bradley, to: char_lin_ruisheng}, key: score, value: 5 }
  - { op: set_flag, key: flag_bradley_invite, value: true }
```

说明：

- `stat_credit_foreign` 在这里不是现钱，而是“洋行开始把你当成可继续考察的本地门路”
- `flag_bradley_invite` 管进门，`stat_credit_foreign` 管后续谈价深度
