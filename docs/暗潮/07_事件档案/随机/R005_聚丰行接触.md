> 赵鸿运先看的是“值不值得投钱、投位子”，不是义气。

## 金融挂点

R005 是跳槽线的第一次正式**市场报价**：

- 不是给你现钱，而是先给你被投资的资格
- 前置资源是 `stat_network`，本质是街市信用
- 后续可把情报、人脉、客户迁移转成新职位与启动资金

与 [`../../04_数值定义/金融系统_暗潮挂点.md`](../../04_数值定义/金融系统_暗潮挂点.md) 对应：R005 属于“门路金融 → 市场估值”转折点。

```yaml
require:
  - { loc: loc_03 }
  - { slot_in: [noon, afternoon, evening] }
  - { key: stat_network, op: ">=", value: 20 }
effects:
  - { op: add, key: stat_credit_market, value: 10 }
  - { op: add, edge: {from: char_zhao_hongyun, to: char_lin_ruisheng}, key: score, value: 10 }
  - { op: set_flag, key: flag_zhao_contacted, value: true }
```

### 实现模板（金融）

```yaml
effects:
  - { op: add, key: stat_credit_market, value: 10 }
  - { op: add, edge: {from: char_zhao_hongyun, to: char_lin_ruisheng}, key: score, value: 10 }
  - { op: set_flag, key: flag_zhao_contacted, value: true }
```

说明：

- `stat_credit_market` 表示你已从“街市熟脸”升到“值得被竞品继续报价的人”
- 它不替代 `stat_network`；前者是**市场授信**，后者是**社交覆盖面**

### B 线收益层级对应

- `R005` 对应**层 3：启动资金的报价权**（不是现银到账，而是“你有资格拿第一笔钱”）
- 它让 `E018B` 的“月薪五两 + 截胡第一单”更像兑现，而不是空头支票
