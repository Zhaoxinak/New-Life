# 茶楼消息 · `R001`

| 项 | 内容 |
|---|---|
| 地点 | `loc_03` · `hz_street_teahouse` |
| 时段 | evening |
| 触发 | 金钱≥5，随机池 |
| 效果摘要 | 钱-5，情报+3~8 |
| 对话入口 | [`dialog_r001_start`](../../11_对话档案/DIALOG_R001.md) |

> 五两不只是一杯茶的钱，而是几天活路换来的消息价。

```yaml
require:
  - { loc: loc_03 }
  - { slot: evening }
  - { key: stat_money, op: ">=", value: 5 }
effects:
  - { op: add, key: stat_money, value: -5 }
  - { op: add_range, key: stat_intel, min: 3, max: 8 }
```
