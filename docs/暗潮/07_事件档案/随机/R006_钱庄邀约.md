# 钱庄邀约 · `R006`

| 项 | 内容 |
|---|---|
| 地点 | `loc_04` · `hz_bank_counter` |
| 时段 | morning, noon |
| 触发 | 金钱≥50，条件池 |
| 效果摘要 | 解锁钱庄高阶 |
| 对话入口 | [`dialog_r006_start`](../../11_对话档案/DIALOG_R006.md) |

> 五十两不是巨款，但足以让票号把你从“零碎客”当成“能周转的人”。

## 金融挂点

R006 是正规金融层的第一道门：

- 它奖励的不是现钱，而是**信用升级**
- `flag_bank_tier2` 表示玩家从“拿零钱的人”升为“能谈周转的人”
- 后续应优先联动 `stat_credit_bank`、借贷展期、高阶往来与汇兑体面线；若已抬起 `flag_need_marriage_fund`，也代表“终于有资格正经备婚事的钱”

与 [`../../04_数值定义/金融系统_暗潮挂点.md`](../../04_数值定义/金融系统_暗潮挂点.md) 对应：R006 属于“现金流压力 → 票号信用 → 周转工具”转折点。

```yaml
require:
  - { loc: loc_04 }
  - { slot_in: [morning, noon] }
  - { key: stat_money, op: ">=", value: 50 }
effects:
  - { op: set_flag, key: flag_bank_tier2, value: true }
```

### 实现模板（金融）

```yaml
effects:
  - { op: set_flag, key: flag_bank_tier2, value: true }
  - { op: add, key: stat_credit_bank, value: 15 }
```

说明：

- `flag_bank_tier2` 负责“服务权限”
- `stat_credit_bank` 负责“授信口径”
- 二者同时存在，后续 `ACT_11` 的高阶往来、展期、汇兑门面才有抓手
