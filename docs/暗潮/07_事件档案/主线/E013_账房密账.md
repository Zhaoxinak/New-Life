# 账房密账 · `E013`

| 项 | 内容 |
|---|---|
| 触发 | 情报≥25 + clue_light_crate |
| 金融定位 | 黑账中轴；第一次把“可疑货”写成“利润链”和“月奉链” |
| 对话入口 | [`dialog_e013_start`](../../11_对话档案/DIALOG_E013.md) |
| 信物 | 选项 B → [`item_special_ledger_copy`](../../12_信物与把柄/ITEM_特别货密账抄件.md) |

> 这里不是单纯“偷账本”，而是玩家第一次真正看见：钱记的钱为什么脏、脏钱流向谁、为什么那么多人不敢让它停。

## 金融挂点

| 选项 | 金融意义 |
|---|---|
| A 记脑放回 | 低变现、高风险；把账权放进脑子里 |
| B 偷走密账 | 高把柄、高嫌疑；`item_special_ledger_copy` 是后续议价资产 |
| C 只记末页 | 拿到利润链边角料，够怀疑，不够翻桌 |

### A 线收益层级（隐忍线口径）

| 选项 | 对应层级 | 叙事落点 |
|---|---|---|
| A 记脑放回 | 层 4：账权经手层（先学会怎么记） | 先让你“经手不露怯” |
| B 偷走密账 | 层 5：暗线入口层（碰到不能写明的钱） | `item_special_ledger_copy` 把你绑进脏账议价链 |
| C 只记末页 | 层 4 的弱化版本 | 有线索但仍欠一点经手资格 |

### A 记脑放回（需情报≥30）

```yaml
require: { key: stat_intel, op: ">=", value: 30 }
effects:
  - { op: add, key: stat_intel, value: 15 }
  - { op: add, key: stat_suspicion, value: 5 }
  - { op: unlock_clue, id: clue_special_goods }
```

### B 偷走密账

```yaml
effects:
  - { op: add, key: stat_intel, value: 20 }
  - { op: add, key: stat_suspicion, value: 25 }
  - { op: unlock_clue, id: clue_special_goods, quality: physical }
  - { op: grant_item, id: item_special_ledger_copy }
  - { op: set_flag, key: flag_ledger_stolen, value: true }
```

### C 只记末页

```yaml
effects:
  - { op: add, key: stat_intel, value: 10 }
  - { op: unlock_clue, id: clue_special_goods, quality: partial }
```
