# 利用未婚妻 · `E012`

| 项 | 内容 |
|---|---|
| 触发 | 柳→林 score≥40 · `flag_endure_preview`（E008B）· Day12 晚 |
| 对话入口 | [`dialog_e012_start`](../../11_对话档案/DIALOG_E012.md) |

> 核心是把“送礼”变成控制：收、拒、拖，都是在给钱与体面定价。

## 情面资产挂点

| 选项 | 情面资产意义 |
|---|---|
| A 教她受礼传消息 | 把礼物从“心意”变成“控制工具”；如烟更像被礼压住 |
| B 坚决拒绝 | 明确拒绝把情面资产转成控制资产 |
| C 拖延 | 不拆雷，也不彻底接礼；保留半开压力 |

```yaml
require:
  - { edge: {from: char_liu_ruyan, to: char_lin_ruisheng}, key: score, op: ">=", value: 40 }
  - { flag: flag_endure_preview, value: true }
```

### A 教她受礼传消息

```yaml
effects:
  - { op: add, edge: {from: char_liu_ruyan, to: char_lin_ruisheng}, key: score, value: -5 }
  - { op: add, key: stat_intel, value: 15 }
  - { op: set, edge: {from: char_qian_zian, to: char_liu_ruyan}, key: leverage, value: 受礼把柄 }
  - { op: set_flag, key: flag_liu_spy, value: true }
```

### B 坚决拒绝

```yaml
effects:
  - { op: add, edge: {from: char_liu_ruyan, to: char_lin_ruisheng}, key: score, value: 10 }
  - { op: add, edge: {from: char_qian_zian, to: char_lin_ruisheng}, key: score, value: -10 }
  - { op: set, edge: {from: char_qian_zian, to: char_liu_ruyan}, key: leverage, value: 无 }
  - { op: add, meter: pursuit, value: 5 }  # 恼羞：纠缠升温，非商行嫌疑
  - { op: set_flag, key: flag_liu_channel_closed, value: true }
```

### C 拖延

```yaml
effects:
  - { op: add, edge: {from: char_liu_ruyan, to: char_lin_ruisheng}, key: score, value: 5 }
  - { op: set, edge: {from: char_qian_zian, to: char_liu_ruyan}, key: leverage, value: 半收半拖 }
  - { op: set_flag, key: flag_liu_channel_half, value: true }
```
