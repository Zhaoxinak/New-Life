## 路线收益口径

| 路线 | Day30 最关键收益 |
|---|---|
| A 隐忍 | 跑街月例、应酬账、接触暗线的账权 |
| B 跳槽 | 新职位、启动资金、截胡第一单的市场位子 |
| C 洋人 | 第一次现银 + 后续分成/抽头/佣金资格 |

## 实现模板（金融）

### E018A · 隐忍落账

```yaml
effects:
  - { op: add, key: stat_money, value: 5 }
  - { op: add, key: stat_trust_firm, value: 10 }
  - { op: set_flag, key: flag_ending_a, value: true }
```

说明：

- `stat_money +5` 表示跑街后“第一笔更像样的活钱”，不是长期总收益
- `stat_trust_firm +10` 表示你已从学徒转成钱记可真正托事的人
- 更大的收益仍属于叙事层：月例变稳、赏钱变厚、应酬账可报、后堂可进、暗线可摸

建议收益分层：

- 第 1 层：月例保活，不再天天只看手里碎银
- 第 2 层：赏钱弹性，偶尔能多出一点可支配活钱
- 第 3 层：应酬账口径，能先替商行花、后回商行报
- 第 4 层：账权口径，开始经手“哪笔钱先走”的顺序
- 第 5 层：暗线入口，真正值钱的是“知道哪些账不能写”

### E018B · 跳槽落账

```yaml
effects:
  - { op: add, key: stat_money, value: 10 }
  - { op: add, key: stat_credit_market, value: 15 }
  - { op: set_flag, key: flag_ending_b, value: true }
```

说明：

- `stat_money +10` 表示聚丰给出的第一笔启动甜头
- `stat_credit_market +15` 表示你从“被报价的人”升为“市场上有位子的人”
- 更高收益仍保留在叙事层：月薪五两、截胡订单、客户迁移

### E018C · 洋行落账

```yaml
effects:
  - { op: add, key: stat_money, value: 20 }
  - { op: add, key: stat_credit_foreign, value: 20 }
  - { op: set_flag, key: flag_ending_c, value: true }
```

说明：

- `stat_money +20` 表示“第一次落袋的现银”，不是全部身家
- `stat_credit_foreign +20` 表示你已从临时门路升为可持续代理关系
- 更厚的长期收益仍建议保留在叙事口径，如“月收入档”“代理抽成”
