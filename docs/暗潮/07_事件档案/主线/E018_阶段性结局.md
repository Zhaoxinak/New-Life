## 实现模板（金融）

### E018A · 隐忍落账

```yaml
effects:
  - { op: set_rank, value: paojie }
  - { op: add, key: stat_money, value: 5 }
  - { op: add, key: stat_trust_firm, value: 10 }
  - { op: set_flag, key: flag_ending_a, value: true }
  - { op: resolve_grudge, id: grudge_demao_defer, mode: forgive }  # 默认可在对白里改选 punish
```

说明：

- `set_rank: paojie` 是章终职级爽的权威落点
- `stat_money +5` 表示跑街后“第一笔更像样的活钱”，不是长期总收益
- `stat_trust_firm +10` 表示你已从学徒/外场转成钱记可真正托事的人
- `grudge_demao_defer` 须在任命戏中罚/恕二选一；上表 forgive 仅为默认模板
- 更大的收益仍属于叙事层：月例变稳、赏钱变厚、应酬账可报、后堂可进、暗线可摸
- 建议软解锁后堂钩：`set_flag flag_houtang_door_ajar`（正式版再 `set_rank: houtang`）

建议收益分层：

- 第 1 层：月例保活，不再天天只看手里碎银
- 第 2 层：赏钱弹性，偶尔能多出一点可支配活钱
- 第 3 层：应酬账口径，能先替商行花、后回商行报
- 第 4 层：账权口径，开始经手“哪笔钱先走”的顺序
- 第 5 层：暗线入口，真正值钱的是“知道哪些账不能写”

#### A 线任命戏里的恩怨分支

若 `grudge_demao_defer` 仍 open，任命戏内二选一：

# 惩罚：要东家当众补话

- { op: resolve_grudge, id: grudge_demao_defer, mode: forgive }

### E018B · 跳槽落账

```yaml
effects:
  - { op: set_flag, key: flag_rank_jufeng_paojie, value: true }
  - { op: add, key: stat_money, value: 10 }
  - { op: add, key: stat_credit_market, value: 15 }
  - { op: set_flag, key: flag_ending_b, value: true }
```

说明：

- `flag_rank_jufeng_paojie` 表示你在**聚丰**拿到了正式跑街外部位子；不覆盖钱记内部的 `player_rank` 历史
- `stat_money +10` 表示聚丰给出的第一笔启动甜头
- `stat_credit_market +15` 表示你从“被报价的人”升为“市场上有外部位子的人”
- 更高收益仍保留在叙事层：月薪五两、截胡订单、客户迁移
- 终章演出应补齐四件套：赵当众给外部位子、看客改口、第一笔月薪口径、旧东家闻讯失态

### E018C · 洋行落账

```yaml
effects:
  - { op: set_flag, key: flag_rank_foreign_agent, value: true }
  - { op: add, key: stat_money, value: 20 }
  - { op: add, key: stat_credit_foreign, value: 20 }
  - { op: set_flag, key: flag_ending_c, value: true }
```

说明：

- `flag_rank_foreign_agent` 表示你已从临时门路升为宝顺可持续调用的天津代理身份
- `stat_money +20` 表示“第一次落袋的现银”，不是全部身家
- `stat_credit_foreign +20` 表示你已从临时门路升为可持续代理关系
- 更厚的长期收益仍建议保留在叙事口径，如“月收入档”“代理抽成”
- 终章演出应补齐四件套：白瑞德亲自递话、洋行内部改眼神、第一次分成落地、长期绑定代价说清
