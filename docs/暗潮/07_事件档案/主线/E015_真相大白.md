# 真相大白 · `E015`

| 触发 | 情报≥40 + clue_special_goods；钥匙需王→林 档≥相善(`score≥40`) 或 人脉≥30 |
| 对话入口 | [`dialog_e015_start`](../../11_对话档案/DIALOG_E015.md) |
| 信物 | 选项 A → [`item_opium_sample`](../../12_信物与把柄/ITEM_鸦片样品.md) |

> 这一场除了揭示“是什么货”，更要让玩家感到：钱家夜里搬的，是足以把学徒、婚事、月例、体面全都压成笑话的暴利。

## 金融挂点

| 选项 | 金融意义 |
|---|---|
| A 取样放回 | 保留证据，后续可继续议价；重真相，轻现钱 |
| B 只推断 | 知道钱路，却不摸现货；最保守 |
| C 大量盗卖 | 典型“脏钱系统”样板：立刻 `stat_money +100`，但嫌疑暴涨 |

> `E015C` 是 Demo 中最典型的高收益高风险金融选择：它不是发财奖励，而是测试玩家愿不愿为暴利押上路线与体面。

### A 取样放回

```yaml
effects:
  - { op: add, key: stat_intel, value: 30 }
  - { op: add, key: stat_suspicion, value: 10 }
  - { op: unlock_clue, id: clue_opium_secret }
  - { op: grant_item, id: item_opium_sample }
```

### B 只推断

```yaml
effects:
  - { op: add, key: stat_intel, value: 15 }
  - { op: unlock_clue, id: clue_opium_infer }
```

### C 大量盗卖

```yaml
effects:
  - { op: add, key: stat_money, value: 100 }
  - { op: add, key: stat_intel, value: 10 }
  - { op: add, key: stat_suspicion, value: 40 }
  - { op: unlock_clue, id: clue_opium_infer }
```

### 实现模板（金融）

```yaml
effects:
  - { op: add, key: stat_money, value: 100 }
  - { op: add, key: stat_intel, value: 10 }
  - { op: add, key: stat_suspicion, value: 40 }
  - { op: set_flag, key: flag_dirty_money_marked, value: true }
  - { op: set, edge: {from: char_qian_demao, to: char_lin_ruisheng}, key: leverage, value: 盗卖把柄 }
  - { op: unlock_clue, id: clue_opium_infer }
```

说明：

- `stat_money +100` 表示“暴利真的落袋”
- `flag_dirty_money_marked` 表示“最近手头突然活了”，便于后续事件认脏钱
- `edge.leverage` 把盗卖从一次性收益改成长期把柄
