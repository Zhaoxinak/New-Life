# 轻清算 · `E021`

| 项 | 内容 |
|---|---|
| 建议日程 | E020 之后 · afternoon · `loc_01` |
| 与 E021B / E021C | **互斥**：A 线主爽走本事件；B/C 主爽分别走 E021B / E021C |
| 触发 | `flag_grudge_window_light`；`rank_in=[waichang,paojie]`；非 `flag_e020b_done` / `flag_e020c_done`；至少一条可兑：`grudge_onlooker` 或 `grudge_zian_slight` 为 open |
| 对话入口 | [`dialog_e021_start`](../../11_对话档案/DIALOG_E021.md) |

> **清算爽（轻）**：罚/恕双极。优先兑看客债；若无看客债则兑 `grudge_zian_slight`。
> **结算权威在事件页**：对白只负责目标选择与演出文本，不再重复承载每个分支的主结算。

## 目标选择（引擎）

1. 若 `grudge_onlooker` open → 以看客为主角  
2. else 若 `grudge_zian_slight` open → 轻量子安  
3. else 跳过并清 `flag_grudge_window_light`

无可兑时：

```yaml
effects:
  - { op: set_flag, key: flag_grudge_window_light, value: false }
```

## 看客线

### A 惩罚

```yaml
effects:
  - { op: resolve_grudge, id: grudge_onlooker, mode: punish }
  - { op: add, key: stat_support_low, value: 10 }
  - { op: add, key: stat_network, value: 3 }
  - { op: set_flag, key: flag_grudge_window_light, value: false }
```

### B 宽恕

```yaml
effects:
  - { op: resolve_grudge, id: grudge_onlooker, mode: forgive }
  - { op: add, key: stat_support_low, value: 8 }
  - { op: set, edge: {from: char_lin_ruisheng, to: char_zhou_guanshi}, key: debt, value: 看客被你放过，欠一声 }
  - { op: set_flag, key: flag_grudge_window_light, value: false }
```

> 看客具象：Demo 可用周管事或「前堂闲话头」旗；对白称「那些跟着起哄的人」。
