# 洋行门路 · `E020C`

| 项 | 内容 |
|---|---|
| 建议日程 | 章二中后段 · afternoon · `loc_05`（或 `loc_03` 导入后切洋行会客） |
| 与 E020 互斥 | 章二升阶仪式三选一：E020 / E020B / E020C |
| 触发 | `route_foreign`；非 `route_foreign_closed`；`flag_bradley_invite` 或 `meter.impression_bradley>=20`；`stat_credit_foreign>=5` 或情报≥25；`rank=apprentice`；非 `flag_e020c_done` / `flag_e020b_done` / `flag_rank_waichang_ceremony` |
| 对话入口 | [`dialog_e020c_start`](../../11_对话档案/DIALOG_E020C.md) |

> **C 线章二主爽**：洋行「记得你」。门路资格仪式——先资格，不先分成。  
> 四件套：仪式（白当面确认门路）· 称呼（「林朋友」钉死）· 银钱（薄礼/车马，象征）· 恩怨窗（E021C 狐假虎威）。

## 金融 / 权限口径

| 层 | 变化 |
|---|---|
| 仪式 | 白瑞德确认：你是可继续谈的本地门路 |
| 称呼 | 「林朋友」；钱记看客开始猜你的靠山 |
| 银钱 | 薄礼级现银（体面包装） |
| 权限 | `loc_05` 再访更顺；谈价层抬一档 |
| 职级 | 可软升 `waichang`（在钱记更好活动）；主爽在洋行信用 |
| 恩怨窗 | `flag_grudge_window_light` → E021C |

```yaml
  - { op: set_rank, value: waichang }
  - { op: add, key: stat_money, value: 3 }
  - { op: add, key: stat_credit_foreign, value: 10 }
  - { op: add, meter: impression_bradley, value: 5 }
  - { op: add, edge: {from: char_bradley, to: char_lin_ruisheng}, key: score, value: 8 }
  - { op: set_flag, key: flag_e020c_done, value: true }
  - { op: set_flag, key: flag_foreign_door_known, value: true }

```
