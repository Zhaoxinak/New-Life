## 组织金融层（统一口径）

组织档案建议统一回答六件事：

1. **明账来源**：表面靠什么赚钱  
2. **灰账来源**：关系、价差、介绍费、回扣从哪来  
3. **黑账来源**：哪条线最见不得光  
4. **主要支出**：月例、运费、上供、封口、佣金、体面花销  
5. **最脆弱环节**：哪一层一断就会逼人跨线  
6. **对玩家意义**：玩家在这台钱路机器里扮演什么角色

建议组织层字段：

| 字段 | 含义 |
|---|---|
| `firm_bright` / `firm_dark` / `firm_heat` | 经营成色、黑账活跃、穿帮风险 |
| `cash_bright` / `cash_dark` | 明暗现金流 |
| `liquidity` | 周转宽紧 |
| `payroll_pressure` | 养人压力 |
| `tribute_pressure` | 上供/保护费压力 |
