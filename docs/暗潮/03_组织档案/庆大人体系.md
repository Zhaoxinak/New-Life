## 钱路画像

| 项 | 内容 |
|---|---|
| 明账来源 | 官面身份本身，不靠明账吃饭 |
| 灰账来源 | 打点、站台、默许、护送银票 |
| 黑账来源 | 月奉、走私利润抽头、保护费 |
| 主要支出 | 养线人、养白手套、护送与压事成本 |
| 最脆弱环节 | 白手套失控、名头被乱用、月奉断档 |
| 对玩家意义 | 庆系不给你现银，却能把你抬成“别人不敢轻看的那种人” |

## 规则

- 印象 ≥ 30 且白瑞德印象 ≥ 30 → 可狐假虎威；同时关闭隐忍线「正义复仇」分支  
- 若被识破「利用名头」→ 后果重于得罪钱德茂（Demo 作警告旗标即可）

## 金融逻辑

庆系代表《暗潮》里最高级的“权力金融”：

1. 钱记要交钱，不是因为礼貌，而是因为活路  
2. 玩家拿到庆系印象，不是发财，而是拿到一种比银子更贵的信用  
3. 一旦用错庆系名头，后果会比少几两银子严重得多

### 玩家切入点

- `E014A`：护送银票，是第一次触到“权力的钱”
- `E017A`：庆系手书在洋行眼里比现银更值钱
- `E018C`：庆系背书成为洋行长期分成的一部分前提
