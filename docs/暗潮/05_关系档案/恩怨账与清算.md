## 1. 运行库形状 `run_grudge`

```yaml
run_grudge:
  - id: grudge_zian_slight      # 定义 id
    status: open                # open | punished | forgiven | expired
    debtor: char_qian_zian      # 债主（欺负过你的人）
    buried_by: E004             # 埋入事件
    flashback_key: dialog.grudge.zian_slight.flash  # 清算时闪回 loc_key
```

- 定义层：本文件登记 id、埋点、兑现窗、罚/恕效果模板。  
- 运行层：只存实例列表；未出现 = 未埋。  
- UI：情报簿或「恩怨」页可读 `open` 条；精确 effect 可隐藏。

## 2. Effect

| op | 必填 | 语义 |
|---|---|---|
| `unlock_grudge` | `id` | 埋债；已存在则忽略或刷新 flashback |
| `resolve_grudge` | `id`, `mode`∈{punish,forgive} | 兑现；改 status |
| `expire_grudge` | `id` | 过期（错过窗口且剧情允许） |

详见 [`../00_总纲/effect词汇表.md`](../00_总纲/effect词汇表.md)。

## 3. 清算戏写法（四拍）

所有罚/恕节点按此顺序写对白与演出：

1. **称呼** — 别人怎么叫你（或第一次改口）  
2. **站位** — 谁站前堂中央 / 谁低头让路  
3. **看客** — 窃窃私语、改眼神  
4. **仇人失态** — 罚则崩脸；恕则又恨又惧  

闪回：兑现前插入 `flashback_key` 一句（埋债时的羞辱）。

---

## 4. 双极原则

| 极 | 玩家爽感 | 必须改局（示例） |
|---|---|---|
| **惩罚** | 当众翻盘、夺脸夺权 | score↓、职位话语权、meter、看客支持↑ |
| **宽恕** | 能杀而不杀的上位感 | 舆论/信任↑、留 `leverage`、未来恩债；**不是零代价圣母** |

第三极「冷处理」可作支线，**不能替代**罚/恕双极。  
**不单开仁义结局支线**；恕只改变关系与后续事件权重。

尺度：**职场打脸**（夺脸、夺权、夺婚事主动权）。私刑/血仇不做主菜；C 线可更脏但仍走权谋。

### 加深规则

- R003 触发时：若已有 `grudge_zian_slight` 且 `open`，可 `set_flag flag_zian_slight_worsened`；清算文案用加重版。  
- 未埋 `grudge_zian_slight` 时 R003 仍 `unlock_grudge`。

## 6. 窗口与过期

| 窗 | 事件 | 可兑现 |
|---|---|---|
| 轻窗 | E021 | `grudge_onlooker`；可选 `grudge_zian_slight` |
| 主窗 | E022 | `grudge_zian_fiancee`；可并兑 `grudge_zian_slight` |
| 任命窗 | E018A | `grudge_demao_defer`；扫尾未兑现 open 条（提示或强制二选一） |

若章三结束仍 `open`：E018 结算前弹出扫尾清算；拒绝选择则 `expire_grudge` 并记「心结未解」修正（人脉或信任微惩），避免烂尾。
