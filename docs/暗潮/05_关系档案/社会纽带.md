# 社会纽带（关系类型）

> **纽带 ≠ 交情**：父子可以不睦；厚交不必是亲戚。  
> 标签可叠加；无则写 `无`。

---

## 1. 类型定义

### 1.1 亲戚

| 类型 | 含义 | 暗潮开局 |
|---|---|---|
| 血亲 | 有血缘 | 钱德茂↔钱子安（父子） |
| 族亲 | 同宗可认 | 无 |
| 姻亲 | 因婚 | 无（林↔柳为**定亲未娶**，不算姻亲成立） |

### 1.2 社会 / 职场 / 情感

| 类型 | 含义 | 例 |
|---|---|---|
| 定亲 | 已定亲未成婚 | 林瑞生↔柳如烟 |
| 恋慕 | 情爱取向（可单向） | 如烟→瑞生；子安→如烟（觊觎） |
| 师兄弟 | 同号师门情分 | 林瑞生↔王胖子 |
| 东伙 | 东家↔伙计/学徒 | 钱德茂→林瑞生、王胖子 |
| 主从 | 上下依附（含白手套） | 庆大人←钱德茂；庆←周管事 |
| 竞业 | 同行对手 | 赵鸿运↔钱德茂 |
| 考察 | 评估合作对象 | 白瑞德→钱德茂 / →林瑞生 |
| 同号 | 仅共事、无更深标签 | 默认可不写 |

## 3. 与交情怎么并存

| 问 | 答 |
|---|---|
| 父子一定相善？ | 否。开局父子纽带在，交情可一善一冷；`meter.father_son` 管「家和」 |
| 定亲一定厚交？ | 开局如烟→瑞生接近厚交；瑞生→如烟相善/厚交；可被利用砸档 |
| 竞业能否相善？ | 能（表面），暗潮开局偏泛泛竞争 |
| 玩家特殊吗？ | 不特殊。只是边的一端是 `char_lin_ruisheng` |
