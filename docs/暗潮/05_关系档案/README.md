## 一条边长什么样

```
from → to:
  score          # 交情分 −100～+100（权威）
  tier           # 由分推导：仇隙|不睦|泛泛|相善|厚交
  trust          # 修正：低|中|高|极低|— 
  suspicion      # 修正：疑心（可对玩家隐藏显示）
  fear           # 修正：忌惮/畏惧（Demo 可后置）
  debt           # 债：无 / 简述
  leverage       # 把柄：无 / 简述
  bonds[]        # 社会纽带标签，见社会纽带.md
  meters{}       # 可选玩法计量（父子和睦、追求亲密、洋人评估…）
```

未列出的人物对：默认 **泛泛 / 分 0 / 信任低 / 疑心低 / 债无 / 把柄无 / 纽带无**。
