# 关系触发逻辑（统一字段）

> 读 **交情分/档**、**修正**、**meter**、**纽带**。每时段末 / 日末扫描。

```yaml
triggers:
  - id: liu_intel_drip
    if:
      - { from: char_liu_ruyan, to: char_lin_ruisheng, tier_in: [厚交], score: ">60" }
      - { meter: pursuit, op: "<", value: 30 }
    then: { schedule: "every_3_days", effect: "intel_from_liu" }

  - id: liu_betray
    if:
      - { from: char_liu_ruyan, to: char_lin_ruisheng, score: "<", value: -20 }  # 不睦及以下
      - { meter: pursuit, op: ">=", value: 60 }
    then: { event: F004 }  # 告密；玩家嫌疑↑

  - id: firm_infighting
    if: { meter: father_son, op: "<", value: 30 }
    then: { flag: flag_qian_infighting, firm_efficiency_down: true }

  - id: qian_surveil
    if:
      - { from: char_qian_demao, to: char_lin_ruisheng, key: suspicion, op: ">=", value: 2  # 高 }
      # 或 score 过低且疑心高
    then: { event: R007 }

  - id: zian_snitch
    if:
      - { from: char_qian_zian, to: char_lin_ruisheng, key: fear, op: ">", value: 1  # 中 }
      - { from: char_qian_zian, to: char_lin_ruisheng, tier_in: [仇隙, 不睦] }
    then: { flag: flag_zian_snitch_risk: true }

  - id: wang_report
    if: { from: char_wang_pangzi, to: char_lin_ruisheng, tier_in: [相善, 厚交], score: ">=40" }
    then: { schedule: "every_5_days", event: R002 }

  - id: bradley_abandons_qian
    if: { meter: eval, op: "<", value: 20 }  # 白→钱
    then: { flag: flag_foreign_window_open: true }

  - id: bradley_formal_talk
    if:
      - { meter: impression_bradley, op: ">=", value: 30 }
      - { meter: impression_qing, op: ">=", value: 30 }
    then: { flag: flag_ending_c_ready, note: "与 E017A 同旗；E018C 硬门控" }

  - id: route_evil_locks_justice
    if:
      - { meter: impression_qing, op: ">=", value: 30 }
      - { meter: impression_bradley, op: ">=", value: 30 }
    then: { flag: flag_endure_justice_closed: true }
```

## 结局条件（改写对照）

| 旧条件 | 新读法 |
|---|---|
| 父子关系≤30 | `meter.father_son ≤ 30` |
| 赵鸿运好感≥50 | 赵→林 `score ≥ +40` 且档≥相善（或分≥50 按调平） |
| 柳如烟好感≤0 且亲密≥60 | 柳→林 `score ≤ -20` 且 `pursuit ≥ 60` |
| 钱德茂猜忌≥70/80 | 钱→林 `suspicion` 高 / 事件 F005 |
| 白/庆印象≥30 | 对应 `meter.impression_*` |
