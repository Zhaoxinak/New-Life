## 一、世界观与时代背景

### 1.1 时代设定

时间：1890年（清光绪十六年）。天津。

天津是北方最大的通商口岸。英、法、德、日租界沿紫竹林一带铺开，洋行的汽笛声日日不断。华界与租界犬牙交错，买办、商人、苦力、地痞、官差混杂其间。表面上，这里是洋货吞吐的商贸枢纽；暗地里，鸦片——洋人称之为"medicine"，中国人称之为"洋药"——仍是最暴利的买卖。

1858年《天津条约》后，鸦片贸易合法化已三十二年。鸦片改称"洋药"，每担（百斤）征关税三十两、厘金八十两，共一百一十两，完税后即可凭单运销内地（仅限华商）。印度来的"公班土"和波斯来的"红皮土"走海路入天津港，经海关保税仓完税后由华商接手，层层转手流入烟馆和富户。朝廷名义上"弛禁"（放任但征税），鸦片税已成清廷重要财源——1888年洋土药税厘合计约六百五十六万两。但合法归合法：有人正大光明完税走货，也有人暗地里绕关逃税、勾结京官牟取暴利。钱记商行做的，就是后者。

### 1.2 核心社会关系链

```
京中高官（幕后·"庆大人"）
    └── 白手套商行（钱记商行）
          ├── 明面生意：木材、布匹、杂货进出口（合法，向商行股东公开）
          └── 暗中生意：以木材为掩护进口鸦片
                ├── 走关部分：走海关完税110两/担，有凭单（合法但瞒着股东）
                └── 走私部分：绕关逃税，零成本入货（违法）
                      └── 纯利润流向：京中"庆大人"（月奉三千两）
                ├── 上游：洋行（货源）
                ├── 中游：商行（转运、分销）
                └── 下游：烟馆、富户（零售）
```

商行老板是这条链的中间人。他的鸦片生意分两条线：一条走海关完税，有凭单，但向商行股东隐瞒真实业务范围（商业欺诈）；另一条彻底违法——绕关走私，一分税不交，纯利全部流向京中官员。这种"合法掩护违法、明暗双线并行"是晚清官商的典型手法。

> **潜在变量**：1890年天津各大洋行正在拓展新业务——中国古董收购，面向欧洲收藏家和美国博物馆供货。1890年清廷尚无任何文物出口管制法律（中国第一部文物保护专门法律要到1930年才出现），洋人在中国收购古董完全合法，"谁有钱谁就能拿走"。但洋人面临两个难题：一是看不懂真伪，需要本地人帮着搜罗、识别；二是不懂官场规矩，没有本地人罩着走不通渠道。因此洋行亟需一个"有眼力、有渠道、有官场背景"的买办。这条利益线目前尚未与钱记商行正式交汇，但它是"洋人介入流"路线的外部条件。

## 三、日周期系统（5时段制）

### 3.1 时段定义

游戏采用**日周期回合制**，每天分为5个行动时段。玩家每个时段选择1个地点执行1个行动，消耗时段并触发数值变化与事件。

```
DAILY_TIME_SLOTS:
  1. 早上   (morning)     — 06:00-10:00 — 商行开张、正式差事、商务会面
  2. 中午   (noon)        — 10:00-14:00 — 短暂接触、传话递信、快速打探
  3. 下午   (afternoon)   — 14:00-18:00 — 外出办事、社交活动、后院行动
  4. 晚上   (evening)     — 18:00-22:00 — 茶楼酒馆、私人互动、未婚妻剧情
  5. 深夜   (late_night)  — 22:00-02:00 — 高风险行动：偷听、潜入、暗中交易。必然增加嫌疑值
```

### 6.3 三大夺权路线

**路线A：跳槽反戈流**
- 核心逻辑：带着情报与客户投奔竞品聚丰行，从外部击垮钱记
- 关键机制：竞品定期评估主角价值；跳槽时情报值转化为新商行职位与启动资金；入职后可发起商业打击
- 风险：跳槽后与钱记彻底为敌；情报不足会被边缘化
- Demo终点：成功入职聚丰行，完成第一次订单截胡

**路线B：隐忍离间流（Demo主推完整路线）**
- 核心逻辑：留在商行伪装忠诚，利用未婚妻接近钱子安，收集情报挑拨父子，引发内斗后上位
- 关键机制：未婚妻操纵（影响柳如烟态度→引导她向钱子安传递消息/制造误会）；父子矛盾值（放大固有矛盾触发内斗事件）；职场钻营（表面努力工作获取信任，暗中拉拢伙计、收集黑料）；背锅嫁祸（将操作嫁祸给内斗另一方）
- **加速器**：Day 16钱子安鲁莽事件选择B（告密钱德茂），直接拉低 meter.father_son 25点
- 风险：柳→林交情分过低反水告密；钱→林疑心过高直接清除主角；父子矛盾过低则计谋无效
- Demo终点：成功挑起父子公开对立，升任跑街，接触到核心账目和鸦片暗线

**路线C：洋人介入流（邪恶路线）**
- 核心逻辑：利用已掌握的鸦片暗线情报阻止钱子安鲁莽破坏走私线路，借机获得庆大人青睐，再以庆大人背景狐假虎威，主动取代钱家成为洋行新代理人
- 关键机制：洋行信任评估（白瑞德持续评估合作方可靠性）；中层/下层伙计拉拢（阻止钱子安需要自己的人手）；meter.impression_qing（完成护送银票任务获得）；狐假虎威（用庆大人管事手书做背书）
- 风险：拉拢伙计暴露则嫌疑值暴增；庆大人若识破主角在利用其名头，后果比得罪钱德茂更可怕
- 复仇变形：钱德茂从"仇人"变为"旧人"——主角用洋人资本反向挤压钱记生存空间
- Demo终点：主角成功与洋人接洽，以庆大人背景狐假虎威，开启合作

## 七、NPC动态关系系统

### 7.1 设计理念（v0.2 统一模型）

> **权威实现见 [`05_关系档案/`](05_关系档案/README.md)。**  
> 玩家与 NPC 同一套：**交情五档**（仇隙/不睦/泛泛/相善/厚交，底层分 −100～+100）+ **修正**（信任/疑心/忌惮/债/把柄）+ **社会纽带**（父子、定亲、竞业…）。  
> 特殊玩法用 `meter`（`father_son` / `pursuit` / `eval` / `impression_*`），不另开好感。

### 7.2 交情与修正（对任意人，含主角）

| 数值 | 范围 | 含义 | 是否对玩家可见 |
|------|------|------|----------------|
| 交情分 score | −100～+100 | 推导五档 | 可见档；精确分可后解锁 |
| 信任 trust | 低/中/高… | 托密、托暗事 | 可见 |
| 忌惮 fear | 同上 | 怕你手段/后台 | 可见（Demo 可后置） |
| 疑心 suspicion | 同上 | 怀疑动机 | **隐藏精确值** |

### 7.3 四维组合行为表

| 组合状态 | NPC行为表现 | 游戏效果 |
|----------|------------|----------|
| 高交情+高信任+低忌惮+低疑心 | 忠心追随，主动帮忙 | 最可靠的盟友，可托付核心任务 |
| 高交情+低信任+低忌惮+低疑心 | 友好但谨慎 | 会帮忙，但涉及核心利益会回避 |
| 低交情+高信任+低忌惮+低疑心 | 公事公办 | 不偏不倚，按规矩办事 |
| 高忌惮+高疑心+低交情+低信任 | 恐惧且怀疑 | 表面服从，暗中等机会反咬 |
| 高忌惮+低疑心+低交情+低信任 | 纯粹恐惧 | 乖乖听话，一旦不怕了立刻翻脸 |
| 低交情+低信任+低忌惮+高疑心 | 警惕观望 | 不会主动帮忙，也不会立刻敌对，但在观察主角 |
| 高交情+高信任+低忌惮+高疑心 | 矛盾纠结 | 内心挣扎，可能因疑心爆发而变脸 |
| 各项全低 | 敌对/漠视 | 随时可能背叛或出卖主角 |

    → 白瑞德邀请主角到宝顺洋行正式会谈（结局C触发条件之一）

## 十、开发注意事项

1. **总文本量**：Demo阶段控制在8000字以内，重点写关键剧情节点，日常行动用短句描述。

2. **核心设计原则**："选择影响数值，数值决定剧情"——每个事件必须有明确数值反馈，不能只有剧情没有玩法影响。

3. **鸦片发现弧**是本作最大卖点，必须保证层层递进的节奏感。5个时间时段中，深夜时段是高风险高回报时段——所有发现弧的关键节点都发生在深夜。

4. **交情五档 + 修正**为现行模型（见 `05_关系档案`）。Demo 可先做交情分+信任+疑心；忌惮后置。

5. **柳如烟的角色定位**要小心处理——她是操纵工具但也是人，不能写成纯工具人。她的纠结、愧疚、恐惧要让玩家感同身受。

6. **嫌疑值与信任度的平衡**是数值设计重点——不能让玩家随便操作就暴毙，也不能毫无惩罚。

7. **洋人介入流（邪恶路线）**：隐忍线是"复仇但留在体制内"，跳槽线是"复仇但用商业手段"，洋人介入线是"背叛体制、沦为洋人搜刮中国文物的买办、延续鸦片贸易"。1890年清廷无文物出口管制法律，洋人收购古董合法，但"合法的恶"比"违法的恶"更让人纠结——主角不是在犯法，是在出卖文化遗产。Demo只做到"与洋人接洽成功"。

8. **洋人介入流的前置条件**：Day 5洋人第一次考察为Day 7路线C选择提供认知基础。Day 12-14第二次考察让洋人对钱记的评估深入。Day 16钱子安鲁莽事件是路线C的核心行动——但玩家必须先通过鸦片发现弧了解到"庆大人"的存在（情报值≥35，已发现账房密账），才能理解钱子安"截货"行为的后果。

9. **钱子安鲁莽事件三选项的设计意图**：
   - 选项A（暗中阻止+自己接手护送）= 洋人介入流必经之路
   - 选项B（告密钱德茂）= 隐忍离间流加速器——代价是疑心+20，但 meter.father_son−25，性价比极高
   - 选项C（放任不管）= 最被动选择——父子决裂但主角无筹码，结局质量最差

10. **伙计支持度系统**：玩家需要通过日常行动（帮忙干活、请喝酒、送小钱、替人背锅）在Day 8-15期间提前积累中层/下层伙计支持度，到Day 16拦截行动时才能调动人手。这给玩家一个"隐忍期"的明确目标——不是瞎等，而是经营人脉。

11. **5时段系统**：比3时段更丰富，也给深夜行动更多权重。深夜是唯一可以偷听、潜入的时段，但每次深夜行动必然增加嫌疑值——玩家必须在"情报收益"和"嫌疑风险"之间权衡。
