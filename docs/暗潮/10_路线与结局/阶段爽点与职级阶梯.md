## 1. 设计铁律

1. **埋债 → 兑现**：羞辱必进恩怨账；之后必有当面清算窗（罚或恕）。
2. **位子先变，再谈大钱**：先改称呼 / 站位 / 可进之屋，再改月例与油水。
3. **爽点分轨**：情报爽 ≠ 人脉爽 ≠ 阴谋爽 ≠ 商业爽 ≠ 清算爽；同日不抢戏。
4. **升阶四件套**（缺一不可）：公开仪式 · 权限变化 · 银钱口径 · 恩怨兑现窗。

## 3. 三章情绪合同

| 章 | 建议长度 | 职级目标 | 情绪合同 | 章末大奖 |
|---|---|---|---|---|
| 一 · 被踩 | ~10–14 日 | 学徒 | 希望 → 屈辱 → 立誓 | 恩怨账建立 + E009 路线立旗 |
| 二 · 摸刀 | ~16–22 日 | **外场** | 情报优势 → 位子变化 | E020 升阶 + E021 轻清算 |
| 三 · 翻盘 | ~18–24 日 | **跑街** + 后堂钩 | 阴谋兑现 → 大清算 | E022 子安清算 + E018 任命 + 后堂开门 |

合计约 **45–60 日** 可跑完 A 线示范弧；实现可压缩/拉长，**不得删升阶四件套与清算双极**。

## 4. 分章爽点（A 线示范）

### 第一章 · 被踩

| 节点 | 爽/痛 | 说明 |
|---|---|---|
| E001–E002 | 温 | 满师希望、婚事压力 |
| E004–E006 | 痛·埋债 | 子安轻慢、搁置升职 → `grudge_*` |
| E008 | 痛·主债 | 盯如烟 → `grudge_zian_fiancee` |
| E009 | **立誓爽** | 决心落地；给出「下一阶小目标」提示 |

### 第二章 · 摸刀

| 节点 | 爽点类型 | 说明 |
|---|---|---|
| E010–E013 | 情报爽 | 发现弧；E019 用情报当面压人一次 |
| E020 | **职级爽** | 升外场仪式四件套 |
| E021 | **清算爽（轻）** | 看客或轻量子安；罚/恕 |
| 自由日 | 经营爽 | 人脉/支持/信用铺路 |

### 第三章 · 翻盘

| 节点 | 爽点类型 | 说明 |
|---|---|---|
| E014–E016 | 阴谋爽 | 鲁莽、挑拨 → 可见权力位移 |
| E015 | 认知爽 | 鸦片真相抬高赌注 |
| E022 | **清算爽（主）** | 子安婚事债；罚/恕必选 |
| E018A | **职级爽（大）** | 跑街任命 + 未兑现恩怨结算提示 |
| 后堂旁白 | 钩子 | `player_rank → houtang` 预告或软解锁 |

## 5. 升阶四件套检查表（写事件必勾）

- [ ] **仪式**：前堂/聚丰/洋行公开宣布或等价场面  
- [ ] **权限**：新热区 / 新 ACT / 新情报源至少一项  
- [ ] **银钱**：月例档或赏钱口径变化（禁止只写无叙事的裸 `+N`）
