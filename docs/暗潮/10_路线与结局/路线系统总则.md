# 路线系统总则

> 本文件只定义“路线”作为玩法结构怎么工作，不绑定《暗潮》当前三条路线的具体剧情。  
> 《暗潮》本体映射见 [`暗潮路线实例映射.md`](暗潮路线实例映射.md)。

---

## 1. 路线是什么

路线不是一次选择后的死锁分支，而是：

- 一组价值倾向
- 一组资源获取方式
- 一组主爽槽位优先级
- 一组结局落点偏好

---

## 2. 路线系统至少要回答

1. 玩家靠什么上位  
2. 玩家用什么资源推进  
3. 每阶段哪类主爽最代表这条路  
4. 失败时以什么方式塌掉  
5. 章终身份如何落点  

---

## 3. 路线与主爽槽位

建议每条路线至少接入三类槽位：

- 中段抬位槽位
- 中段第一次还手槽位
- 后段主清算槽位

路线系统定义“需要有这些槽位”；具体战役再决定这些槽位由哪些事件承接。

---

## 4. 路线与混搭

路线不一定互斥。  
但在同一阶段的主爽槽位里，默认只应有一个主胜出者。

因此系统上要区分：

- 路线倾向可共存
- 主爽事件不可并播

《暗潮》本体混搭细则见下方附录；B/C 主爽对位见 [`BC路线爽点映射.md`](BC路线爽点映射.md)。

---

## 5. 路线系统负责什么

- 定义路线如何推进
- 定义路线如何混搭
- 定义路线落点需要什么类型的槽位

路线系统不负责：

- 某条路线在某一天发生什么
- 某个角色在哪条路线说了哪句台词
- 某个战役里具体哪一场是章终判定

这些属于战役实例层。

---

## 6. 成功标准

- 路线差异首先体现在“你靠什么上位”，而不是只换一套对白。  
- 同一战役可同时存在路线倾向与主爽互斥，不相互矛盾。  
- 新 DLC 若要新增第四条路线，应能复用相同槽位结构，而不必推翻全部命名。  

---

## 附录 A · 《暗潮》混搭规则（战役实例）

```yaml
ROUTE_MIXING_RULES:
  - 三条不互斥，可同时推进
  - 先隐忍积情报(章一–章二) 再跳槽(章二–章三) ✓
  - 嫌疑过高可转向洋人线 ✓
  - 一边隐忍一边经营洋人 ✓
  - special:
      if: { qing_impression: ">=30", bradley_impression: ">=30" }
      then: 关闭隐忍线「正义复仇」分支
      else: 该分支仍开放
  - 跳槽线始终可混搭（赵利益优先）
```

E009 选择只是**初始加成 + 旗标**，不是锁死唯一路线。

每阶段主爽点分轨见 [`BC路线爽点映射.md`](BC路线爽点映射.md)：混搭时勿让三线同日抢仪式戏。  
旧 Demo 口吻里的 Day7–30 一律按三章开放日程理解，权威见 [`../09_日程表/`](../09_日程表/README.md)。
