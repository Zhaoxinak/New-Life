```yaml
ROUTE_MIXING_RULES:
  - 三条不互斥，可同时推进
  - 先隐忍积情报(Day7-15) 再跳槽(Day16-30) ✓
  - 嫌疑过高可转向洋人线 ✓
  - 一边隐忍一边经营洋人 ✓
  - special:
      if: { qing_impression: ">=30", bradley_impression: ">=30" }
      then: 关闭隐忍线「正义复仇」分支
      else: 该分支仍开放
  - 跳槽线始终可混搭（赵利益优先）
```

Day7 选择只是**初始加成 + 旗标**，不是锁死唯一路线。

每阶段主爽点分轨见 [`BC路线爽点映射.md`](BC路线爽点映射.md)：混搭时勿让三线同日抢仪式戏。
