## 3. 混搭规则在暗潮中的落地

1. Day7 选择只决定初始倾向，不自动锁死最终路线。  
2. 同阶段主爽只播一个，避免同轮并播多个升阶或清算仪式。  
3. 未被选中的路线铺垫可保留数值意义，但不抢主仪式戏。

## 4. 与其他系统的连接

| 系统 | 在暗潮中的连接方式 |
|---|---|
| 职级 | A 线主要体现为 `player_rank` 推进；B/C 更多体现为外部位子与代理身份 |
| 清算 | 三条路线都有清算，但方式不同 |
| 金融 | 三线的“钱从哪里来”完全不同 |
| 结局 | 章终要给出不同身份落点，而不是只换成败台词 |
