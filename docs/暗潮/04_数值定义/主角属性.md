# 主角属性

> 存档字段；档案只给定义与初值。

## 五大核心属性

| ID | 名 | 初值 | 作用 |
|---|---|---|---|
| `stat_money` | 金钱（两） | 30 | 生计、体面、打点、买情报、贿赂、变现 |
| `stat_intel` | 情报值 | 5 | 计谋、发现弧、鲁莽事件门槛 |
| `stat_network` | 人脉声望 | 15 | 高阶接触、成功率 |
| `stat_trust_firm` | 商行信任度 | 40 | 职权；≥50 跑街 |
| `stat_suspicion` | 嫌疑值 | 0 | 惩罚阶梯 |

## 金钱的设计定位

`stat_money` 不只是“能买什么”，更是 Demo 里最直接的现实压力：

- **生计**：饭钱、生活费、偶发急用；没钱就没得体面
- **体面**：办喜事、请客、送礼、维持“像个有奔头的人”
- **门路**：茶楼买消息、打点伙计、钱庄往来、竞品接触
- **风险**：脏钱来得快，但会抬高嫌疑、扭曲路线选择

同样是十两银子，对不同场景意义不同：

- 对林瑞生，是几天的活路、婚事能不能往前推一步
- 对柳如烟，是敢不敢得罪钱家、敢不敢退礼
- 对钱子安，是“二十两月例”背后的羞辱
- 对钱德茂，是能不能继续把上下游都喂饱

## 信用层（金融系统）

| ID | 名 | 初值 | 作用 |
|---|---|---|---|
| `stat_credit_bank` | 票号信用 | 0 | 借贷、展期、高阶往来、柜面态度 |
| `stat_credit_market` | 街市信用 | 0 | 竞品报价、消息深度、被人当不当回事 |
| `stat_credit_foreign` | 洋行信用 | 0 | 邀约、谈价深度、分成资格 |

说明：

- 这三项都不是现金，不替代 `stat_money`
- 它们描述的是“别人愿不愿继续和你做更深的交易”
- Demo 里优先挂在 `R005` / `R006` / `R009` / `E017` / `E018C`

## 获取 / 消耗（摘要）

| 属性 | 获取 | 消耗 |
|---|---|---|
| 金钱 | 打工、差事、外快、竞品资助、变现 | 请客、收买、利息、送礼、生活费 |
| 情报 | 偷听文件、伙计、如烟、茶楼 | 出售、散布、要挟使用 |
| 人脉 | 请客、办事、商会、舆论 | 求人、脱罪、引荐 |
| 信任 | 超额差事、背锅、伪装忠诚 | 失误、暴露、小报告 |
| 嫌疑 | 失败、目击、敏感区、深夜 | 休息、低调、收买、关系 |

## 金钱来路（叙事口径）

| 来路 | 说明 | 风险 |
|---|---|---|
| 月例 / 工钱 | 最干净，最慢 | 易受升降职影响 |
| 差事赏钱 | 体面收入，证明“有用” | 依赖东家与人情 |
| 打点回扣 | 灰色收入 | 会腐蚀关系、埋把柄 |
| 竞品资助 | 跳槽线前置甜头 | 会被钱记视为吃里扒外 |
| 账外变现 | 如 E015C | 来得最快，也最脏 |

## 金钱消耗（戏剧口径）

| 去向 | 说明 |
|---|---|
| 过日子 | 日常吃穿住用；钱少时先伤体面，再伤行动 |
| 情面 | 请客、送礼、办喜事、退礼 |
| 经营 | 买消息、收买、跑钱庄、拉拢伙计 |
| 保命 | 封口、脱罪、临时周转 |

## 金钱与路线

- **隐忍线**：钱是“熬”的成本。你要维持体面，才能继续在钱记做人。
- **跳槽线**：钱是“筹码”的证明。穷得叮当响的人，很难被赵鸿运当回事。
- **洋人线**：钱不是目的，而是结果。先有价值，后有分成；先有门路，后有银子。
