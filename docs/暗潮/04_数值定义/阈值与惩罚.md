# 阈值与惩罚

## 主角属性阈值

| 属性 | 阈值 | 效果 |
|---|---|---|
| 金钱 | <10 | 断炊边缘；部分体面型行动文案降级，婚事/请客压力显著 |
| 金钱 | 10–19 | 拮据；日常行动可做，但“打点/请客/送礼”压力很高 |
| 金钱 | 20–49 | 周转；能维持体面，但遇到突发礼金/借贷容易伤筋动骨 |
| 金钱 | 50–99 | 宽裕；钱庄、茶楼、人情往来更顺手 |
| 金钱 | ≥100 | 解锁高阶行动；也更容易被人盯上“你最近手头很活” |
| 情报 | ≥10 / 25 / 35 / 40 | 鸦片弧层 & E014 |
| 人脉 | ≥20 / 30 / 40 | 各阶接触 |
| 商行信任 | ≥50 | 跑街 |
| 嫌疑 | ≥30 | F001 被敲打 |
| 嫌疑 | ≥50（且信任≤20） | F002 降职 |
| 嫌疑 | ≥70 | F003 开除 |
| 嫌疑 | ≥100 | 失败结局 |

## 洋人线阈值

| 条件 | 效果 |
|---|---|
| 白瑞德印象 ≥20 | R009 洋行邀约（`loc_03` → 导向 `loc_05`） |
| 白瑞德印象 ≥30 | `loc_05` 正式会谈门槛（E018C 数值门之一） |
| 庆大人印象 ≥30 | 手书/狐假虎威可用 |
| 中层&下层支持均 ≥40 | E014 选项 A 可执行 |
| 庆印象≥30 且 白印象≥30 | 关闭隐忍「正义复仇」分支 |

## 信用阈值

| 条件 | 效果 |
|---|---|
| `stat_credit_bank` ≥ 10 | 票号不再把你当零碎客 |
| `stat_credit_bank` ≥ 20 | 展期 / 高阶往来更自然 |
| `stat_credit_market` ≥ 10 | R005 之后更像“可继续报价的人” |
| `stat_credit_market` ≥ 20 | 跳槽线更容易谈启动位子与甜头 |
| `stat_credit_foreign` ≥ 5 | R009 后被洋行视为可继续观察的本地门路 |
| `stat_credit_foreign` ≥ 20 | E018C 后进入“可持续代理关系” |

## 金钱的叙事阈值

| 档 | 金额 | 叙事状态 | 常见后果 |
|---|---|---|---|
| 断炊 | 0–9 | 活路优先 | 更容易接受脏钱、典当、低头求人 |
| 拮据 | 10–19 | 勉强撑门面 | 婚事拖延、请客心疼、退礼更难 |
| 周转 | 20–49 | 还像个正经过日子的 | 能买消息、跑人情，但不能频繁撒钱 |
| 宽裕 | 50–99 | 有资格被当“能办事的人”看 | 解锁票号高阶、谈资更足 |
| 活钱厚 | ≥100 | 不缺急用银 | 既能铺路，也会招来猜测与觊觎 |

## 婚事 / 体面压力

| 条件 | 效果 |
|---|---|
| `flag_need_marriage_fund == true` | 玩家已明确意识到聘礼/铺盖/酒席钱压力存在 |
| `flag_need_marriage_fund == true` 且 `stat_money < 20` | `ACT_06` 更容易表现为空手相陪；`ACT_08` 更像拖婚期 |
| `flag_need_marriage_fund == true` 且 `stat_money >= 30` | 可通过汇兑、赠礼、备婚事叙事逐步缓解 |

## 金钱与人物压力

- **林瑞生**：钱少，婚事就只是空口白话；升跑街不只是升面子，是升月例和活路。
- **柳如烟**：退礼不是拒绝一个男人，而是冒着得罪钱家的风险丢掉“靠山”。
- **钱子安**：月例二十两并不穷，真正刺痛他的是“父亲不把钱和权给他”。
- **钱德茂**：会给赏钱，但绝不让下面的人摸到账外大钱。
- **白瑞德 / 赵鸿运**：看重的不是你穷不穷，而是你值不值得投钱。
