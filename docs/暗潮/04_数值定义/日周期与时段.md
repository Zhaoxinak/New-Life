# 日周期与时段

```yaml
DAILY_TIME_SLOTS:
  morning:    { index: 1, clock: "06:00-10:00", note: "开张、正式差事、商务" }
  noon:       { index: 2, clock: "10:00-14:00", note: "短暂接触、传话、快打探" }
  afternoon:  { index: 3, clock: "14:00-18:00", note: "外出、社交、后院" }
  evening:    { index: 4, clock: "18:00-22:00", note: "茶楼酒馆、私人、如烟" }
  late_night: { index: 5, clock: "22:00-02:00", note: "高风险：偷听潜入暗交易" }
```

规则：

- 每时段选 **1 地点 × 1 行动**（或触发固定事件占用该时段）  
- `[休息]` 时段不可自由行动，默认 `loc_06`  
- 深夜行动 **必然** 推高嫌疑（具体见行动 / tick）
