## 一句话

**1890–1911，天津。** 你在出口商号 **通源号** 当学徒 **沈阿木**，从搬木头爬到管事，最终瞄着 **号东**。  
门面是木材与土货洋货；背地里货栈夹带 **洋药/土膏**。明账养脸面，暗账救坏季——升职等于看见更深的账。

---

## 你玩什么

| 节奏 | 内容 |
|---|---|
| 白天 | 去本号 / 货栈 / 茶楼等做事（正道跑腿对账，歪门夹带打点） |
| 季末 | **季会**：报绩、问责、人事；交情决定谁保你、谁抛你 |
| 正道 | 勤能升到 **管事**，再往上有 **软顶**——光加班当不上掌柜 |
| 歪门 | 加暗救季更快，但 **heat / 把柄 / 穿帮** 会反噬 |
| 破格 | 会馆外名、洋行外利、危季变局——才是管事之上的门 |

**核心爽感：** 门面越正经，暗里越悬；先搬木头，再发现舱里夹的不是木。

## Demo 会演什么（展示包）

不做号东终局。大约 **6～8 季**，把这条弧演明白：

```
搬木满师 → 上柜对账 → 入座管事 → 软顶出门
→ 坏季加暗救银根 → 危季穿帮甩锅 → 摸到破格窗（或开革）
```

三场硬戏提纲：[`Demo/季会样例.md`](Demo/季会样例.md)（A 入座 / B 加暗 / C 穿帮）。  
节拍与验收：[`Demo/切片与验收.md`](Demo/切片与验收.md)。

正式版同一套规矩，**没有强制电影轨**，自己在津门活成号东或别的样子 → [`正式版/`](正式版/README.md)。
