# Demo · 引导策略 【草案】

> 解决：展示包如何 **保证撞上 A/B/C**，又不做成强制电影轨。  
> 正式版 **不采用** 本页的「保底脚本」，只保留共用规则。

---

## 1. 定调

| 原则 | 说明 |
|---|---|
| **软引导为主** | 口风、账房知会、师父叮嘱、茶楼传闻 |
| **保底为辅** | 若玩家一直避开，到指定季用「天气/事件」把议题送上门 |
| **不强制传送** | 不把人拽进建筑；最多「今日宜去货栈」类提示 |
| **样例可变形** | A/B/C 的议题固定，选项与谁站队随交情变 |

---

## 2. 三场硬戏如何「自然撞上」

### 样例 A · 入座（约第 2～3 季）

| 手段 | 内容 |
|---|---|
| 软 | 郑德海：「该让掌柜看看你了」；柜上事增多 |
| 条件 | 升迁条件将满时，钱伯衡在本号多露脸 |
| 保底 | 第 3 季季会人事窗：若已达柜伙且绩够，**强制进入提名戏**（仍可选歪门抢功/沉默） |

### 样例 B · 加暗救季（管事后第 1～2 个坏季）

| 手段 | 内容 |
|---|---|
| 软 | 木市文案变冷；钱伯衡叹气；茶楼有人说「南边那笔」 |
| 条件 | `firm_bright`/`cash` 掉进坏季阈值（见时间气血） |
| 保底 | **升管事后第一次坏季**，议去留必出现「加南边货 vs 砍摊」二项（可多一个甩锅选项） |
| 注意 | 若玩家从未解锁暗线知情：先用「多出来的箱子」短事件揭一层，再开会 |

### 样例 C · 穿帮危季（加暗后 1～2 季内）

| 手段 | 内容 |
|---|---|
| 软 | 褚三在货栈附近晃；孙墨林说账对不齐；马裕泰茶楼阴阳 |
| 条件 | 若样例 B 选了加暗 → `heat` 抬升；或设 `flag_demo_dark_used` |
| 保底 | 加暗后 **不晚于第 2 次季会** 进入危季脚本（可提前若 heat 已爆） |
| 若玩家样例 B 硬扛未加暗 | 改走「银根断裂 / 对家落井」危季变体，仍练抛人与交情，不强制洋药穿帮 |

---

## 3. 提示层（UI/文案，不锁操作）

- 季初：一句话时令 + 号里气氛  
- 会前一日：账房知会（天气预告）  
- 软顶后：HUD/口风「会馆 / 钱庄或许用得上」  
- 可忽略；忽略则只靠保底季会，不惩罚「坏档」以外的额外死亡

---

## 4. 正式版禁用清单

- 不按「第 N 季必出样例 B」排程  
- 不用 `flag_demo_*` 保底旗  
- 坏季/危季只由气血与玩家行为触发
