## 1. 一句话

**《通源入局》**：沈阿木从学徒做到管事、撞上软顶，经历「入座 → 加暗救季 → 穿帮危季」；摸到破格门槛即可收展，**不做到号东**。

---

## 2. 内容白名单

### 建筑

| 级别 | 建筑 |
|---|---|
| 必做 P0 | 本号、货栈码头、会馆、钱庄、茶楼、公门 |
| 可浅 P1 | 报关（可并货栈）、洋行、对家 |
| 不做/极简 | 私宅（用下处）、京号、官场 |

### 暗货 / 明货

| 深做 | 夹带、洋药/土膏、货情倒卖；木摊+皮毛摊 |
|---|---|
| 事件一句 | 私盐 |
| 不做 | 人口掮客、硝磺军火专线 |

### 职级与结局

- 正道 1→4 完整；摸到 4→5 破格窗即可收展  
- 不做号东议东终局  
- 失败：开革短终局（好懂）→ 待补专页  

卡司以 [`../共用/字号与卡司.md`](../共用/字号与卡司.md) 为准；危季露 1 股东即可。

## 4. 进度节拍（软引导，非强制传送）

靠 [`引导策略.md`](引导策略.md) 软撞上。

| 阶段 | 职级 | 关键体验 |
|---|---|---|
| 开局～满师 | 学徒→伙计 | 搬木、赔累、师徒 |

| 入座 | →管事 | **样例 A** |
| 软顶 | 管事 | 喜季不提掌柜；出门会馆/钱庄 |
| 坏季 | 管事 | **样例 B** 加暗 |
| 危季 | 管事 | **样例 C** 穿帮 |
| 收束 | — | 破格窗或失败 |

## 5. 验收（代入感 · 实机勾选）

- [ ] 升职当场改称呼  
- [ ] 门外 → 入座，座位变化明显  
- [ ] 加暗后货栈「多箱子」余波  
- [ ] 穿帮时交情档改变谁保你/谁抛你  
- [ ] 软顶后知道要出门，不是再加班  
- [ ] 开革失败短终局好懂
