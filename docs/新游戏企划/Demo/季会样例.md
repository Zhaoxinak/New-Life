### 样例 A · 第一次入座（柜伙→管事）

| 项 | 内容 |
|---|---|
| 天气 | 平季或小喜（`bright` 尚可） |
| 你的职级 | 会前仍是柜伙后排；人事窗宣布升管事 |
| 真刀议题 | 木摊要不要加人；刘成业暗示你「不够资格」 |
| 关键选择 | 正道：拿实绩顶回去；歪门：揭刘一笔小错抢印象；沉默让钱伯衡罩 |
| 收束 | 钱伯衡提名，赵东家点头；**当场改口「沈管事」**；你正席有座 |
| 余波 | 刘成业交情↓；郑德海交情↑；下季起有分管候选 |

### 样例 B · 加暗救季（管事 · 坏季）

| 项 | 内容 |
|---|---|
| 天气 | **坏季**（木市瘦、`cash` 紧） |
| 真刀议题 | 「加一船南边货（洋药/土膏）补银根？」vs 砍副摊/削月钱 |
| 在场压力 | 王股东（虚）要总数；孙墨林不安；钱伯衡看你眼色（若你管事有声量） |
| 关键选择 | **主张加暗** / **主张硬扛砍摊** / **推给刘成业去脏**（歪） |
| 若加暗 | `dark↑ cash↑ heat↑`；会后货栈「多箱」事件；鲍有财交情变化 |
| 若硬扛 | 可能砍到你的摊或吴小顺月钱；明誉在，银根更紧；逼你出门找会馆外利 |
| 余波 | 软顶叙事可并行：即使救季成功，也不自动升掌柜 |

### 样例 C · 穿帮危季（管事）

| 项 | 内容 |
|---|---|
| 天气 | **危季**（`heat` 高或单货不符） |
| 开场 | 门外脚步/褚三影；账对不上或栈上被拿一箱 |
| 真刀议题 | 谁顶罪；暗线收不收 |
| 交情决策 | 刘成业若仇隙/不睦 → 优先点你；郑德海厚交/相善 → 力保；钱伯衡按号内利害 |
| 关键选择 | 自己认（压力/把柄结构变）/ 甩刘 / 甩栈伙 / 买通褚三压事（银钱+人情条） |
| 收束分支 | 保住→暗线收缩、钱伯衡位子不稳（**破格窗**）；抛你→开革失败终局；抛刘→仇隙锁定 |
| 余波 | 会馆脸面伤；公门线激活；对家马裕泰茶楼放风 |
