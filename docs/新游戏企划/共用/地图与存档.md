## 4. 存档应有什么

| 层 | 内容 |
|---|---|
| meta | 存档槽、游戏日、季、时段、版本号 |
| player / npcs | 人物全字段 |
| relations | 边表（交情分、信任…） |
| firm | 五气血 + 各摊绩 |
| inventory | 信物列表 |
| flags | 下表 |
| intel | 已知情报 id |

## 5. 旗标命名（共用）

| 旗 | 值 | 含义 |
|---|---|---|
| `know_dark` | 0/1/2 | 暗账知情 |
| `flag_soft_cap` | 0/1 | 管事软顶已说破 |
| `flag_big_loss` | 0/1 | 大赔 |
| `flag_bad_ledger` | 0/1 | 重大错账 |
| `flag_bust_risk` | 0/1 | 穿帮风险高 |
| `flag_exposed` | 0/1 | 已穿帮 |
| `flag_promoted_N` | 0/1 | 某阶晋升（可选） |
| `intel_false` | id… | 假情报集合 |
| `route_assigned` | route_id / null | 当前分管 |
| `senior_rank` | 0/1 | 资深标签 |

## 6. Demo 专用（正式版禁用）

| 旗 | 含义 |
|---|---|
| `flag_demo_*` | 展示保底；正式版存档不得出现 |

共用逻辑读 `flag_demo_*` 须 Demo 隔离。
