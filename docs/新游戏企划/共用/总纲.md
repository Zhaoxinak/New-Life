## 3. 字号生意：明业与暗业

> 字号对外是体面出口行；对内两套账。  
> **明业养名声与长期货路；暗业补银根与坏季**——都进主线，不是支线小游戏。

### 3.1 设定一句话

**明：** 津门出口商号，**木材为主、土货洋货齐全**，走洋关、会馆、船栈，门面光鲜。  
**暗：** 借货栈、舱单、木船做夹带与见不得光的买卖；品类不止一样，赚快银、买把柄。

字号：**通源号**【草案】。详见 [`字号与卡司.md`](字号与卡司.md)。

### 3.2 明业 / 明货（产品线放全）

贴晚清天津口岸。**木材是门面主货**，其余明货都做，用来丰富字号、分散市况，并给不同职级「管摊」空间。

#### 出口 / 集散（土货）

| 明货 | 做什么 | 账面味道 | 主线用途 |
|---|---|---|---|
| **木材（主门面）** | 腹地/关外木经津集散，报关装船出口或转沪 | 稳、慢、看船期市价 | 门面身份；学徒伙计主活 |
| **皮毛 / 羊毛 / 驼毛** | 口外、西北货经津出口 | 量大时很肥；看内地通路 | 正道大单；会馆话头 |
| **猪鬃** | 刷业原料出口 | 利不暴，走得勤 | 管事可独管一摊 |
| **棉花** | 华北棉出口/转口 | 随年成起伏大 | 坏木市时的正道补 |
| **干果**（枣、杏仁等） | 传统土产出口 | 季强、额不大 | 低阶可经手的「干净货」 |
| **药材** | 西宁大黄等经津 | 认货眼力；信誉货 | 柜伙验货、识货线 |
| **草帽辫** | 出口欧美常见货 | 曾是大口；市况会变 | 时代感；可兴可衰 |
| **豆货 / 兽骨等** | 杂项土货 | 填舱、吃散利 | 丰富舱单，不必深玩 |

#### 回程 / 入口（洋货）

| 明货 | 做什么 | 账面味道 | 主线用途 |
|---|---|---|---|
| **洋布 / 洋纱** | 代销或自营入口分销 | 体面、走量大 | 接触洋行；正道破格 |
| **五金** | 钉铁器材等 | 稳 | 工料、货栈消耗联动 |
| **煤油** | 入口分销 | 利清、洋行味重 | 回程舱；租界面孔 |
| **火柴 / 杂洋货** | 小额入口 | 散利 | 日常丰富感 |

#### 明业服务（不算货，但是生意）

| 项 | 做什么 | 主线用途 |
|---|---|---|
| **货栈** | 代存代装 | 明暗都经过这里 |
| **船运 / 订舱代理** | 代订舱位、佣金 | 有舱位才有夹带窗口 |
| **报关代办** | 走洋关手续 | 舱单真假的第一现场 |

> 玩法上不必每种货一套系统：用 **货路/摊**（木摊、毛摊、棉摊…）挂在管事职级上即可；市况好坏进季账。

### 3.3 暗业 / 暗货（放全，仍挂商号壳）

通道是货栈与舱单；**洋药/土膏是暴利主菜**，其余暗货一并有，方便歪门与季会花样。

| 暗货 / 暗事 | 怎么藏 | 赚什么 | 风险 | 主线用途 |
|---|---|---|---|---|
| **夹带走私**（手法） | 少报舱单、瞒厘金关税、木箱夹层 | 每船可蹭 | 洋关、栈伙 | 歪门默认技；各类暗货的「通道」 |
| **洋药 / 土膏** | 随木箱、压舱 | **暴利核心** | 公门、租界、海关 | 坏季救命；穿帮=号级大危机 |
| **私盐** | 木船顺路、河海交接 | 稳、地盘硬 | 盐巡、地头 | 第二暗线；管事货路 |
| **硝磺** | 随五金/煤油回程夹 | 军政敏感利 | 查得凶 | 比土膏更「犯官」；高风险选项 |
| **洋枪 / 军火私售** | 拆件藏货栈深处 | 暴利+人情 | 截获、追责 | 与军需暗单近；可后置 |
| **军需暗单** | 战事年挂「木货/五金」壳 | 暴利+人情 | 战败清算 | **后期预留**（甲午等） |
| **赃货销路** | 经货栈「洗」成土货出门 | 中利 | 公门顺藤摸瓜 | 歪门人际；对家可栽你 |
| ~~人口掮客~~ | — | — | — | **【Demo 砍】** 不进内容 |
| **假契 / 阴阳合同** | 明一份暗一份 | 短期填账 | 洋行、会馆、钱庄 | 毁门面；正道对手可打 |
| **灌水木 / 以次充好** | 充好木出口 | 短期填明账 | 退货、毁誉 | 专砸木材门面 |
| **货情倒卖** | 卖船期、库存、暗货行踪 | 不占舱 | 暴露则无友 | 季会穿帮好戏 |
| **高利私账** | 用号名或暗银放贷 | 利滚利 | 闹人命、挤兑传言 | 钱庄线联动；号东期危险 |

> 文案对白：洋药/土膏等一律当时叫法。  
> 系统上可做成 **暗货目录**，掌柜调「本季走哪几样」；不必一上来全深度模拟。  
> Demo 深做：夹带 + 洋药/土膏 + 货情；私盐可事件化；其余后置。

### 3.3.1 洋药 / 土膏（主菜，点到为止）

- **壳：** 木材与货栈——先查木，深查才露膏。  
- **谁知：** 低阶见多箱；柜伙觉账不对；管事可管一船；掌柜定走不走；号东担总。  
- **正歪：** 正道少碰；歪门加船救季；穿帮可抛人顶罪。  
- **不做：** 单独做成专项模拟经营大全。

### 3.4 两套账，怎么进主线

| 账 | 谁日常看得见 | 季会怎么用 |
|---|---|---|
| **明账** | 柜伙起：各色明货、佣金 | 宣「本季哪几摊肥了」；养会馆名声 |
| **暗账** | 管事起分管一条；掌柜看配比；号东担总 | 银根窟窿常靠暗账堵；也可被当场捅破 |
| **合并观感** | 低阶只觉「号里怎么又发钱了」 | 众东要的是「总数好看」；不管脏不脏——直到出事 |

**职级 = 看见的深度：**

| 职级 | 对生意的认知 |
|---|---|
| 学徒 | 只知搬木头、守号规 |
| 伙计 | 跑明单；偶遇「多出来的箱子」 |
| 柜伙 | 对上明账；察觉流水「对不齐」 |
| 管事 | 可管一条明货路，或一条暗线 |
| 掌柜 | 调 **明暗配比**：偏明稳、偏暗险 |
| 号东 | 定还做不做暗业；出事时站队与顶罪 |

### 3.5 明暗如何拖季账

| 情况 | 季会后果 |
|---|---|
| 木市好 | 正道升迁、谈扩摊；可少做暗 |
| 木市坏 | **核心抉择**：加暗救季 vs 硬扛挨砍 |
| 暗业赚翻 | 众东开心；把柄+1 |
| 暗业穿帮 | 裁人、换掌柜、关号；抛人抵罪 **或** 意外破格窗 |
| 只做明、硬扛坏季 | 裁摊；逼你出门找外路破格 |

对齐：正道≈养明；歪门≈加暗；破格筹码可以是干净大单，也可以是「暗账救过号」。

## 4. 职级（六阶）

### 4.1 总则

> **详档与晋升/降级：** [`职级与晋升/README.md`](职级与晋升/README.md)

软顶=管事；正道/歪门与明暗咬合；季会见 §5。

```
正道：学徒 → 伙计 → 柜伙 → 管事 ■软顶
破格：              管事 ⇢ 掌柜 ⇢ 号东
```

### 4.2 一览

| 阶 | 职级 | 一句话 |
|---|---|---|
| 1 | 学徒 | 搬木、学规矩 |
| 2 | 伙计 | 跑明单 |
| 3 | 柜伙 | 上柜碰明账 |
| 4 | 管事 | 管一摊（明或暗）；正道尽头 |
| 5 | 掌柜 | 调明暗配比（破格） |
| 6 | 号东 | 坐东；定暗业存废 |

### 4.3 福利 · 权力 · 义务 · 压力

| 阶 | 福利 | 权力 | 义务 | 压力 |
|---|---|---|---|---|
| 学徒 | 管饭住处 | 无 | 守规 | 体罚、被逐 |
| 伙计 | 月钱 | 接小单 | 跑码头；丢货赔 | 赔累、砸锅 |
| 柜伙 | 月钱涨 | 对账议价 | 账清脸面 | 错账；瞥见暗流 |
| 管事 | 分成 | 管货路、荐人 | 整摊盈亏 | 摊亏；**暗线爆了算你** |
| 掌柜 | 高分成 | 拍板、调人 | 全号名声 | 代过；**明暗配比赌错** |
| 号东 | 股权分红 | 定高层分号 | 存亡站队 | 倾家；**暗业总责** |

### 4.4 谁提拔 / 正歪 / 破格

- 提拔链：师父 → 管事/账房 → 掌柜+号东淡点头 → 破格+众东 → 股权场  
- 正道养明；歪门加暗；歪门买不到号东  
- →掌柜：会馆名 / 大单或暗救季 / 意外；→号东：必须进东  

### 4.5 外场与信物

外场：见 [`建筑企划/`](建筑企划/README.md)。不单开商店（置办并入茶楼）。  
信物：满师帖→荐保→账房条→份例→会馆帖/大单→钱庄票→股契；暗产黑账页、夹带条。

## 5. 季会（摘要）

> **共用规则：** [`季会企划.md`](季会企划.md)  
> **Demo 展示剧本：** [`../Demo/季会样例.md`](../Demo/季会样例.md)  
> **正式版：** 季会自由生成 → [`../正式版/长线.md`](../正式版/长线.md)

季会是主线发动机：每季一场戏，收束明暗季账、问责砍摊、宣布人事。  
职级决定你从门外听差到正席再到拍板。  
五段：开场定座 → 宣季账 → 问责表功 → 议去留 → 人事窗 → 余波。  
天气：平 / 喜 / 坏 / 危；坏季逼加暗，危季逼穿帮，人事窗接升迁与破格。

**时间骨：** 日常填满一季 → 开季会 → 下一季。
