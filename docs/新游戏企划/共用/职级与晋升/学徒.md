---

## 1. 名片

| 项 | 内容 |
|---|---|
| 职级码 | `1` |
| 古称 | 学徒 |
| 定位 | 号里最小一辈；饭碗系于守规与师父脸色 |
| 进项 | 管饭、下处；赏钱偶有（开局银钱约 8）；季俸见 [`职级附表.md`](职级附表.md) |
| 压力类型 | **体罚被逐** |
| Demo | 开局身份（沈阿木） |

---

## 2. 看见的深度

只知搬木头、守号规；**不知暗账**。  
撞见「多箱」只当怪事，除非事件强制揭一层。

---

## 3. 日常

货栈扛货、打扫、跟师学尺子与号规；夜在徒弟下处。

---

## 4. 权力 · 义务 · 福利

| 层 | 内容 |
|---|---|
| 权力 | 无分管；不能上柜碰账；不能对外代表字号 |
| 义务 | 听派活；丢货要挨；不得偷拿号里东西 |
| 福利 | 管饭、下处；偶得赏钱 |
| 分管摊 | 无；打工给集体亮色 |
| 暗线资格 | 无 |

---

## 5. 压力

> 总规：[`压力.md`](压力.md)

| 项 | 内容 |
|---|---|
| 类型 | **体罚被逐** |
| 怕什么 | 挨罚、被开革、当众辱师/受辱 |
| 加压 | 丢货、偷懒被抓、号规过、师父交情↓ |
| 缓解 | 休息、认错、师父相善、满师将近 |
| 高压表现 | 躲掌柜、话少、易被吓选歪门或乱认 |
