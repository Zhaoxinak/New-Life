# 号东（6）

> 上级：[`README.md`](README.md) · 压力：[`压力.md`](压力.md) · 晋升：[`晋升.md`](晋升.md) · 降级：[`降级.md`](降级.md)  
> **终局身份**（Demo 远影）。

---

## 1. 名片

| 项 | 内容 |
|---|---|
| 职级码 | `6` |
| 古称 | 号东 |
| 定位 | 字号存亡人格化；股权与族面 |
| 进项 | 东股分红为主（赵季堂 45%） |
| 压力类型 | **存亡** |
| Demo | 观礼/点头；不做议东终局 |

---

## 2. 看见的深度

定还做不做暗业；出事站队与顶罪总责。

---

## 3. 日常

少跑腿；喜季赏脸、危季观礼；众东场。

---

## 4. 权力 · 义务 · 福利

| 层 | 内容 |
|---|---|
| 权力 | 定高层；定暗业存废；议东权重；可换掌柜 |
| 义务 | 对众东与族人交代；倾家可发生 |
| 福利 | 东股分红 |
| 分管摊 | 无；脏事交掌柜 |
| 暗线资格 | 总责，可不亲自经手 |

---

## 5. 压力

> 总规：[`压力.md`](压力.md)

| 项 | 内容 |
|---|---|
| 类型 | **存亡** |
| 怕什么 | 关号、毁誉、族亲蒙羞 |
| 加压 | 危季、会馆点名、公门总案、众东逼宫 |
| 缓解 | 危转平、弃卒保号、站队过关 |
| 高压表现 | 「总数」更冷；可换掌柜、抛人

---
## 6. 可做行动

| 类型 | 例子 | 主本事 |
|---|---|---|
| 正 | 定总数调门、赏脸 | 口才、明誉 |
| 歪 | 默许/叫停暗业 | 存亡判断 |
| 人事 | 换掌柜、抛人最终点头 | 交情+股权政治 |

---

## 7. 季会

上首；一句「总数」可定天气；危季决定抛谁。

---
