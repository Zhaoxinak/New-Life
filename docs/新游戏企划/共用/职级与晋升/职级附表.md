## A. 月钱与份例

 进项种类

| 种类 | 谁有 | 何时发 | 说明 |
|---|---|---|---|
| **季俸** | 伙计起 | 每季初日（或季会后） | 死工资；学徒无 |
| **份例** | 管事 | 季会后按摊绩 | 有摊才有；削摊则 0 |
| **身股/东股分红** | 掌柜身股、号东东股 | 喜季或年结【Demo 简化：坏季不发】 | 见 [`../人物档案/通源号股权.md`](../人物档案/通源号股权.md) |
| **赏钱** | 任意 | 行动成功即时 | 跑成、表功 |
| **暗分成** | 经手暗线者 | 暗成功时 | 抬污名/heat；不进明账 |

管饭（学徒）不算银钱进项，但免「饿」类压力。

## 3. 管事份例（Demo）

分管明摊时，季会后：

```
份例 = floor( 本季该摊 route_perf / 5 )
```

| `route_perf` | 份例约 |
|---|---|
| 0–9 | 0 |
| 10–24 | 2～4 |
| 25–49 | 5～9 |
| 50–74 | 10～14 |
| 75–100 | 15～20 |

暗线分管：用 `dark_perf` 同公式，但 **份例进私囊时污名 +1～3**（叙事：来路不明）。

削摊：份例归零，季俸仍发 18。

## B. 季会发言权

## 1. 图例

| 符号 | 含义 |
|---|---|
| — | 不在场或无权限 |
| 听 | 能听见本段 |
| 说 | 可主动开口（选项） |
| 答 | 仅被点名时可答 |
| 决 | 对本拍议题有实质决定权/一票 |

学徒门外默认「听缝」；偷听全段 = 歪门另检。

---

## 2. 五拍 × 职级

### 2.1 定座

| 职级 | 权限 | 说明 |
|---|---|---|
| 学徒 | — / 听缝 | 传茶；不参与座次 |
| 伙计 | 听缝 | 偶被叫进屋站着 |
| 柜伙 | 听 | 看谁入席 |
| 管事 | 听·说 | 可争「今日先问谁的摊」 |
| 掌柜 | 听·说·**决** | 定议程顺序 |
| 号东 | 听·说·决 | 可一句话改议程 |

### 2.2 宣账

| 职级 | 权限 | 说明 |
|---|---|---|
| 学徒 | 听缝 | 听不清数字 |
| 伙计 | 听缝 / 答 | 被点名才对一单 |
| 柜伙 | 听·答·（有限）说 | 可纠 **一笔明账**；暗账多含糊 |
| 管事 | 听·说 | 对自己摊数字可辩 |
| 掌柜 | 听·说·决 | 定「怎么报」口径 |
| 号东 | 听·决 | 少说；要「总数」 |

账房（孙）宣读：职务权限，不单靠职级码。

### 2.3 问责

| 职级 | 权限 | 说明 |
|---|---|---|
| 学徒 | — / 答 | 极少被点；点到只能答 |
| 伙计 | 答 | 只答自己那单 |
| 柜伙 | 答·说 | 可帮腔或自辩账 |
| 管事 | 听·说 | 交摊、甩锅、被甩主战场 |
| 掌柜 | 听·说·决 | 定问谁、问多深 |
| 号东 | 听·决 | 可叫停或加码 |

### 2.4 去留（砍摊/加暗/抛人）

| 职级 | 权限 | 说明 |
|---|---|---|
| 学徒 | — | 无 |
| 伙计 | 听缝 | 无表决 |
| 柜伙 | 听 | 无表决；可被点名表态 |
| 管事 | 听·说 | 争保摊；无最终决 |
| 掌柜 | 听·说·**决** | 提案砍/加/抛 |
| 号东 | **决** | 点头或否决；危季抛人最终常在他 |

众东观礼：喜/危季可「说」施压，无日常决（议东另场）。

### 2.5 人事（升/降/开革建议）

| 职级 | 权限 | 说明 |
|---|---|---|
| 学徒 | — | 满师多在柜上，不靠本拍 |
| 伙计 | 听缝 | 听谁被提 |
| 柜伙 | 听·答 | 被提管事时可自陈 |
| 管事 | 听·说 | 可求升（触软顶）；可荐人 |
| 掌柜 | 听·说·**决** | 提名主责任 |
| 号东 | 决 | 淡点头/否决；撤掌柜级必须他 |

## 3. 程序用法

```
if 行动.最低职级 > 玩家.职级码 → 灰置（或隐藏）
if 行动.需要知情 and not 知情 → 灰置，提示「尚未听说」
if 行动.需要分管 and 无摊 → 拒
```

新行动入库时必须填：最低职级、正歪、主本事、是否要知情/分管。

## D. 升降文案模板

## 1. 晋升

### 1.1 满师（1→2）

**宣布人：** 郑德海（柜上或下处）  
**短：**「阿木，满师了。往后是伙计的活。」  
**发物：** 满师帖  
**系统句：** 职级 → 伙计 · 压力类型 → 赔累 · 季俸开始

### 1.2 上柜（2→3）

**宣布人：** 孙墨林或钱伯衡  
**短：**「柜上缺人手。荐书在此——去对账。」  
**发物：** 荐书/保单  
**系统句：** 职级 → 柜伙 · 压力类型 → 账脸 · 可碰明账

### 1.3 入座（3→4）

**场合：** 季会人事窗  
**宣布人：** 钱伯衡（号东可淡点头）  
**短：**「木摊（或某摊）——从今日起，你管。」  
**发物：** 管事份例折  
**系统句：** 职级 → 管事 · 授分管 · 压力类型 → 摊责 · 软顶生效  
**第一次入席旁白：** 建议专写一场（门外→正席）

### 1.4 软顶（停在管事）

**场合：** 喜季人事  
**短：**「你是好管事。掌柜的位子……眼下还不是时候。」  
**口风：**「外头名、外头利，或等变局。」  
**系统：** `flag_soft_cap=1`

### 1.5 破格→掌柜（4→5）

**短（外名）：**「会馆有帖。从今日起，你代东家理事。」  
**短（脏）：**「季是你救的。位子——你来坐。」  
**系统句：** 职级 → 掌柜 · 压力类型 → 代过

### 1.6 破格→号东（5→6）

**场合：** 议东  
**短：**「股契过讫。通源——有新东。」  
**Demo：** 不使用；仅伏笔句：「身股、东股，不是伙计能问的。」

## 2. 降级 / 削权

### 2.1 削摊

**宣布人：** 钱伯衡  
**短：**「这摊先不归你了。管事的名——还在。」  
**系统：** 分管清空 · 份例 0 · 压力↑ · 职级码可仍为 4

### 2.2 降阶

**短（管事→柜伙）：**「摊你扛不住。回柜上对账去。」  
**系统：** 职级码下降 · 压力类型换低阶 · 压力值↑

### 2.3 开革

**场合：** 季会去留/人事或当场  
**短：**「通源号——不用你了。」  
**Demo：** 接短终局  
**系统：** 编制清除 · 月钱停

### 2.4 撤掌柜

**宣布人：** 赵季堂  
**短：**「伯衡，你先歇。柜上——换人。」  
**系统：** 5→4 或开革；身股议处（正式版）
