## 设计原则

| 原则 | 说明 |
|---|---|
| **职级 = 看见的深度** | 升一级多看见一层账与人 |
| **古称六阶** | 学徒→伙计→柜伙→管事→掌柜→号东 |
| **软顶在管事** | 正道到管事封顶；掌柜/号东破格 |
| **可降可革** | 升不是单向 |
| **同模型** | NPC 同阶；外场用当量 |

```
正道：学徒 → 伙计 → 柜伙 → 管事 ■软顶
破格：                         ⇢ 掌柜 ⇢ 号东
```
