## 0. 类型总览

| 类型 | 职级码变不变 | 典型触发 | Demo |
|---|---|---|---|
| **削摊** | 可不变 | 摊亏、问责、夺摊 | 深做 |
| **降阶** | **变低** | 不胜任、错账、妥协留人 | 可用 |
| **开革** | 离号 | 危季抛人、大过、穿帮顶罪 | 短终局 |
| **顶罪甩锅** | 常害低阶 | 穿帮危季 | 样例 C |
| **停阶** | 不变 | 自愿不升 | 合法（非惩罚） |
| **撤掌柜** | 5→更低或开革 | 总数崩、穿帮、东家换人 | 正式版为主 |

```
号东 ──失东/出局──→（败局）
掌柜 ──撤──→ 管事 / 开革
管事 ──削摊──→ 仍 4 无份例  或  ──降阶──→ 柜伙
柜伙 ──降阶──→ 伙计  或  开革
伙计 ──降阶──→ 学徒（罕见）或 开革
学徒 ──大过──→ 开革（无更低阶）
```

## 1. 削摊（管事专用 · Demo 首选）

| 项 | 内容 |
|---|---|
| 对象 | 管事（4） |
| 职级码 | **保留 4**（简化） |
| 变化 | 分管摊清空；**份例归零**；号内倚重↓；压力↑ |
| 触发 | 季会砍摊、问责过重、同辈夺摊成功、掌柜惩罚 |
| 文案味 | 「还是管事，只是这摊不归你了」 |
| 再起 | 可再挣分管（须掌柜再授） |

> 正式版若要「降阶更疼」，可改为削摊同时 4→3；Demo 为减复杂度默认不降码。

## 2. 降阶（职级码下降）

### 2.1 通表

| 从 | 到 | 典型因 | 主决定人 |
|---|---|---|---|
| 掌柜 (5) | 管事 (4) | 撤掌柜仍留用 | 号东 |
| 管事 (4) | 柜伙 (3) | 不胜任、连亏、妥协留人 | 掌柜 |
| 柜伙 (3) | 伙计 (2) | 大错账、账房否决继续上柜 | 掌柜/账房 |
| 伙计 (2) | 学徒 (1) | 极罕见（辱号后留饭碗） | 掌柜 |
| 学徒 (1) | — | 无更低；走开革 | — |

### 2.2 降阶时系统变化

| 变化 | 说明 |
|---|---|
| 职级码 | 写入低阶 |
| 压力类型 | 换成低阶类型 |
| 行动资格 | 按低阶收紧（灰掉高阶选项） |
| 分管/份例 | 管事降下必丢摊与份例 |
| 身股 | 掌柜被撤：身股可议收/冻结（正式版）；Demo 可不演 |
| 交情 | 提拔人交情常↓；仇家可能↑ |
| 明誉/污名 | 视事由：错账伤明誉；穿帮抬污名 |

### 2.3 否决与保护

| 保护 | 说明 |
|---|---|
| 厚交力保 | 可挡一次降阶，改削权或记过（铁律：当场穿帮除外） |
| 把柄 | 可逼掌柜「不降你」，事后交情↓ |
| 号东点头 | 撤掌柜级必须号东非仇隙且点头 |

## 3. 开革（离号）

| 项 | 内容 |
|---|---|
| 触发 | 危季抛人；号规大过；穿帮顶罪到自己；累犯 |
| 宣布 | 季会去留/人事，或当场驱逐 |
| Demo | **短终局**（好懂） |
| 正式版 | 可续：流落、投裕泰、另谋；见结局企划 |
| 系统 | 编制清除；月钱停；本号分管/份例/未结清亏空可追 |
| 信物 | 满师帖等可被追回或作废（叙事可选） |

**谁容易被抛：** 职级低、交情差、无把柄反制、本季绩差——见季会抛人规则。

---

## 4. 顶罪与甩锅（穿帮季）

| 项 | 内容 |
|---|---|
| 本质 | 高阶把罪责压到低阶或仇家 |
| 结果 | 被顶者：开革 / 降阶 / 公门嫌疑↑ |
| 约束 | 交情五档 + 铁律（厚交难卖；当场凿实难保） |
| Demo | 样例 C；玩家可选扛/甩/跑 |

不是正式「降级按钮」，但是职级往下走的高频来源。

---

## 5. 停阶（非惩罚）

| 项 | 内容 |
|---|---|
| 含义 | 有资格不升，或升不了也不降 |
| 样例 | 郑德海长期伙计；正式版「管事到白头」 |
| 系统 | 不触发降级惩罚；可涨本事与交情 |

### 5.1 资深标签（Demo 可用）

同一职级码连续停留 **≥ 4 季**，且无开革/大过：

| 奖励 | 效果 |
|---|---|
| 标签 | `资深{职级}`（如资深伙计） |
| 倚重 | +5（一次） |
| 季俸 | +2（仅伙计/柜伙/管事） |
| 对话 | 解锁「老人」口吻与额外口风 |
| 软顶 | 管事资深不自动破格；仅口风更明确 |

郑德海开局可直接带 `资深伙计`（叙事已停阶多年）。
