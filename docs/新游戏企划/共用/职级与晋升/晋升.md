## 1. 学徒 → 伙计（满师）

| 项 | 默认 |

## 2. 伙计 → 柜伙（上柜）

| 项 | 默认 |
|---|---|

## 3. 柜伙 → 管事（入座）

| 项 | 默认 |
|---|---|
| 绩 | 近 1 季 **个人打工分 ≥ 40** **或** 独立成功大单 1 次；无重大错账旗 |
| 倚重/交情 | 钱伯衡 ≥ **相善** **或** 号内倚重 ≥ **60** |
| 点头 | 赵季堂非仇隙（默认过） |
| 信物 | 宣布后发 **管事份例折**；授分管摊 |
| 否决 | 同辈使绊成功（如刘成业）；污名 ≥ **50** |
| 宣布 | **季会人事窗**（Demo 样例 A） |
| 升后 | 职级 4；分管 1 摊；压力→摊责；**软顶生效** |

打工分与集体 `route_perf` 分记；摊规则见 [`../明业与摊/README.md`](../明业与摊/README.md)。

职级说明：[`柜伙.md`](柜伙.md) → [`管事.md`](管事.md)

## 4. 软顶：管事 ↛ 掌柜（正道）

| 项 | 内容 |
|---|---|
| 规则 | 正道条件**永不齐**；无「攒够就升掌柜」清单 |
| 体验 | 喜季人事夸「好管事」→ `flag_soft_cap=1` |
| 口风 | 指向会馆/钱庄/洋行，或等变局 |
| 目的 | 再往上是破格题，不是勤奋题 |

职级说明：[`管事.md`](管事.md)

## 5. 破格：管事 → 掌柜

### 5.1 公共条件（条条要）

1. 号东/关键众东 **不强烈否决**  
2. 现任掌柜「位子可动」：坏事、自退、危季不稳、或挖角危机  

### 5.2 三选一（可脏可净）

| 路 | 信物/条件 | 味道 | 代价 |
|---|---|---|---|
| **外名** | 会馆名帖/议事条；李敬斋 ≥ 相善；`firm_face` ≥ **40** | 体面 | 慢；要门面 |
| **外利（净）** | 洋行回单/大单合同（陈子卿） | 利 | 退货可打脸 |
| **外利（脏）** | 近季 `dark_perf` ≥ **55** 且单季 `firm_cash` 回升 ≥ **15** | 救季 | 污名↑、heat↑ |
| **意外** | 钱伯衡退/出事；或对家挖角须有人顶 | 变局 | 被动、险 |

歪门可加速，留毒（把柄、heat、穿帮更惨）。

**Demo：** 摸到破格窗即可收展，**不要求升成掌柜**。

职级说明：[`管事.md`](管事.md) → [`掌柜.md`](掌柜.md)
