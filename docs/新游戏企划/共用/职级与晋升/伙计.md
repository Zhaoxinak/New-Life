## 1. 名片

| 项 | 内容 |
|---|---|
| 职级码 | `2` |
| 古称 | 伙计 |
| 定位 | 出师腿脚；字号外围办事人 |
| 进项 | 死月钱；跑成有赏 |
| 压力类型 | **赔累** |
| Demo | 满师后 |

---

## 2. 看见的深度

跑明单；偶遇「多出来的箱子」——可触发知情半揭。

---

## 3. 日常

押船、送货、茶楼传话、跟柜上跑腿。

---

## 4. 权力 · 义务 · 福利

| 层 | 内容 |
|---|---|
| 权力 | 接小单；可非正式带更小学徒跑腿 |
| 义务 | 丢货赔累；误期砸锅记过 |
| 福利 | 死月钱；跑成有赏 |
| 分管摊 | 无 |
| 暗线资格 | 默认无；事件/掌柜点名可「搭一把手」 |

---

## 5. 压力

> 总规：[`压力.md`](压力.md)

| 项 | 内容 |
|---|---|
| 类型 | **赔累** |
| 怕什么 | 赔银子、欠号、误期砸锅 |
| 加压 | 丢货、大赔旗、月钱不够赔、被点名 |
| 缓解 | 跑成赏钱、还清、歇一日 |
| 高压表现 | 抢活还债、易被拉去夹带「快银」 |

---
## 6. 可做行动

| 类型 | 例子 | 主本事 |
|---|---|---|
| 正 | 押木上船、送货 | 勤谨 |
| 正 | 茶楼打听市价 | 口才 |
| 歪 | 夹带搭手（需知情或被拉） | 胆色+眼力 |

---

## 7. 季会

末席旁听；问责时可能被点名赔货。

---

## 8. 本号样例

**吴小顺**；满师后玩家；**郑德海**（资深伙计卡阶，合法停阶）。

---
