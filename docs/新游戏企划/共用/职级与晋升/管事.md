# 管事（4）

> 上级：[`README.md`](README.md) · 压力：[`压力.md`](压力.md) · 晋升：[`晋升.md`](晋升.md) · 降级：[`降级.md`](降级.md)  
> **正道尽头 · 软顶位。**

---

## 1. 名片

| 项 | 内容 |
|---|---|
| 职级码 | `4` |
| 古称 | 管事 |
| 定位 | 一摊之主；号里中层；正道软顶 |
| 进项 | 月钱 + **摊份例**（看摊绩） |
| 压力类型 | **摊责** |
| Demo | 入座目标；破格前停靠 |

---

## 2. 看见的深度

可管一条明货路，**或**（点名）一条暗线；季账与自己摊绑定。

---

## 3. 日常

盯船期、派伙计、报账、争份例；茶楼维护关系。

---

## 4. 权力 · 义务 · 福利

| 层 | 内容 |
|---|---|
| 权力 | **分管 1 摊**；荐人；摊内奖惩打手 |
| 义务 | 整摊盈亏；暗线爆了算你（若管暗） |
| 福利 | 月钱 + 管事份例折 |
| 分管摊 | `route_wood` / `route_fur` / 暗线等之一 |
| 暗线资格 | 可；需掌柜点名或坏季加暗 |

---

## 5. 压力

> 总规：[`压力.md`](压力.md)

| 项 | 内容 |
|---|---|
| 类型 | **摊责** |
| 怕什么 | 整摊亏、暗线爆算到自己头上、被夺摊 |
| 加压 | 摊绩差、季会问责、firm_heat、同辈挖墙 |
| 缓解 | 摊绩回升、辩摊过关、掌柜一句「过了」 |
| 高压表现 | 死保本摊、易甩锅低阶、易加暗救绩 |

---
## 6. 可做行动

| 类型 | 例子 | 主本事 |
|---|---|---|
| 正 | 管木/毛摊、谈会馆门面 | 眼力、口才、勤谨 |

| 破格准备 | 走会馆/钱庄/洋行 | [`晋升.md`](晋升.md) §5 |
