---

## 0. 一句话

季会不是结算弹窗，是**每季一次的戏**：号活不活、你升不升、明暗露不露，多半在这里落地。

---

## 1. 定位

| 项 | 内容 |
|---|---|
| 是什么 | 本号议事厅里的季度大会；算账、问责、砍摊、定人 |
| 为何存在 | 把三个月零碎行动收成一次「有重量的结果」 |
| 服务主线 | ①商号存亡 ②职级升降/软顶 ③明暗穿帮 ④破格窗口 ⑤号东局 |
| 节奏 | **一季一次**（春夏秋冬）；全年 4 场。若嫌密可改半年，仍用「季会」名义 |
| 时长体感 | 一场 5～12 分钟可玩完；前低阶更短（门外戏） |
| 场所 | 本号 **议事厅** |

与总稿关系：

- 职级六阶、正道/歪门、明暗双账 → 见总稿 §3、§4  
- 时间骨：日常填满一季 → **开季会收束** → 下一季

## 2. 会前：季账从哪来

开会前系统先结算本季（玩家可在会前一天收到「账房知会」）：

| 输入 | 来源 | 会上怎么用 |
|---|---|---|
| **明业成色** | 各明货摊盈亏（木、毛、棉、洋布…） | 宣账、砍哪条明路 |
| **暗业进账** | 洋药/土膏、私盐等是否走、赚多少 | 银根窟窿靠不靠它堵；穿帮风险 |
| **风险值** | 公门、洋关、对家、会馆风声 | 决定本场是「平季」还是「危季」 |
| **人事摩擦** | 同辈抢摊、掌柜信任、把柄 | 问责点名谁 |
| **你的摊绩** | 你负责的明摊/暗线 | 表功或背锅 |

### 2.1 会前可做（按职级解锁）

| 行动 | 约从 | 正/歪 | 作用 |
|---|---|---|---|
| 请人喝口风 | 伙计+ | 正 | 预知谁会被点名、本季天气 |
| 递帖求保 | 柜伙+ | 正 | 问责时有人帮腔 |
| 改一笔小账 | 柜伙+ | 歪 | 宣账好看；危季易爆 |
| 串通同辈口径 | 管事+ | 正/歪 | 保摊或联手抢摊 |
| 故意避会 | 任意 | 歪 | 躲过问责；缺席本身有代价 |
| 买通门外听差 | 管事+ | 歪 | 控制低阶传话版本 |

## 3. 谁在场 · 你坐哪

**固定在场：** 号东（或代理人）、掌柜、账房先生、各管事。  
**偶来观礼：** 众东、会馆人（坏季、危季、议东时）；对家说客极少数危季。

| 你的职级 | 位置 | 能听到 | 能开口 |
|---|---|---|---|
| 学徒 | **门外听差**（倒茶、传话、候着） | 门缝只言片语；歪门可偷听全段（有败露风险） | 几乎不能；传错话是歪门 |
| 伙计 | 门外；**偶被点名进门对质一单** | 对质时一段 | 只答自己那单 |
| 柜伙 | **后排侧座**（备询账） | 明账宣读；暗账多半被含糊掉 | 被问才说；可纠一笔明账 |
| 管事 | **正席入座** | 明账+与己相关的暗线口径 | 交摊报、争摊、甩锅/被甩 |
| 掌柜 | **主位侧 / 主持** | 两套账的配比真相 | 定调、提裁扩、扛责 |
| 号东 | **主位拍板** | 全部 | 定人定股定暗业存废 |

**五拍×职级细表（听/说/答/决）：** [`职级与晋升/职级附表.md`](职级与晋升/职级附表.md)

**升职的季会体感：** 第一次从门外走进正席 = 主线里程碑（建议专写一场戏）。

## 4. 一场季会怎么开（五段）

固定骨架，每季换肉。低阶可能只经历其中几段（门外时用旁白/偷听压缩）。

```
① 开场定座 → ② 宣季账 → ③ 问责表功 → ④ 议去留 → ⑤ 人事窗 → 散会余波
```

### 4.1 开场定座（约 1 分钟体感）

- 谁迟到、谁缺席、有没有「生人」坐进来（众东、会馆、对家说客）。  
- 点出本场气氛：**平季 / 喜季 / 坏季 / 危季**。  
- 玩家职级决定：端茶、侧坐、入席、主持。

### 4.2 宣季账（核心信息）

账房先念**明账**（各货路），再由掌柜用官话带过「另有进项」或装穷。

| 宣账结果 | 玩家听到的味道 | 主线钩子 |
|---|---|---|
| 明肥暗少 | 正道风光 | 易谈扩摊、升迁 |
| 明瘦暗肥 | 「总数尚可」但心腹知鬼 | 埋把柄；歪门得意 |
| 明暗都瘦 | 刀气 | 必砍人砍摊 |
| 账对不上 | 柜伙可立功或惹祸 | 穿帮序章 |

**柜伙+** 可选项：沉默 / 正道指出明账错漏 / 歪门假装没看见或帮着圆。

文案注意：暗账对外称「南边那笔」「另账」等，对白用当时叫法（洋药/土膏），勿现代化解说。

### 4.3 问责表功（人对人）

点名 1～3 个摊：盈的赏脸，亏的要说法。

| 你的处境 | 正道选 | 歪门选 |
|---|---|---|
| 摊好 | 实绩表功，要名分/分成 | 把别人功劳也揽上（留仇） |
| 摊坏 | 认责、立军令状下季补 | 甩给手下/同辈；甩给「市面」 |
| 与你无关 | 帮人说句公道 | 落井下石抢摊 |
| 暗线相关 | 拒谈细节，保号脸 | 暗示「没有我银根早断」要挟 |

结果立刻改：信任、仇怨、把柄、下一段「去留」权重。

### 4.4 议去留（号的生存落地）

议题只有几类，**每场挑 1～2 个真刀**：

| 议题 | 好季常见 | 坏季常见 |
|---|---|---|
| 货路 | 扩哪条明摊 | 砍哪条明摊 |
| 暗业 | 少走、收手 | **加一船洋药/土膏？** 或停哪条暗线 |
| 银根 | 分红、加薪 | 借钱庄、削月钱 |
| 外患 | 可忽略 | 对家/公门怎么应 |

**本段是主线抉择台：**  
「加暗救季」vs「硬扛挨砍」应反复以不同包装出现，而不是只出现一次。

权限：

- 掌柜/号东：最终口径  
- 管事：只能争自己的摊、表态暗线  
- 低阶：看戏或被点到名  

### 4.5 人事窗（攀爬与破格）

收束到「人」：

| 窗口 | 触发倾向 | 主线作用 |
|---|---|---|
| **赏与升** | 喜季 + 正道实绩 | 1→4 正道升迁多落在这里宣布 |
| **软顶明说** | 你已是管事且再要升 | 「你是好管事」——逼出门破格 |
| **掌柜不稳** | 坏季 / 代过太重 | **4→5 破格窗**打开 |
| **抛人抵罪** | 危季穿帮 | 你可抛人或被抛；活下来或出局 |
| **谈股 / 议东** | 好季连胜或号东无嗣等 | **5→6 伏笔**；后期变主戏 |
| **暗业存废** | 号东在场的危季 | 终局道德/利益题 |

宣布完 → 散会。当场换称呼（升职）是强反馈。

## 5. 四种季会「天气」

| 类型 | 条件方向 | 会上重点 | 玩家爽点 |
|---|---|---|---|
| **平季** | 明暗都过得去 | 小赏小罚、微调 | 稳升、攒关系 |
| **喜季** | 明肥或总数大好 | 扩摊、谈名分、谈股 | 正道高光 |
| **坏季** | 明瘦，银根紧 | 砍摊、逼加暗、换人 | 核心抉择 |
| **危季** | 风险爆（查私、揭暗、账穿） | 追责、抛人、公门阴影 | 高潮/失败边缘 |

天气可由会前季账自动判定，再被会中选择微调（例如硬圆账可能把坏季拖成危季）。

Demo 至少各做一场「坏季」「危季」打磨手感。

## 6. 按职级：可玩菜单

| 职级 | 本场可玩重点（别贪多） |
|---|---|
| 学徒 | 偷听关键词；传话传对/传歪；别在门口挨打 |
| 伙计 | 被叫进去对质时站稳；赔不赔、认不认 |
| 柜伙 | 明账问答；发现「对不齐」时揭或不揭 |
| 管事 | **完整五段都参与**；保摊/抢摊；暗线口径 |
| 掌柜 | 定明暗配比提案；扛责或卸责；卡别人升迁 |
| 号东 | 拍板；定抛谁；定暗业；定是否开议东 |

## 7. 会后余波

散会当天或次日必有落地，否则季会像念报：

| 会上结果 | 余波例子 |
|---|---|
| 升/降/开革 | 当场或次日换称呼；号里势利眼变脸 |
| 砍摊 | 被砍的人茶楼寻仇或托你 |
| 加暗 | 货栈多一船「木箱」事件链 |
| 危季 | 公门上门、会馆传话、对家放风 |
| 软顶台词 | 会馆/钱庄破格引导自动亮 |
| 抛人抵罪 | 仇怨旗；或你被盯上 |

## 8. 主线里程碑（建议写死几场）

| 里程碑 | 建议落在哪场季会 |
|---|---|
| 第一次入座（升管事） | 专场：从门外到正席 |
| 撞软顶 | 管事任上某次喜季仍不提掌柜 |
| 第一次「加暗救季」总抉择 | 一场标准坏季 |
| 暗账穿帮 | 一场危季 |
| 破格上台掌柜 | 坏季或危季后的人事窗 |
| 议东 / 入股 | 后期喜季或号东危机季 |

---

## 9. 演出与代入感

- 议事厅：茶烟、账本一拍、有人把杯子放重  
- 宣暗账时降低音量或换说法（「南边那笔」）  
- 门外学徒版用**声响 + 半截句**，不要同屏全文（保留发现感）  
- 升职当场有人改口称呼  
- 危季可加门外脚步/公门影（不一定真闯进来）

---

## 10. 范围：做什么 / 不做什么

**做：**

- 五段固定流程 + 四季天气  
- 职级座位差异  
- 正道/歪门选项  
- 会后余波  
- 与软顶、破格、号东局挂钩  

**不做：**

- 复杂董事会投票模拟器（公式别堆）  
- 每季十几议题；**每场真刀 1～2 个议题 + 人事一句**  
- 低阶每季开完整策略菜单（资格就是成长）  
- 把季会做成纯 UI 报表而无场面
