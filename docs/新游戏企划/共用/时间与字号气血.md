# 时间与字号气血 【草案】

> 给季会天气、日常循环提供输入。数值可调，字段先锁。

---

## 1. 时间粒度

```
年 → 季（春夏秋冬）→ 旬（上中下旬，可选）→ 日 → 时段
```

### 时间参数

正式版可加长或改为两季一会；Demo 展示包用紧参数（[`../Demo/切片与验收.md`](../Demo/切片与验收.md)）。

### 展示包常用参数

| 单位 | 设定 |
|---|---|
| **时段/日** | 上午 / 下午 / 晚上（3 动） |
| **日/季** | **12 日 = 1 季**（约一旬实用化；不必真日历） |
| **季会** | 每季末日强制入会（可前一日账房知会） |
| **一年** | 4 季 = 48 行动日；Demo 打 **6～8 季** |

> 若嫌季会太密：可改「两季一会」，日常仍按季累计账。**Demo：一会一季。正式版：可两季一会或保持。**

每日：

1. 选建筑做事（同时段 1 主行动；可含短移动）  
2. 结算行动结果（摊绩/暗绩/交情/嫌疑…）  
3. 季末日 → 结算字号气血 → 季会  

移动：同城建筑 **不另耗时段**（或晚上不可去公门/洋行等，用开放表限制）。

## 2. 字号气血（公司层 · 非人物）

每人有银钱；**号**另有一套：

| 字段 | 含义 | 主要来源 |
|---|---|---|
| `firm_bright` | 明业成色 0–100 | 各明摊本季表现 |
| `firm_dark` | 暗账进项 0–100 | 洋药等是否走、赚多少 |
| `firm_cash` | 银根 0–100 | 明+暗兑现 − 开支 − 债务催逼 |
| `firm_face` | 号誉（会馆/洋行脸）0–100 | 大单、退货、毁誉、灌水木 |
| `firm_heat` | 外患风险 0–100 | 公门、对家、单货不符 |

派生：

- **总数观感**（众东要的）≈ `0.4*bright + 0.35*cash + 0.15*dark + 0.1*face`（暗的贡献可被心腹看见）  
- 低阶玩家只见「号里发不发得起月钱」的演出。

### 初值（通源号开局）【草案】

| 字段 | 值 | 味道 |
|---|---|---|
| bright | 55 | 木市平平 |
| dark | 25 | 暗线有但不凶 |
| cash | 50 | 过得去 |
| face | 60 | 会馆挂得住 |
| heat | 20 | 未盯上 |

## 3. 季会天气判定

先算再开会（可被会中选择改写，如硬圆账 → heat↑）。

| 天气 | 条件【草案】 |
|---|---|
| **危季** | `heat ≥ 70` **或**（暗账穿帮旗）**或**（`cash < 25` 且 `heat ≥ 50`） |
| **坏季** | 非危，且 `bright < 40` 或 `cash < 40` |
| **喜季** | 非危非坏，且 `bright ≥ 70` 且 `cash ≥ 55` |
| **平季** | 其余 |

会前「账房知会」用文案说天气，不直接甩字段名。

天气对各阶 **压力加成** → [`职级与晋升/压力.md`](职级与晋升/压力.md) §5。

## 4. 字号气血怎么被玩家扳动（摘要）

| 行为 | 主影响 |
|---|---|
| 明摊做好 | bright↑ cash↑ |
| 加船洋药 | dark↑ cash↑ heat↑ |
| 会馆站台成功 | face↑ |
| 退货/灌水木 | face↓ bright↓ |
| 公门查栈 | heat↑；失败则穿帮旗 |
| 钱庄借款 | cash↑，债记在号或人身上 |

## 5. 开革与关号

| 情况 | 结果 |
|---|---|
| 个人被开革 | Demo **失败终局**（短）；可写「流落码头」一句 |
| `cash` 连续 2 季 < 15 且无借款成功 | 关号危机；号东甩锅 → 易危季抛人 |
| 穿帮且无人顶罪 | 关号或掌柜换人硬结局支 |
