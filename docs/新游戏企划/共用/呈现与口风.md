## A. UI 与反馈

### A1. HUD（常驻）

| 块 | 显示 | 不显示 |
|---|---|---|
| 时间 | 季·日·时段 | 内部 tick |
| 身份 | 古称职级、分管摊名 | 职级码数字可藏 |
| 身家 | 银钱约数或「紧/够/宽」 | 可不露精确到个位 |
| 压力 | 文案味 + 轻/紧/崩 | 可隐藏 0–100 |
| 号况 | 「号里还过得去/紧」 | 五气血精确值默认藏 |

### A2. 面板

| 页 | 内容 |
|---|---|
| 档案 | 信物与把柄 · 档案页 |
| 交情 | 关键人五档用语（仇隙…厚交） |
| 摊 | 有分管才显示绩成色 |
| 情报 | 已知事件/口风 |

### A3. 行动反馈句式

| 结果 | 结构 |
|---|---|
| 成功 | 场面一句 + 可选小利 |
| 失败 | 场面一句 + 压力/赔累味道 |
| 大失败 | 更重场面 + 旗/把柄暗示 |

**忌：** 弹「勤谨+1」「heat+7」。

### A4. 称呼变化

| 触发 | 例子 |
|---|---|
| 满师 | 「阿木」→「沈伙计」 |
| 入座 | 「管事」入称呼 |
| 交情升/降 | 台词变软 / 变硬 |

### A5. 季会 UI

五拍进度条；座位示意；选项灰置写原因。

## B. 对话与口风

### B1. 口风类型

| 类型 | 用途 | 例子 |
|---|---|---|
| 指引 | 下一步去哪 | 「该让掌柜看见你了」 |
| 市况 | 木淡/毛旺 | 「船期都空着」 |
| 预警 | 穿帮/问责 | 「褚三这两日爱往栈上转」 |
| 假话 | 检定失败 | 故意带错 |

### B2. 交情改台词

| 档 | 调法 |
|---|---|
| 仇隙 | 嘲讽、拒说、说假 |
| 不睦 | 冷、惜字 |
| 泛泛 | 公事公办 |
| 相善 | 多半句实在的 |
| 厚交 | 抢着报；可交底 |

### B3. 模板

**师父：**「{名字}，{建议行动}。号里吃饭，就听号里的。」  
**掌柜：**「绩说话。{摊或暗}——你自己看。」  
**账房：**「这笔，对不齐。」  
**茶楼：**「听说{对象}，{传闻}……」

### B4. 禁止

- 系统术语入对白（heat、flag）  
- 明说「你的任务是升管事」  
- 正式版用 `flag_demo` 对话
