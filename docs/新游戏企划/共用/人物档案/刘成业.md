## 3. 背景

从伙计熬到管事，认定木摊是自己熬出来的。暗线上帮过掌柜，自以为心腹。阿木被老郑护着，他当成抢路的种子。

**污名 28 为故意设计**：号里老油条早有风闻，但不够毁他管事位——方便他当「体面墙」又当「背锅/供人」候选；穿帮季可优先拿他开刀或由他供弱势。
