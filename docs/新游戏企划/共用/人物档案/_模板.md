---

## 空值约定

| 写法 | 何时用 |
|---|---|
| `—` | **不适用**（外场无号内职级/分管/倚重等） |
| `0` | **适用但开局为零**（无股权、无污名、无摊绩…） |
| `未知` | 草案未定、待补专名或精确数 |
| `无` | 明确没有（无师父、无分管摊）——身份层也可用 `—`，与「无」同义时优先写 `无` |

数值列不要留空白单元格；文本列没有内容时写 `—`。
