# 亲戚与社会纽带 · 开局总表 【草案】

> 隶属：[`README.md`](README.md) · [`关系开局表.md`](关系开局表.md)  
> **亲戚 ≠ 交情**：族亲可以不睦；厚交不必是亲戚。  
> **亲戚 ≠ 师徒/同乡**：后者写在「社会纽带」，勿塞进亲戚栏。

---

## 0. 类型定义（统一用词）

### 0.1 亲戚（必须写明有或无）

| 类型 | 含义 | 本游戏用法 |
|---|---|---|
| **血亲** | 直系/旁系有血缘 | 父兄子侄等；Demo 卡司暂无直系同场 |
| **族亲** | 同姓同宗、族谱可认 | **赵季堂 ↔ 赵季岑** |
| **姻亲** | 因婚姻结成的亲 | 开局卡司 **无** |

### 0.2 社会纽带（不是亲戚，但要明文）

| 类型 | 含义 |
|---|---|
| **师徒** | 号内授业（郑↔沈、郑↔吴） |
| **同门** | 同一师父门下 |
| **同乡** | 同籍贯话头（可接会馆） |
| **结拜** | 开局 **无** |
| **恋慕** | 开局 **无**（标签位预留） |

空值：某人无某类关系 → 表内写 **`无`**，不要留空、不要省略整表。

## 3. 赵氏亲族（锁定）

```
赵氏（通源号东家一支）
├── 赵季堂（号东）──族亲·堂兄弟── 赵季岑（众东）
└── （其余族人正式版再扩；Demo 不出）
```

| 项 | 草案 |
|---|---|
| 关系 | **同辈族亲（堂兄弟）** |
| 血缘远近 | 共曾祖或共祖父【可虚，不必写死代数】 |
| 交情开局 | 季岑→季堂 **厚交**；季堂→季岑 **相善偏厚**（对称可 +50/+55） |
| 议东 | 季岑默认护季堂与「姓赵的号」；挡外人争东 |
| Demo | 季岑可不出或危季闪一眼；关系仍先锁死 |

## 4. 与交情字段怎么并存

人物企划 `tags` 建议拆清：

```
kinship:     none | blood | clan | in_law
bond_tags:   apprentice | fellow_disciple | tongxiang | sworn | romance | …
```

决策时：**先看交情五档**；亲戚/师徒给额外修正（如族亲危季更难抛号东自己人；师徒满师门槛）。
