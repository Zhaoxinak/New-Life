## 3. 背景

请来管明账。心里清楚号有暗本，职责是明面能过会馆与东家眼。坏季暗银回填时最难受——要做平，又不能写破。

## 4. 性情 · 说话味道

- 少言；对则点头，错则一句话钉死。
- 不收小贿；大钱/把柄另说。
- 口头禅 / 称呼习惯：未证明算盘前，视学徒为搬货的。
