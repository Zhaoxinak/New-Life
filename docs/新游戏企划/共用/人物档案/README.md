## 怎么设计（本游戏）

| 原则 | 说明 |
|---|---|
| **同一模型** | 玩家与 NPC 字段行完全一致 |
| **一人一钩** | 每人至少 1 个主线用途 |
| **性情服务决策** | 兴趣癖好进对话与软引导 |
| **五维有偏科** | 开局拉差距 |
| **交情单向写清** | §6 两行；总分见关系开局表 |
| **Demo 深浅** | 优先级在 §9；浅角色也填满表 |

## 空值约定（速查）

| 写法 | 含义 |
|---|---|
| `—` | 不适用 |
| `0` | 适用但开局为零 |
| `无` | 明确没有（师父/分管等） |
| `未知` | 待补（细址等可保留） |
