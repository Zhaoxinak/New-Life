## 3. 背景

年轻时也想过上柜，算盘与胆色不够，卡在好伙计。收阿木半是同乡、半是把规矩传下去。木市紧时他最早皱眉，却总说脚踏实地。

### 暗账知情 · 行为底线（锁定）

| 层级 | 内容 |
|---|---|
| 知情 | **半知**：闻得号里有「南边货」补季，不主动查舱单、不碰黑账本 |
| 撞见夹带/私货 | **先劝退徒弟/同门收手**；交情↓；可报郑自己压力↑ |
| 会否供出 | **默认不供**（怕毁号也毁人）；例外：公堂当场凿实、或把柄逼他、或号规铁证当众——见交情铁律优先级 1 |
| 危季 | 保徒与保号冲突时：相善以上优先挡徒弟「死罪」级指控，可改认「管教不严」；不替徒弟揽暗线主犯 |
| 玩家预期 | 走歪门被师傅发现 = 训斥+交情伤，**不是**立刻被送官 |
