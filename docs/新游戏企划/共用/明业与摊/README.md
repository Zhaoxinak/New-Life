## 谁管摊

| 职级 | 规则 |
|---|---|
| 学徒伙计 | 无分管；打工给当前摊加集体亮色 |
| 柜伙 | 无分管；对账影响记录准确性 |
| 管事 | **1 条明摊** 或（点名）**1 条暗线** |
| 掌柜 | 定本季暗线开不开、谁管 |
| 号东 | 定暗业存废 |

开局：木摊主事 = 刘成业。

## 摊绩与份例

| 项 | 规则 |
|---|---|
| 绩字段 | 集体 `route_perf` / `dark_perf` 0–100；季末 **减半** |
| 打工分 | 无分管者做事给个人打工分（升管事用） |
| 份例 | 分管者季会后 `floor(route_perf/5)`（见职级附表） |
| 进气血 | 明摊好 → `firm_bright`↑ `firm_cash`↑ |
| 号内倚重 | 长期值，季末不清 |

## 其它明摊（事件化）

| 摊 id | 用法 |
|---|---|
| `route_cotton` | 坏木市时事件：「棉倒还能走」→ 临时打工分或 bright 微+ |
| `route_bristle` 等 | 同 |

不单开 `route_perf` 长存也可；事件直接改气血。
