## 0. 一句话

舱单在此过眼：正经报关养明誉；少报买通养暗货——**纸面真假的第一现场。**

---

## 1. 时代背景

津海关/报关行手续繁琐。买办、关手、代办跑腿构成灰色地带。木行常自带或委托报关。

---

## 2. 主线职责

| 方向 | 作用 |
|---|---|
| 正道 | 干净舱单、按时放行、洋行信任 |
| 歪门 | 少报、伪品名、买通关手 |
| 季会 | 危季常由「单货不符」引爆 |
| 攀爬 | 柜伙起接触；管事掌柜定口径 |

---

## 3. 空间切块 · 热区

| 热区 id | 区域 | 谁进得去 | 时段 | 挂行动（权威 ID） |
|---|---|---|---|---|
| `hz_customs_queue` | 挂号排队 | 伙计跑单；柜伙+ | 上/午 | `act_customs_file`；耗时感（1 时段） |
| `hz_customs_desk` | 关手案桌 | 柜伙+ | 上/午 | 对单；正道放行检定并入 file |
| `hz_customs_side` | 侧廊 / 代办角 | 知情≥1；管事口径 | 上/午 | `act_customs_grease`（少报通融） |
| `hz_customs_inspect` | 验货廊（浅） | 事件 | 偶 | 单货不符爆发；链穿帮 |

**Demo 落地策略：**  
- **浅：** 货栈办公室多一个「交单」选项，内部仍调 `act_customs_*`。  
- **深：** 独立建筑点，上表四热区。  
**夜间：** 关。

## 5. 行动 ↔ 热区一览

| 行动 id | 热区 | 最低阶 | 正歪 | 成功摘要 | Demo |
|---|---|---|---|---|---|
| `act_customs_file` | 排队/案桌 | 2（跑单）/3 | 正 | 放行；face 微↑；船期顺 | P1 |
| `act_customs_grease` | 侧廊 | 3 | 歪 | 少报过关；heat↑；暗船次可行 | P1 |
| `act_customs_check` | 案桌/验货 | 3 | 正 | 眼力；发现对家手脚或己号破绽 | P1 |

**与夹带链：**

```
库房夹带 →（可选）hz_customs_side · grease 圆舱单
→ 失败/查验 → 单货不符 → flag_bust_risk / 穿帮
正道：file 干净单 → 洋行信任↑
```

## 6. 本建筑事件钩

| 事件 id | 说明 |
|---|---|
| `ev_customs_hold` | 卡单一日；推补手续或 grease |
| `ev_manifest_mismatch` | 单货不符；危季/穿帮入口 |
| （并入）`ev_rain_delay` | 船期乱时报关积压 |

## 7. 产出与风险

| 产出 | 风险 |
|---|---|
| 放行、船期顺、face | 卡单误期、赔累 |
| 少报过关（暗） | heat；验货廊穿帮 |

## 8. Demo / 不做

**Demo P1：** 先货栈「交单」热区即可；独立点可选。  
**不做：** 完整海关法规、税则沙盘。
