## 0. 一句话

巡捕房 / 县衙 / 租界巡捕合成的**一个点**：歪门的外牙，也是查私时号的死神。

---

## 1. 时代背景

天津华界与租界执法并存。商号遇盗报案走公门；夹带洋药、私盐则怕公门。不叫「警察局」。Demo 落点合成建筑，主脸 **褚三**。

---

## 2. 主线职责

| 方向 | 作用 |
|---|---|
| 正道 | 报案、洗白清白、销小案（正名） |
| 歪门 | 买通压事、栽人对家、拿人恐吓 |
| 季会 | 危季阴影；会后上门问话 |
| 攀爬 | 胆色路线；heat / 嫌疑管理 |

## 3. 空间切块 · 热区

| 热区 id | 区域 | 谁进得去 | 时段 | 挂行动（权威 ID） |
|---|---|---|---|---|
| `hz_yamen_gate` | 衙门 / 捕房门口 | 伙计跟；柜伙+ | 上/午 | `act_report_theft`（P1 浅）；排队受气 |
| `hz_yamen_clerk` | 书办桌 / 挂号房 | 柜伙+ | 上/午 | 递状、销小案手续（并入 bribe 正名支） |
| `hz_yamen_chu` | 褚三熟路侧门 | 知情或 heat 事件后 | 上/午 | **`act_bribe_chu`**；人情条 |
| `hz_yamen_cell` | 班房外廊 | 事件 | 偶 | 危季「问话」演出；不开放日常 |

**解锁：** 知情≥1 或 `heat` 事件/`ev_chu_patrol` 后口风「该去公门打点」。学徒默认不进。  
**夜间：** **关闭**（巡栈改在货栈巷，见货栈 `hz_dock_alley`）。

**歪门外牙链（Demo 必验感）：**

```
heat↑ / ev_chu_patrol → 口风打点
→ hz_yamen_chu · act_bribe_chu → 人情条 · heat 暂压
→（失败）加码查栈 · 银白花 · 褚仇隙
→（危季）班房问话事件 → 甩锅/穿帮
```
