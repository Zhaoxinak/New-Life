## 共用模板（每篇都按此写）

1. 一句话 / 时代背景  
2. 主线职责（正道 · 歪门 · 季会前后）  
3. **热区 id** + 挂接行动库 ID  
4. 谁在这、时段刷新  
5. 交情五档如何改决策  
6. 本建筑事件钩  
7. 产出信物 / 风险  
8. Demo 优先级 · 明确不做
