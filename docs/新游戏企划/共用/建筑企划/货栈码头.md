## 0. 一句话

明货从这里上船下栈；暗货也从这里夹带——**舱位与木箱，就是歪门的门。**

---

## 1. 时代背景

天津口岸货栈毗邻码头：木材码垛、土货进栈、回程洋货卸船。船期、潮汛、苦力、栈伙，全是市井与风险。

---

## 2. 主线职责

| 方向 | 作用 |
|---|---|
| 正道 | 装木验货、赶船期、攒摊绩；识货（眼力） |
| 歪门 | 夹带、掉包、少装多报、灌水木（事件警示） |
| 季会 | 本季船次成败进明账；穿帮多从此查起 |
| 攀爬 | 伙计「赔累」主舞台；管事管摊实绩场 |

**明暗两条装船链（Demo 必验）：**

```
正：木垛搬木 → 泊位押船 →（管事）办公室盯船
歪：知情揭箱 → 库房夹带 →（可选）夜走南边货 → 怕褚巡
```

## 8. Demo / 不做

**Demo P0：** 木垛 + 泊位 + 库房 + 办公室四热区；一明一暗装船链。  
**不做：** 真实航运模拟、每船 3D 操作、报关独立大关（报关 P1 浅挂）。
