# 事件池 【草案】

> 自由日不无聊：日事件 + 季事件 + 行动嵌入。  
> 不替代主循环；是市况/压力/口风/把柄的投放器。  
> 建筑落地：[`建筑企划/`](建筑企划/README.md) · 把柄产出：[`信物与把柄.md`](信物与把柄.md)  
> Demo 宜少而准；正式版扩池。禁 `flag_demo_*` 进共用逻辑。

---

## 1. 触发与配额

| 类 | 何时 | Demo 配额 |
|---|---|---|
| **日事件** | 日初掷：30% 出 1 条 | 最多 1；引导日可抬权 |
| **行动嵌入** | 做事成/败/大败附带 | 随行动；不占日事件名额 |
| **季事件** | 季初日：市况 1 + 可选季钩 1 | 市况必有；钩子 50% |
| **会前知会** | 季末日前日 | 必有 1（账房） |
| **危季特事件** | `firm_heat` 高 / 穿帮链 | 覆盖普通日事件 |

**投放原则：** 给由头不强制传送；口风推建筑；正式版扩池。

## 2. 权重与互斥（Demo）

| 规则 | 说明 |
|---|---|
| 同 id 冷却 | 日事件默认 5 日不重复 |
| 职级门 | 不满足条件的条目权重=0 |
| 知情门 | `ev_extra_crate` 仅 `know_dark=0` |
| heat 门 | `ev_chu_patrol` 建议 heat≥40 |
| 互斥 | 同日不叠两条「推同一建筑」的强引导 |
| 引导抬权 | Demo 引导策略可 ×2～×3 某 id（见 Demo/引导策略） |
