## 6. 检定与随机

### 6.1 何时检定

| 要检 | 不检（直接结算） |
|---|---|
| 有失败可能的做事、夹带、改账、口风、辩摊 | 纯移动、看提示、发季俸、打开面板 |
| 季会关键选项（帮腔、甩锅、争摊） | 强制剧情句（Demo 保底入场后的「听」） |

---

### 6.2 主公式（d100）

```
目标值 = 40 + 主本事×0.5 + 修正合计
目标值 clamp 到 [5, 95]
掷 d100：≤ 目标值 → 成功；否则失败
```

主本事：行动表指定的五维之一（勤谨/算盘/眼力/口才/胆色）。  
双本事行动：先平均再入式，或「主检 + 辅检各一次都过」——**Demo 默认取平均**。

---

### 6.3 修正表（可叠，先加后 clamp）

| 来源 | 修正 | 备注 |
|---|---|---|
| 交情（对关键 NPC） | 仇隙 −15 · 不睦 −8 · 泛泛 0 · 相善 +8 · 厚交 +15 | 只算当场相关的一人 |
| 职级资格差 | 刚好够阶 0；高一阶 +5；高两阶+ +10 | 低阶不可做的已灰掉 |
| 压力 | ≥60 → −5；≥80 → −12 | 见 [`职级与晋升/压力.md`](职级与晋升/压力.md) |
| 白日/夜班 | 夜班夹带 +5 成功率，但 heat 额外风险 | 暗行动 |
| 把柄逼人 | 被逼方做事 +20（事可成），事后交情必↓ | 铁律 |
| 银钱砸场 | 请客/贿赂：花足额 +5～+15 | 有上限一次 |
| 天气（季会内） | 危季问责 −5；喜季表功 +5 | 仅季会 |

---

### 6.4 结果分档

| d100 相对目标 | 结果 | 通用处理 |
|---|---|---|
| ≤ 目标−30 | **大成功** | 额外赏钱/交情↑/绩双份；文案加彩 |
| ≤ 目标 | **成功** | 按行动表成功栏 |
| > 目标 且 ≤ 目标+25 | **失败** | 按失败栏；压力 +5～10 |
| > 目标+25 或自然 96–100 且未大成功区 | **大失败** | 大赔/穿帮风险/交情↓；可挂旗 |

自然 1：若已成功，升一档（成功→大成功）；已大成功则再加一句彩。  
（可选规则，Demo 可开。）

---

### 6.5 对抗检定（可选）

两人对立（抢功、甩锅）：双方各算目标值，掷各自 d100，看谁「成功且差值大」。  
平局：掌柜眼色 / 职级高者胜。

## 7. 范例（三个）

### 7.1 正道：押木上船（伙计）

| 项 | 内容 |
|---|---|
| 何时 | 上午 · 货栈码头 |
| 行动 | `act_escort_ship` |
| 主检定 | **勤谨** |
| 成功 | 赏钱+；打工分+；`route_wood`↑ |
| 失败 | 赔累；交情（刘/鲍）可能↓ |
| 大失败 | 丢货；`firm_bright` 微扣 |

交情：鲍 ≥ 相善 → 成功率+；仇隙 → 刁难。

### 7.2 歪门：夹带一箱（柜伙/管事）

| 项 | 内容 |
|---|---|
| 何时 | 下午或夜班 · 货栈 |
| 行动 | `act_smuggle_slot` |
| 主检定 | **胆色** + **眼力**（Demo 取平均） |
| 成功 | `dark_perf`↑；字号 dark/cash/heat↑；污名微涨 |
| 失败 | 未装上；heat 仍微涨 |
| 暴毙 | 把柄落人口 / 推危季 |

余波：成功可触发「多出来的箱子」闲话。

### 7.3 社交：茶楼喝口风（≥伙计）

| 项 | 内容 |
|---|---|
| 行动 | `act_tea_gossip` / 会前 `act_pre_tea` |
| 花费 | 银钱少量 |
| 检定 | **口才**；交情定深浅 |
| 成功 | 预告天气或点名；交情微↑ |
| 失败 | 白花或假消息 |
