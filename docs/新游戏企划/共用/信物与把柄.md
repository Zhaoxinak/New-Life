## 1. 把柄（leverage）

### 1.1 什么是把柄

一条 **可用有限次逼人做事** 的实证 / 把柄物 / 把柄事。  
**强用时：** 事可成，**交情必降**（通常一档），并记「被迫」标签。  
厚交被强用 → 仍降档，且易转不睦（铁律优先于情面）。

### 1.2 字段

| 字段 | 说明 |
|---|---|
| `leverage_id` | 稳定 ID（下表） |
| `from` / `to` | 持有者 → 被制者（人物 id） |
| `tag` | 短标签（文案/UI） |
| `uses_left` | 默认 1；人情条类可 1～2 |
| `exposed_if_used` | 用后是否公开化（号内皆知） |
| `item_ref` | 可选信物 id（黑账页、人情条…） |
| `source_ev` / `source_act` | 来自哪条事件/行动 |

档案摘要只显示「把柄条数」；详情进情报页。

## 2. 怎么来 / 怎么用 / 怎么爆（总则）

| 阶段 | 规则 |
|---|---|
| **来** | 大失败目击、改账露馅、货情倒卖、主动搜集、人情反噬、危季供出 |
| **用** | 逼保荐/帮腔/装船/销案/免抛；每条默认 1 次强用 |
| **爆** | `uses_left=0` 后持有者可公开撕破脸；或双方互爆同毁 |
| **反咬** | 互有把柄 → 冷战、交换销毁、或同毁 |

## 4. 用例流程（Demo 必验感）

### 4.1 夹带败露 → 被握 → 季会免抛

```
act_smuggle_slot 大失败 → lev_bao_witness 或 lev_chu_bust
→（可选）act_bribe_chu 暂压
→ 危季问责 → 强用把柄求免抛
→ 交情降一档 + 被迫标签；事成或仍被抛（厚交也非绝对）
```

### 4.2 改账 → 孙握 → 求条受阻

```
act_cook_books 失败 → lev_sun_ledger
→ act_ask_key 默认拒或检定重罚
→ 还把柄（交实账/交情修补）或硬刚
```

### 4.3 货情 → 马握 → 反噬

```
act_sell_info 成功 → 银+；潜伏 lev_ma_sellout
→ 马强用或放风 → heat↑ / face↓
→ 玩家用 lev_player_ma 反咬或茶楼冷战
```

### 4.4 人情条生命周期

```
act_bribe_chu 成功 → 信物「公门人情条」（uses_left=1）
→ 使用压 heat / 销小案
→ 用尽 → lev_chu_favor_back（褚反握）或交情↓
```

## 5. 情报

### 5.1 档与 id 前缀

| 档 | 前缀 | 内容 | 获取 |
|---|---|---|---|
| 市况 | `intel_mkt_` | 木/毛旺淡、船期 | 茶楼、季市况、雨误 |
| 人事 | `intel_hr_` | 谁将被问责、谁保荐 | 会前知会、口风 |
| 暗线 | `intel_dark_` | 哪船有货、谁点名 | 知情≥1 + 打听/鲍留舱 |
| 对家 | `intel_rival_` | 裕泰动作 | 茶楼、`ev_yutai_*` |
| 公门 | `intel_yam_` | 是否查栈 | 褚巡、打点后 |

### 5.2 Demo 情报种子

| intel_id | 档 | 真假 | 来源例 | 依计行事 |
|---|---|---|---|---|
| `intel_mkt_wood_slump` | 市况 | 真 | `ev_wood_slump` | 转毛/加暗 |
| `intel_mkt_fur_hot` | 市况 | 真 | `ev_fur_boost` | 押毛船 |
| `intel_hr_blame_liu` | 人事 | 半真 | `ev_pre_notice` | 会前 align/plea |
| `intel_dark_slot_tonight` | 暗线 | 真 | `ev_bao_slot` | 夜夹带 |
| `intel_yam_patrol` | 公门 | 真 | `ev_chu_patrol` | 缓夹带或打点 |
| `intel_rival_wind` | 对家 | 真 | `ev_yutai_wind` | 护 face / 防探 |
| `intel_false_*` | 任意 | **假** | 口风检定失败 | 依计→额外失败/heat |

### 5.3 真假规则

- 口风/茶楼检定失败 → 写入 `intel_false` 集合（存档旗）。  
- UI 不标「假」；事败后口风可拆穿。  
- 依假情报做事：主检定额外 −10～−20 或直接事件惩罚。
