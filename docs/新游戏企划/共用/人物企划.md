## 0. 一句话

每个人物（含玩家）都是津门局里的一个人：有职级、有身家、有本事、有明暗名声、有把柄与压力；人和人之间用同一套关系数值互相看着。

---

## 1. 总原则

| 原则 | 说明 |
|---|---|
| **同一模型** | 玩家 = 带 `is_player` 的人物；NPC 读写同一套字段 |
| **为商号主线服务** | 数值服务：做事、升迁、明暗、季会、正歪，不堆战斗 RPG |
| **能演出来** | 优先用场面/称呼/物件反馈；数字给系统算，少直接甩脸 |
| **关系是双向边** | A 对 B 与 B 对 A 可不同；玩家不特殊 |
| **字号 ≠ 人物** | 字号季账、明暗总盘是公司层；人物只持「自己的摊绩/股份/嫌疑」 |

---

## 2. 人物要分几层

```
身份（是谁、在哪混）
  → 职场（职级、分管、功绩）
  → 身家（银钱、股权）
  → 本事（会干什么）
  → 名声与风险（明誉 / 污名 / 嫌疑 / 把柄）
  → 压力（本阶在怕什么）
  → 关系网（对其他人怎么看）
```

---

## 3. 身份层（结构字段，多为非数值）

人人都有；决定「能进哪、台上怎么叫」。

| 字段 | 说明 | 玩家 / NPC |
|---|---|---|
| `id` / 姓名 | 稳定 ID + 显示名 | 同 |
| 籍贯 / 出身 | 同乡会馆、师承话头 | 同 |
| 所属 | 本号 / 对家 / 会馆 / 钱庄 / 洋行 / 公门 / 闲散… | 同 |
| 职务标签 | 账房先生、师父、众东、买办眼线…（可多标签） | 同 |
| 是否在本号编制 | 决定吃哪份月钱、能否入季会席 | 同 |
| `is_player` | 仅控制权 | 仅玩家为真 |

---

## 4. 职场层（攀爬核心）

对齐总稿六阶：学徒 → 伙计 → 柜伙 → 管事 → 掌柜 → 号东。

| 数值 / 字段 | 含义 | 谁在用 |
|---|---|---|
| **职级**（1–6） | 古称阶；决定福利/权力/义务/压力味道、季会座位 | 本号众人；外号人物可映射「相当阶」 · **详档** [`职级与晋升/`](职级与晋升/README.md) |
| **分管摊** | 木摊/毛摊/暗线…或空 | 管事+ 常见；决定季会交哪本账 |
| **摊绩** | 本季/近季你摊上的成色（明） | 问责表功、升迁燃料 |
| **暗绩** | 你经手暗货带来的银与险（可隐藏） | 歪门、掌柜调配、穿帮时算到人头 |
| **号内倚重** | 掌柜/号东觉得你「还能用」 | 正道提拔；被裁时谁先走 |
| **满师 / 保荐等旗** | 信物进度（满师帖、荐保…） | 卡 1→2、2→3 |

> **功绩不要只做一个总数**：至少拆 **摊绩（明）** 与 **暗绩**，否则正歪在季会上分不清。

外号 NPC（会馆董事、巡捕、洋行买办）可以：

- 职级填「社会当量」（例如会馆管事 ≈ 本号管事阶），或  
- `职级` 为空，只用职务标签 + 本事/名声 —— Demo 可先对本号全员上满六阶模型。

---

## 5. 身家层

| 数值 | 含义 | 主线 |
|---|---|---|
| **银钱** | 个人活钱 | 请客、买通、赔货、入股起步 |
| **身股 / 银股** | 在本号（或他号）的股权份额；无则 0 | **号东必经**；议东投票权重 |
| **亏空 / 私欠** | 欠号里的、欠钱庄的、欠高利的 | 歪门反噬；季会可被拿捏 |

玩家与 NPC 都会贪银子、都会欠债；AI 用同一套决定「要不要收你的贿」。

---

## 6. 本事层（能力数值 · 建议五维）

不搞战斗属性。服务：跑单、上柜、夹带、交际、季会话术。

| 数值 | 古味称呼 | 管什么 |
|---|---|---|
| **勤谨** | 腿脚与守规 | 学徒伙计跑腿成功率；少丢货 |
| **算盘** | 账与价 | 柜伙对账、议价、改账（歪）难度 |
| **眼力** | 识货 | 验木验药、看出灌水木/夹层 |
| **口才** | 说话办事 | 请客、会馆站台、季会辩摊 |
| **胆色** | 敢不敢走歪 | 夹带、洋药、买通公门的成功率；也更容易惹嫌疑 |

派生（可不单独存，用公式）：

- **明本事** ≈ 勤谨 + 算盘 + 眼力  
- **暗本事** ≈ 胆色 + 眼力 + 算盘  

检定：做事 / 季会选项成功率 = 本事 ± 关系 ± 职级资格。

---

## 7. 名声与风险层

明暗双账在人物身上的影子。

| 数值 | 含义 | 主线 |
|---|---|---|
| **明誉** | 会馆、洋行、体面人眼里的信用 | 正道破格·名；喜季谈扩摊 |
| **污名** | 「手脚不干净」的江湖传闻 | 高了会馆抽脸、众东忌用；歪门快的代价 |
| **公门嫌疑** | 巡捕/衙门/洋关盯你的程度 | 危季、查私；胆色行事推高 |
| **把柄**（你握别人的 / 别人握你的） | 见 §8 关系边；也可有「总把柄值」作摘要 | 逼让、抛人、歪门要挟 |

> **明誉 ↑ 与 污名 ↑ 可并存**（外清内浊）——正符合木行门面。

---

## 8. 压力层

总稿：每阶压力味道不同。人物上建议：

| 字段 | 说明 |
|---|---|
| **压力**（0–100） | 当前紧绷程度；高了易出事、易选歪门、季会易失态 |
| **压力类型** | 由职级决定（只读）：体罚被逐 / 赔累 / 账脸 / 摊责 / 代过 / 存亡 |

来源：丢货、错账、摊亏、穿帮风险、欠债、季会问责。  
缓解：休息、认责过关、升职换味道（旧压可部分结算）。  

**按职级展开的类型、加压源、高压后果** → [`职级与晋升/压力.md`](职级与晋升/压力.md)。

NPC 压力高：更易背叛、泄密、在季会甩锅——与玩家同一套。

## 9. 关系层（人对人 · 人人相同）

任意两人 `A → B` 一条边（玩家与 NPC 同一套）。  
**主轴是五档「交情」**——决定对方遇事时的默认决策；其余为修正项。

### 9.1 五档交情 · 怎么起名

你要的五档（敌对 → 喜爱）在商号局里，建议用下面这套**当面称呼 / 系统名**，比「好感」「喜爱」更贴津门，也不易做成恋爱游标。

| 档 | 系统短名 | 当面/档案用语（推荐） | 今语对照 | 一句话 |
|---|---|---|---|---|
| 1 | **仇隙** | 有仇 / 不对盘 | 敌对 | 见面就想绊你，能坑则坑 |
| 2 | **不睦** | 面冷 / 不对付 | 稍差 | 不帮不主动害；有机会使绊 |
| 3 | **泛泛** | 点头之交 / 寻常 | 中立 | 按规矩来，少额外人情 |
| 4 | **相善** | 说得上话 / 相熟 | 好感 | 愿帮一把，仍看利害 |
| 5 | **厚交** | 贴心 / 靠得住 | 喜爱（偏交情，非必然恋情） | 肯护短、肯担险，仍可被把柄/大义压过 |

**命名说明：**

- 总称用 **「交情」**（五档），不用「好感度」——商号里先是办事交情。  
- 第 5 档用 **厚交** 而非「喜爱」：可含师徒亲、同乡死党、男女私情；私情用关系标签 `恋慕` 叠加，不单开一套恋爱数值。  
- HUD 可只显示档案用语；底层仍可用 -2…+2 或 0…100 映射到五档。

**数值映射（建议）：**

| 交情分（对对方） | 档 |
|---|---|
| ≤ −60 | 仇隙 |
| −59 ～ −20 | 不睦 |
| −19 ～ +19 | 泛泛 |
| +20 ～ +59 | 相善 |
| ≥ +60 | 厚交 |

单向：A 对 B 是厚交，B 对 A 可以是不睦。

### 9.2 修正项（不替代交情档）

交情定「愿不愿」；下面定「能不能 / 敢不敢」：

| 修正 | 含义 | 典型打断 |
|---|---|---|
| **信任** | 托密、托暗线 | 相善但信任低 → 帮明忙，不帮藏私 |
| **疑心** | 防你抢摊/告密 | 厚交但疑心高 → 护你面子，不交底账 |
| **债** | 谁欠谁 | 不睦但欠你大债 → 被迫帮一次 |
| **把柄** | 你握他的 | 仇隙也得按你口气办（恨你更深） |
| **忌惮** | 怕你后台/手段 | 泛泛也敢不敢拒绝你 |

### 9.3 五档 → 默认决策（核心）

下表是 **A 对 B 的交情** 下，A 做决策时的默认倾向。  
实际 = 默认 × 信任/疑心/债/把柄/压力/号内利害。

#### 日常

| 决策 | 仇隙 | 不睦 | 泛泛 | 相善 | 厚交 |
|---|---|---|---|---|---|
| 借小钱 / 通融半天 | 拒，或故意刁难 | 拒 | 看规矩/利益 | 多半允 | 允，少讨价 |
| 通风报信（对你有利） | 不报，或报假 | 不报 | 偶漏一句 | 愿报 | 抢着报 |
| 通风报信（出卖你） | **抢着卖** | 有价就卖 | 危及自身才卖 | 很难卖 | 几乎不卖（除非把柄/大祸） |
| 一同事上抢功 | 必抢、栽脏 | 能抢则抢 | 看机会 | 少抢你 | 让你、或共享 |
| 请你喝酒说话 | 拒或设套 | 冷脸 | 可去，话少 | 愿去 | 深谈、交底 |

#### 明业 / 暗业

| 决策 | 仇隙 | 不睦 | 泛泛 | 相善 | 厚交 |
|---|---|---|---|---|---|
| 带你做干净单 | 排除你 | 不优先 | 按职级 | 愿搭手 | 主动拉你 |
| 交你一条暗线 | 绝不（除非陷害） | 绝不 | 极少 | 信任够才交 | **可交**（主通道） |
| 穿帮时供出你 | **优先供你** | 倾向供你 | 供弱势/外人 | 尽量扛、少提你 | 替你挡、自己认或甩仇家 |
| 联手夹带 | 只为坑你 | 难 | 纯分成关系 | 可谈 | 好搭档 |

#### 季会（见季会企划）

| 决策 | 仇隙 | 不睦 | 泛泛 | 相善 | 厚交 |
|---|---|---|---|---|---|
| 问责时帮腔 | 落井下石 | 沉默或阴阳 | 中立看掌柜眼色 | 帮你圆 | 力保、揽责 |
| 争摊 / 砍摊 | 主张砍你 | 不反对砍你 | 按账说话 | 保你摊 | 用自己摊换你的 |
| 人事提名 | 挡你升 | 不荐你 | 无表态 | 可保荐 | **力荐**、以名声担保 |
| 危季抛人 | 第一个点你 | 点你很轻松 | 点「好抛的」 | 死保到最后 | 宁自己被点 |
| 议东投票 | 反你 | 难投你 | 看股权与号东 | 倾向你 | 绑在你车上 |

#### 破格 / 外场

| 决策 | 仇隙 | 不睦 | 泛泛 | 相善 | 厚交 |
|---|---|---|---|---|---|
| 会馆替你说话 | 毁你 | 不帮 | 挂名应付 | 愿站台 | 押自己脸面 |
| 钱庄替你担保 | 拆台 | 拒 | 看抵押 | 可商 | 宽贷 |
| 公门事上帮你压 | 加码害你 | 不管 | 留一手 | 递话 | 拼人情去销 |

### 9.4 交情怎么变（简规）

| 行为方向 | 交情 |
|---|---|
| 帮腔、让利、救命、季会力保 | ↑ |
| 抢功、栽赃、供出、砍摊落井 | ↓ |
| 共事久、同乡酒、共同分赃成功 | ↑（可脏） |
| 把柄逼人办事 | 事能成，但交情常 ↓（怕与恨） |

单季大变建议封顶跳 **一档**，避免一天从仇隙变厚交（特殊剧本除外）。

### 9.5 交情决策铁律（冲突时）

当「交情」与「把柄 / 银钱 / 号规 / 气血」打架时，按下列优先级决断（同一 NPC、同一场决策）：

| 优先级 | 因素 | 说明 |
|---|---|---|
| 1 | **号规 / 公堂 / 当场穿帮** | 人在当场、证据凿实 → 厚交也难硬保；最多改为「死保到最后、自己背锅」 |
| 2 | **把柄（leverage）** | 可逼成 1 次事；**必须**伴随交情 ↓（怕与恨），且不睦/仇隙下逼成更脏 |
| 3 | **银钱 / 生死债（obligation）** | 可买一次票；厚交用银 = 人情债；仇隙收钱 = 交易，不升档 |
| 4 | **交情五档** | 无 1～3 强制时，**完全按档**走 §9.3 表 |
| 5 | **忌惮（dread）/ 字号气血** | 危季、高热时，泛泛更易抛人；厚交仍死保，但成本写进压力 |

**铁律摘要：**

- **厚交 ≠ 免疫把柄**：厚交被逼办事时，事可成，档必降（通常一档），并记「被迫」标签。  
- **仇隙 ≠ 永不交易**：仇隙可用银/把柄成交，但事后交情不升，污名/嫌疑可升。  
- **相善/厚交挡不住字号崩盘**：危季抛人时，厚交「宁自己被点」优先于「保你升职」。  
- **Demo 保底不得改写交情铁律**：引导策略可抬事件概率，不可把仇隙写成力荐。

冲突样例（管事提名）：钱伯衡对你 **相善**，但你持其把柄且本季 `firm_heat` 高 → 他可保荐入座，但会压你「别再惹火」；若你再逼，交情降为泛泛。

### 9.6 关系表字段（修订）

```
from_id, to_id,
rapport,              # 交情分 → 映射五档
rapport_tier,         # 可选缓存：仇隙|不睦|泛泛|相善|厚交
trust, suspicion,     # 信任 疑心
obligation, leverage, dread,  # 债 把柄 忌惮
kinship,              # none|blood|clan|in_law —— 亲戚；与交情独立
bond_tags             # 社会纽带：apprentice|fellow_disciple|tongxiang|sworn|romance…
```

旧稿「人情」并入 **交情分/五档**；决策优先读档，再用修正项。  
**亲戚/师徒写在 `kinship` / `bond_tags`，不要只靠备注。** 开局总表见 [`人物档案/亲戚与社会纽带.md`](人物档案/亲戚与社会纽带.md)。

常见关系对（本号 Demo）：玩家 ↔ 师父/掌柜/号东/同辈/账房；及外场会馆、钱庄、对家、公门。NPC↔NPC 同样算。

## 10. 和主线系统怎么咬合

| 系统 | 主要吃哪些人物数值 |
|---|---|
| 日常做事 | 本事五维、职级资格、勤谨/丢货 |
| 正道升迁 | 摊绩、号内倚重、明誉、**提拔人对你的交情档** |
| 歪门 | 胆色、暗绩、污名、嫌疑、把柄；交情影响谁肯联手/谁先供你 |
| 季会 | 职级座位、摊绩/暗绩、口才、**交情五档决策**、压力 |
| 破格→掌柜 | 明誉或脏银（暗绩）+ 外场关系 |
| 破格→号东 | **股权** + 众东关系/把柄 |
| 外场（会馆钱庄公门） | 明誉/污名/嫌疑、银钱、口才、胆色 |

## 12. HUD 建议（玩家可见 vs 藏）

| 常显 | 可查档案 | 默认隐藏（靠演出） |
|---|---|---|
| 银钱、职级 | 本事五维、明誉 | 暗绩、污名细节、他人把柄 |
| 当前压力味道（文案） | 分管摊、股权 | 公门嫌疑精确值 |
| | 与关键人的**交情档**（仇隙…厚交） | NPC 之间的边（可部分窃听得知） |

NPC 用同一数据；玩家「调查/喝茶」只是**解锁阅读权限**，不是另一套数值。

## 13. 范围

**做：** 同一模型；五维本事；明誉/污名/嫌疑；摊绩/暗绩；股权；**交情五档 + 修正项**；压力。  

**不做（本期）：** 战斗攻防、以「喜爱」为名的恋爱数值主轴（恋慕仅作标签）、每人一套独特成长树。

## 14. 待补人物名单（占坑）
